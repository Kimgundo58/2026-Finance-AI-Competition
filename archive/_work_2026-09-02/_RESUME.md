# 재개 릴레이 지시 (2026-09-01 02:50 자동 실행)

너는 **릴레이 전용 세션**이다. 작업을 직접 하지 마라. 아래 3가지만 하고 끝낸다.

배경: 8세션(A~H)이 `0831_최종구현.md` 계약서대로 Agent 층을 구현하던 중
계정 토큰 한도에 걸려 멈췄다. 02:40 에 한도가 리셋됐다. 그 세션들을 깨우는 게 네 일이다.

---

## 1. 등록소에서 세션 이름을 읽는다

```bash
export PYTHONIOENCODING=utf-8 && for f in scripts/_work/_sessions/*.txt; do echo "$(basename $f .txt) -> $(cat $f)"; done
```

`README` 는 세션이 아니다 — 건너뛴다.
🔴 **이름이 중복될 수 있다.** 두 역할이 같은 이름이면 `이름 [ref]` 를 통째로 써서 보낸다.
(현재 등록분 기준 B 와 F 가 둘 다 `ai-0f` 이고 ref 가 다르다)

## 2. 살아 있는 세션에만 재개를 지시한다

`ListAgents` 로 어느 이름이 실제로 살아 있는지 먼저 확인한다. 죽은 이름에는 보내지 않는다.

살아 있는 역할마다 `SendMessage` 로 아래를 보낸다 (`<역할>` 만 바꾼다):

```
[재개] 계정 토큰 한도가 02:40 에 리셋됐다. 작업을 재개해라.
`결과보고.md` 의 `<역할>` 섹션에 네가 적어둔 "다음에 이어서 할 일" 부터 이어간다.
계약서는 `0831_최종구현.md` — 소유권(§3)·동결 인터페이스(§4)·정지 조건(§7)·
하지 않을 것(§10)은 그대로다. 끝나면 자기 섹션을 갱신하고 A 에게 `DONE <역할>` 을 보낸다.
```

**A 에게는 한 줄을 더 붙인다:**

```
🔴 A 추가: 다른 세션들의 진행 상태를 `결과보고.md` 로 파악하고 통합을 이어가라.
GPU 창을 열기 전에 반드시 드라이런을 먼저 통과시켜라. 끝나면 즉시 팟을 닫는다.
```

## 3. 결과를 남긴다

`scripts/_work/_resume_결과.md` 에 한 파일로 적는다 — 실행 시각, 살아 있던 역할,
보낸 역할, 죽어 있던 역할. 그게 전부다.

## 🔴 하지 않을 것

- **작업을 직접 하지 마라.** 코드·데이터·스키마를 건드리지 않는다. 너는 릴레이다
- **GPU 팟을 열지 마라.** A 만 연다 (훅이 중복 개설을 거부한다)
- **커밋하지 마라**
- 아무도 안 살아 있으면 `_resume_결과.md` 에 그 사실만 적고 끝낸다.
  새 작업 세션을 스스로 만들지 마라 — 감독 없는 무인 재시작은 오너가 승인한 범위 밖이다
