# 써도돼요 — API 컨테이너 의존성 (FastAPI + CPU 임베딩). Dockerfile 빌더 단계가 설치한다.
#
# 임베딩(KURE-v1)은 이 컨테이너 안에서 CPU 로 실행한다(scripts/retrieve.py, device="cpu").
# 별도 서비스로 분리하지 않는다. 판정 1건에 네트워크 왕복이 하나 더 생기면 SSE 하트비트(12초) 간격을 넘길 수 있다.
#
# torch 는 CPU 빌드로 고정한다. PyPI 기본 torch 는 CUDA 빌드(~2.5GB)라 이미지가 지나치게 커진다.
# `+cpu` 로컬 버전은 아래 인덱스에만 있으므로 버전 고정 자체가 CUDA 휠 설치를 막는다.
# `--index-url` 로 바꾸지 않는다. 이 인덱스에는 fastapi 등 다른 패키지가 없다.
--extra-index-url https://download.pytorch.org/whl/cpu

# ── 웹 계층 ───────────────────────────────────────────────────────────
fastapi==0.141.1
# [standard] 확장은 붙이지 않는다. 로컬 개발 환경과 같은 구성으로 둔다
uvicorn==0.52.4
pydantic==2.13.4
# routes_l3 의 File()/Form() 이 필요로 한다. 없으면 라우트 등록에서 실패한다
python-multipart==0.0.32
# server/auth.py 가 JWKS 를 가져온다. FastAPI TestClient 도 사용한다
httpx==0.28.1
# server/auth.py 의 Supabase JWT 검증. 지연 import 라 없어도 기동은 되지만 첫 로그인에서 실패한다.
# [crypto] 는 Supabase 의 RS256/ES256 서명 검증에 필요하다
PyJWT[crypto]==2.13.0

# ── DB ───────────────────────────────────────────────────────────────
psycopg==3.3.4
psycopg-binary==3.3.4

torch==2.11.0+cpu

numpy==2.1.3
# BM25 토큰화. 색인과 쿼리가 같은 토큰화를 써야 한다
kiwipiepy==0.23.1

# HWPML(XML)

# HWP OLE v5

# pdfplumber 의 필수 의존성이다. 버전을 고정하려고 명시한다
pypdfium2==5.12.1
# stage0_extract 의 1차 PDF 판독
pypdf==6.15.0

# ── 넣지 않은 것과 이유 ──────────────────────────────────────────────
# torchvision      : 판정·파싱 경로에서 import 하지 않는다. 약 500MB 를 차지한다
# bm25s            : 서빙 경로에서 쓰지 않는다
# requests / bs4   : 법령 수집 스크립트 전용이다. 컨테이너는 수집을 하지 않는다
# pydantic-settings: 코드에서 import 하지 않는다
# httpx-sse        : 서버는 SSE 를 보내기만 한다. 클라이언트 파서는 필요 없다
#
# 이 파일을 바꾸면 빌더의 pip 레이어가 다시 실행된다. 모델 재다운로드는 Dockerfile 의 캐시 마운트가 막는다.
