# 프론트 수정 정리 (2026-09-04)

QA 지적 **2 / 3-1 / 3-2** 번호를 그대로 씁니다. 그 항목을 고치다 같이 나온 것은 해당 번호 아래에 붙였습니다.

## 2. 주관기관 → 1개로 고정, 검색·수정 불가

- 기관 목록이 코드에 1개만 박혀 있었음 → `lib/orgs.ts` 새로 만들고 `GET /api/orgs` 로 검색하게 고침.
- 온보딩 2단계에서 입력해도 아무 반응이 없었음 → 250ms 디바운스 검색 붙여서 서버 결과가 목록으로 뜨게 고침.
- 마이페이지 주관기관도 같은 하드코딩이었음 → 온보딩과 같은 검색으로 바꾸고, 빈 값이면 저장 버튼이 안 눌리게 고침.
- 서버에 기관 데이터가 없으면 온보딩이 통째로 막혔음 → 0건이면 기존 기관 1개를 예비로 보여주고 진행은 되게 고침.

---

## 3-1. 지출 상세 → 첨부 파일 임의 생성

- 상세를 열면 「견적서·참고자료」를 화면이 지어내고 있었음 → 지어내는 코드를 없애고 실제 첨부만 보여주게 고침.
- 새 지출계획에서 넣은 첨부가 상세에 안 나타났음 → `lib/attachments.ts` 새로 만들어 계획 id 로 보관하고, 상세에서 그걸 읽어 뿌리게 고침. (서버에 첨부 API 가 아직 없어 세션 동안만 유지됩니다.)
- 임시저장이 나중에 진짜 계획이 되면 첨부가 끊겼음 → 저장 시 id 를 옮겨 붙게 고침.
- 첨부 크기·개수 제한이 없었음 → 1개 3MB, 최대 10개로 막고 넘으면 안내가 뜨게 고침.

---

## 3-2. 지출 상세 내 일정 → 결제 전 확인 항목 / 집행 / 필요 증빙 자료

- 체크박스를 눌러도 서버에 안 남고 새로고침하면 풀렸음 → `할일수정` 을 불러 `상태: 완료/준비필요` 로 저장하게 고침.
- 서버에 없는 항목(예시 데이터)을 누르면 오류창이 떴음 → 서버에 있는 것만 저장하고, 없으면 화면에서만 바뀌게 고침.
- 그때 뜨던 「저장할 수 없습니다」가 사실상 정상 상황이었음 → 체크는 그대로 두고 한 줄 안내만 뜨게 고침.
- 집행 일정 화면이 통째로 비는 경우가 있었음 → `일정만=true` 결과가 0건이면 전체 할일로 다시 채우게 고침.

## + 홈 지출목록 & 지출계획 지출목록 정렬 통일

- 홈과 목록의 정렬 기준이 서로 달랐음 → 양쪽 다 「위험 먼저 → 최근 수정순」으로 맞춤.

## + 상세지출 내 task 와 일정 task 의 연결

- 상세 체크박스와 집행 일정 완료가 따로 놀았음 → `ScheduleItem.taskId` 를 추가해 같은 할일을 가리키게 고침.
- 한쪽만 눌러도 다른 쪽이 안 바뀌었음 → 양쪽을 한 함수(`할일동기화`)로 묶어 상세↔일정 어느 쪽을 눌러도 같이 바뀌고 서버에도 저장되게 고침.

## + 그 밖에 (고치다 발견한 것)

- 목록의 「선택 항목 AI 점검」이 서버를 안 부르고 2.7초 애니메이션만 돌았음 → `planId` 를 넘겨 실제 판정을 부르고, 결과가 배지에 반영되게 고침. (배지가 전부 「점검 전」이던 원인)
- 예전에 「둘러보기」를 한 번 누르면 그 데모 토큰이 로그인 토큰을 덮어썼음 → 로그인 토큰을 우선 쓰게 뒤집음. (「지출계획 23412 을(를) 찾을 수 없습니다」의 원인)
- 계획을 못 찾으면 판정이 통째로 죽었음 → 저장만 포기하고 `plan_id` 없이 한 번 더 판정해 결과는 나오게 고침.
