## 0. 레이어 설계 (L1 / L2 / L3)

이 데이터셋은 창업지원사업 규범의 **위임 계층(delegation chain)** 을 그대로 따른다.
「중소기업창업 지원사업 통합관리지침」 제2장(추진체계)이 정의하는 체계가 곧 레이어 구조다.

```
총괄기관 (중소벤처기업부)                          ← L1
      │  기본계획 · 운영요령(고시) · 통합관리지침
      ▼
전문기관 (창업진흥원)                              ← L2
      │  사업별 세부관리기준
      ▼
주관기관 (대학 · 창조경제혁신센터 · TP · 기술원 등)  ← L3
      │  협약 · 사업비 집행 · 점검
      ▼
창업기업등 (예비창업자 · 창업기업 · (예비)재창업자)
```

| 레이어 | 주체 | 폴더 | 문서 성격 | 파일 수 |
|---|---|---|---|---|
| **L1** | 중소벤처기업부 (총괄기관) | `중기부/` | 법률·고시·훈령·**통합관리지침** (모든 사업 공통 상위규범) | 9 |
| **L2** | 창업진흥원 (전문기관) | `창진원/` | 사업별 **세부관리기준** (지침이 위임한 사항 구체화) | 42 |
| **L3** | 주관기관 (사업 수행기관) | `창진원/*/주관기관 현황`, `중기부/(공고문)…통합공고문` | 주관기관 명단·연락처·주소 → **DB 다운로드 예정** | (부분 수집) |
| **공통** | 시스템 운영 | `PMS/` | K-Startup 사업관리시스템 **역할별 사용 매뉴얼** | 42 |
| **공통** | 중진공 | `kosmes_faq.json` | 창업지원 **FAQ 194건** (실무 Q&A) | 1 |

### 규범 위계 (RAG 인용 우선순위)

```
① 법률      보조금 관리에 관한 법률 / 공공재정환수법 / 중소기업창업 지원법
② 고시      중소기업창업 지원사업 운영요령 (중기부고시 제2024-101호)
③ 훈령      중소벤처기업부 보조사업 관리규정 (훈령 제181호)
④ 지침      중소기업창업 지원사업 통합관리지침 (제14차, ’25.12.23.)   ← L1
⑤ 세부기준  사업별 세부관리기준 (예비창업 / 초기창업 / 창업도약 / …)   ← L2
⑥ 공고문    연도별 모집공고 (구체적 지원자격·금액·일정)
⑦ 매뉴얼    PMS 시스템 조작 매뉴얼 · FAQ                              ← 실무
```

> **충돌 시 원칙**: 상위 규범 우선. 단 세부관리기준 다수가 "요령 및 지침을 우선 적용하고,
> 명시되지 않거나 지원사업의 특성에 따라 달리 정하는 사항은 본 기준을 따른다"고 명시(예: 초격차 제3조).
> 재도전성공패키지는 "주관기관 내부규정과 상충되는 경우 본 관리기준 우선"(제3조).

## 2. `창진원/` — **L2: 전문기관 사업별 세부관리기준** (작성 시 42개 · **현재 61개**)

L1 통합관리지침이 위임한 사항을 사업별로 구체화. 대부분 **연도별 개정 이력**이 함께 보관되어 있어
**버전 비교(diff) 학습**에 바로 활용 가능하다.

### 2-0. 전형적인 세부관리기준 골격

```
제1장  총칙 (목적 · 용어정의 · 적용범위)
제2장  추진체계 (평가위원회 / 사업운영위원회)
제3장  선정 (신청자격 · 선정평가 · 최종선정)
제4장  협약 (협약의 변경)
제5장  사업 운영 (창업프로그램)
제6장  보고(점검) 및 평가   ← 제1절 주관기관 / 제2절 창업기업 으로 분리
제7장  사업비의 구성 및 집행 ← 주관기관 비목 / 창업기업 비목
제8장  사업비의 관리 원칙
제9장  사업비 정산 및 제재·환수
제10장 사후관리 및 행정사항
```

### 5-1. 포맷별 파서

| 포맷 | 개수 | 파서 | 비고 |
|---|---|---|---|
| PDF (텍스트) | 약 20 | `pymupdf` / `pdfplumber` | 일부 파일에 **글자 이중 렌더링** 존재(같은 문장이 두 번 추출됨 — 제14차 지침, 창업도약 2022본 등) → 중복 라인 제거 후처리 필요 |
| PDF (스캔 이미지) | 2 + PMS 대부분 | **OCR / VLM 필요** | 부정행위 사례집(62p), 재도전 2026 기준(9p), PMS 42개 전부 |
| HWP (일반) | 약 20 | `olefile` + `zlib` BodyText 파싱 | 제어문자 노이즈(`捤獥汤捯`, `湰灧`, `氠瑢`, `桤灧`, `汯捯` 등) → 정규식 필터 필요 |
| HWP (배포용/DRM) | 약 13 | **`pyhwp`** (`pip install pyhwp`) | 일반 파서로는 "이 문서는 상위 버전의 배포용 문서입니다" 안내문만 나옴. `hwp5.xmlmodel.Hwp5File` + `hwp5.hwp5txt.TextTransform` 조합으로 ViewText 복호화 가능 (문서당 30초~2분 소요) |
| HWPX | 1 | `zipfile` + XML | `Contents/section0.xml` — 가장 깨끗한 텍스트 |
| JSON | 1 | 표준 파서 | 그대로 사용 |

**배포용 HWP 추출 코드 스니펫**

```python
from hwp5.xmlmodel import Hwp5File
from hwp5.hwp5txt import TextTransform

tt = TextTransform()
f = Hwp5File(path)
with open(dest, 'wb') as o:
    tt.transform_hwp5_to_text(f, o)   # Hwp5File 객체를 넘겨야 함 (경로 문자열 X)
f.close()
```

> 다만 이 방식은 **표(table) 내용이 `<표>` 플레이스홀더로만 남는** 경우가 있다
> (예: 팁스 운영사 현황). 표 데이터가 핵심인 문서는 한글뷰어 → PDF 변환 후 표 추출 권장.

### 5-4. 청킹 전략 제안

- **법령 · 지침 · 세부관리기준** → **조(條) 단위** 청킹. `제N조(제목)` 정규식으로 분할하고 항·호는 같은 청크에 유지. `article_path`를 청크 헤더로 프리펜딩.
- **TIPS 운영지침** → 조 체계가 아닌 **번호 항목(`1.` → `가.` → `1)`)** 체계 → 2단계(항목 > 하위항목) 분할.
- **통합공고문(508개 사업표)** → **행(row) 단위 구조화 추출** 후 표 형태 유지. 자유 텍스트 청킹 금지.
- **주관기관 현황 / 운영사 현황** → 테이블 → **정형 DB로 별도 적재** (L3 소스).
- **FAQ** → Q+A 1건 = 1청크. `category_main`/`category_sub`를 메타데이터로.
- **PMS 매뉴얼** → 페이지 단위 + VLM 캡션. 조작 절차는 **순서 보존**이 중요하므로 페이지 순서 메타데이터 필수.
- **부정행위 사례집** → 사례 1건(사례 본문 + `조치` 블록) = 1청크. 제재 수위("참여제한 5년, 사업비 전액 환수")가 답변 근거로 직결됨.
