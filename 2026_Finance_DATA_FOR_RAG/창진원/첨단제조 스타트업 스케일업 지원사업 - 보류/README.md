# 첨단제조 스타트업 스케일업 지원사업 — 수집 보류

## 보류 사유
**현금(사업화 자금)이 창업기업에 직접 지급되는지 불명확.**
장비·인력·인증 체계를 **현물로 제공**하는 프로그램형으로 읽히며,
그렇다면 창업기업이 직접 집행하는 사업비가 없어 사전승인 판정 대상이 아니다.

## 근거
2026년 통합공고문(중기부 공고 제2025-648호) p.6~7 ◇사업화 연번 10

- 사업개요: 첨단제조 스타트업의 제품 고도화 및 기술 검증을 위해 **지역 혁신기관(TP, 대학, 연구기관 등)이 보유한 장비·역량을 활용**하여 조기 스케일업 지원
- 지원내용: 지역 혁신기관 등이 보유한 **전문 장비·인력·인증 체계를 활용하여 전주기 기술지원 프로그램**을 지원
  → **"①사업화 자금" 표기 없음**
- 지원대상: 10년 미만 첨단분야 제조창업기업 / 예산 28억 / ’26.2월(예정) / 창업진흥원 지역전략실 / **비고 "신규"**

세부관리기준 미발간 (폴더가 빈 것은 수집 실패가 아니라 문서 미존재).
