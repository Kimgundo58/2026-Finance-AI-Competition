# 룰 A-Z 재검토 — 최종 결론과 수정 목록

> 중앙 ai-c5 · 2026-09-04 · 워커 4 + 문서세션 1 산출을 통합했다.
> 진단 과정은 [[_홀리스틱_불가가_0인_이유]](정정이 그대로 남아 있는 기록). **이 문서가 결론이다.**

## 0. 한 줄

「룰이 «불가» 를 말하지 못한다」는 **절반만 맞았다.** 불가를 말하는 자리는 `허용` 컬럼이 아니라
**금지예시**이고, 병목은 어휘가 아니라 **매칭**이다. 오늘 고친 5행은 전부 **«틀린 불가» 를 없앤 것**이라
즉답 불가는 늘지 않고 **줄어든다.**

## 1. 적용한 것 — `corpus.rules` 5행 (각 금지예시 한 원소)

| rule | 사업 / 비목 | 바꾼 값 | 왜 |
|---|---|---|---|
| 440 | 초기창업 / 인건비 | `퇴직급여충당금` → `1년 미만 근무 인력의 퇴직급여충당금` | **2025 개정 미반영.** 근거는 2025년판을 가리키는데 값이 2024년판이다 |

| 467 | 창업도약 / 인건비 | 4대사회보험 미가입 신규 채용인력 → `+(제도상 가입 불가자는 예외)` | 위와 같다 |

- 🔴 **449·458·467 은 한 행 안에서 자기모순이었다** — `허용예시` 에 「만 60세 이상 국민연금 제외자」가
  이미 들어 있는데 `금지예시` 는 무조건이었다. 실호출로 「만 65세 이후 고용된 자」 인건비가
  **LLM 0회 즉답 «불가»** 로 죽는 것을 확인했다. 세 사업 동시라 파급이 컸다.
- 🔴 **예비 rule 430 은 안 건드렸다.** 예비는 2025년판도 「집행불가」라 **정확하다.**
  「예비를 복사했다」로 오진한 채 고쳤으면 정확한 룰을 망가뜨렸을 자리다 → 회귀 케이스로 박았다.

**절차**: 74행 스냅샷(`_스냅샷_적용전_74행.json`) → 트랜잭션 하나 · 행별 SAVEPOINT →
**새 연결로 재확인**(COMMIT 반환값을 믿지 않는다) → `금지적중()` 9케이스 전/후 대조(전부 기대와 일치) →
되돌리는 SQL 5줄 출력. 스크립트 `_적용_룰수정_ai-c5.py`(dry-run 기본).
**캐시**: v7(`_설정_해시` = 판정컬럼 내용해시, 리비전 00012)이 배포돼 있어 자동 무효화된다.

### 잃는 것 — 적어 둔다
예외단서를 붙이면 **진짜 위반자도 즉답을 잃는다**(「가입 의무가 있는데 미가입」이 이제 통과).
🔴 그래도 이 방향이 맞다 — **오답 비대칭**이다. 놓친 불가는 정상 경로로 내려가 다시 판단된다.
**즉답을 놓치는 것이지 판정을 놓치는 게 아니다.**

## 3. 원인 — 두 갈래로 갈라 세야 한다

**㉠ 불가를 못 낸다 — 매칭 결함 셋**
- ⓐ **긴 핵 미적중**: 무조건 금지예시의 80%가 10자 이상, 20자+ 가 58건
  (47자: 「사업계획 이행 관련성이 낮은 GPU 등 … 100만원 이상 부품의 다량 구매」). 사용자가 그렇게 안 쓴다
- ⓑ **짧은 핵 과적중**: 「사무실 관리비」(7자)가 월세+관리비 혼합 질문을 통째로 닫는다
- ⓒ **부연 열거 품목 소실**: 「차량(승용차·화물차·이륜자동차 등) 임차 경비」의 핵은 `차량 임차 경비` 라
  **「화물차 임차」가 미적중**이다. 사용자는 상위어가 아니라 구체 품목을 쓴다

**㉡ 가능을 못 낸다 — 값을 못 읽어 판정을 유보한다**
- rule 477 실측: `_한도전수()` 가 `미파싱한도()` 로 잡아 `{'초과': None}` → **«이내» 를 영영 못 말한다**
- W2 6문항: 원문상 명시 허용인데 룰은 전부 조건부(원인 서술 = 사전승인 상시 True + 한도 미구조화)
- 🔴 **㉡의 두 발견을 한 원인으로 합쳐 부르지 마라.** 겹치는 건 «한도 미구조화» 한 축뿐이고
  「사전승인 상시 True」는 W4 사업에서 확인되지 않았다

**㉢ TIPS 는 ㉠㉡ 어느 쪽도 아니다** — 룰이 0행이라 판정이 통째로 LLM 에 넘어간다. **모수를 갈라 세라.**

## 5. 방법에 대해 — 이번에 값을 한 것

- 🔴 **닻 2개가 갈리면 안 고친다.** 값뿐 아니라 **원인 진단**도. 실제로 두 번 막았다 —
  439 오탐, 그리고 440 의 «복사 오진»(그대로 갔으면 정확한 예비 430 을 망가뜨렸다)
- 🔴 **기계 스캔이 0건이라고 결함이 0건이 아니다.** W3 의 전수스캔이 1차에 450 을 **못 찾았다** —
  L1 의 «가장 엄한 문장»(키워드 3/3)이 예외단서를 가진 L2 문장(2/3)을 덮었다.
  임계 이상 «모든» 문장을 보게 고친 뒤에야 나왔다. 후보 37 중 진짜는 5, 놓친 진짜는 2
- 🔴 **양식이 조문보다 강한 닻일 때가 있다.** [양식 제7호] 사전 승인·검토 요청서에
  「□ 3. 차량… 임차」 체크박스가 있다 = **기관이 승인 대상으로 취급한다**는 증거다.
  조문 해석은 갈리지만 양식은 안 갈린다
- 🔴 **문서가 같아도 조가 다르면 대상이 다르다.** 초기창업 제16조는 «주관기관» 인건비 조라
  창업기업 룰 440 의 근거가 못 된다(내가 근거로 지정했다가 정정됐다)
- 🔴 **근거 등급과 적용 가능 여부는 다른 축이다.** 453 은 근거가 A로 올라갔지만 칸이 조건을 못 담아
  적용 불가다. 안 가르면 「근거가 강해졌으니 고치자」로 읽힌다
