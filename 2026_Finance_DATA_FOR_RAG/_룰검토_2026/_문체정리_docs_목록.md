## 세는 기준

| 항목 | 기계 판정 |
|---|---|
| 기호 | `«` `»` `「` `」` 개수 합 |
| 🔴 | 문서당 3개까지. 초과분만 문제로 센다 |
| 긴단락 | 표·코드·목록·인용을 뺀 평문이 4줄 이상 이어지는 덩이 |
| 긴문장 | 70자 넘는 문장 비율. 20% 넘으면 문제 |
| 작업량 | 기호 + (🔴−3)×2 + 긴단락×3 + (긴문장>20%)×10 → 40↑ 상 · 15↑ 중 · 그 밖 하 |

줄수는 참고만 한다. 100줄 상한은 `docs/` 규칙이라 별건으로 따로 본다.
