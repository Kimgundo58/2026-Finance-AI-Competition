# 룰 검토 — 예비창업패키지

예비창업패키지에 적용되는 룰 19행을 규정 원문과 하나씩 맞춰 본 결과다.
정확 4행, 고쳐야 할 것 6행, 룰이 아예 없는 경우 5가지가 나왔다.
룰 데이터는 한 행도 고치지 않았다. 제안만 적는다.

이 문서는 구조 진단(1~2절), 행별 판정(3~5절), 정답셋 대조(6~7절)로 나뉜다.
결론만 볼 사람은 3절과 6절을 보면 된다.

## 1. 사전 조건과 용어

원본은 두 가지다. 둘 다 판독 품질이 좋아 인용 신뢰는 전부 A다.

1. 예비창업패키지 세부관리기준(2025년)
2. `L1_중소기업창업_지원사업_통합관리지침_제14차개정_20251223`

세부관리기준은 옛 판인 제13차 조번호로 지침을 부른다.
룰의 근거는 이미 제14차 번호로 맞춰져 있어 판본은 맞다.

용어 두 가지를 먼저 푼다.

- `금지예시` — 룰 한 행에 달린 금지 품목 목록
- `금지적중()` — 사용자가 적은 품목이 그 목록에 걸리는지 보는 함수. 걸리면 LLM 없이 불가를 낸다

## 2. 불가를 말하는 자리

아래는 그 함수들을 실제로 돌려 잰 값이다. 측정일은 2026-09-04다.

| 잰 것 | 값 |
|---|---:|
| 조회 범위 행. L1 공통 9 + L2 예비 10 | 19 |
| 허용 칸 분포. 조건부 · 가능 · 불가 | 18 · 1 · 0 |
| 금지예시 총계 | 67 |
| 예외 단서가 붙어 즉답 대상이 아닌 것 | 8 |
| 즉답 대상 | 59 |
| 즉답 대상인데 핵이 14자 넘어 거의 안 걸리는 것 | **46** |
| 즉답이 실제로 도는 것 | **13** |

허용 칸에 불가가 0인 건 룰 한 행이 비목 하나를 통째로 맡기 때문이다.
비목 전체가 불가인 비목은 없으니 0이 맞다.
진짜 문제는 매칭이다. 불가를 말할 단어는 있다. 그 단어가 조문 한 구절 통째라 안 걸린다.

룰은 금지예시를 층과 무관하게 합쳐서 본다. 근거는 `rule_lookup.py:812,849`다.
그래서 L2 예비 행에 없어도 L1 행이 받쳐 준다. 실제로 그런 자리가 있다.

| 품목과 용도 | 비목 | 즉답 결과 |
|---|---|---|
| 책상 · 사무실에 놓을 책상 구매 | 기계장치 | 적중 없음 |
| 사무용 집기 · 사무실 집기 구매 | 기계장치 | 적중 없음 |
| 기프티콘 · 박람회 방문객 배포용 | 광고선전비 | 적중. rule 434 |
| 성공보수 · 특허 등록 성공보수 | 특허권등 | 적중. rule 429 |
| 보증금 · 사무실 임차 보증금 | 지급수수료 | 적중. rule 422, L1 행 |
| 순금 · 도금용 순금 구매 | 재료비 | 적중 없음. 예외 단서가 정상 동작 |

읽는 순서는 이렇다.

1. 보증금은 L2 행에 없는데 L1 rule 422로 걸렸다. 합집합이 실제로 구제한다
2. 그런데 책상과 사무용 집기는 L1 rule 419에 금지예시가 3건 있는데도 안 걸린다
3. 핵이 `사무용 공간에 들어가는 집기`로 15자라 품목과 정확히 같지 않다
4. 사용자 문장에 그 구절이 통째로 들어 있지도 않다

🔴 그래서 결함은 표기 쪽이다. 고칠 자리는 금지예시의 핵이다.
근거는 지침 제39조② 원문이다.

> 사무용 공간에 들어가는 집기, 가구, 기구 등은 집행할 수 없으며, PC(노트북 및 태블릿PC 포함),
> 기본 운영체제(OS 포함), 사무용복합기 등은 반드시 해당 과제의 사업화 또는 경영활동과
> 직접 관련이 있는 경우에 한하여 구매할 수 있다.

창업진흥원 공식 답변도 같은 사안을 불가로 못박았다. `eval.golden_set` 세트 공식, 번호 별첨4-4다.

## 3. 행별 칸 검토

칸 판정은 허용 · 한도 · 사전승인 · 증빙 · 금지예시 순서다.
기호는 셋이다. ✔ 근거가 받쳐 준다, ✗ 근거가 없다, – 빈 칸이다.

| rule · 비목 | 칸 판정 | 결론 |
|---|---|---|
| 426 재료비 | ✔ · – · ✔ · ✔ · ✔ | 정확. 사전승인 적용 범위 표기만 없다 |
| 427 외주용역비 | ✔ · ✔ · ✔ · ✔ · △ 3/8 | 수정필요 |
| 428 기계장치 | ✔ · ✔ · ✗ · ✔ · △ 1/6 | 수정필요. 제39조④는 사전검토를 요구한다 |
| 429 특허권등무형자산취득비 | ✔ · – · – · ✔ · ✔ | 정확 |
| 430 인건비 | ✔ · – · ✔ · ✔ · ✔ | 정확 |
| 431 지급수수료 | ✔ · ✔ · – · ✔ · △ 2/10 | 수정필요. 한도는 멘토링 30만원 하루 |
| 432 여비 | ✔ · ✗ · ✔ · ✔ · ✔ | 수정필요. 제43조④가 등급 상한을 정한다 |
| 433 교육훈련비 | ✔ · – · – · ✔ · ✔ | 정확 |
| 434 광고선전비 | ✔ · – · ✗ · ✔ · △ 4/5 | 수정필요. 제45조②가 제38조를 준용한다 |
| 435 창업활동비 | △ · ✔ · – · ✔ · – | 수정필요. 한도는 월 50만원. 5절 참조 |

금지예시 n/m은 근거 조문이 담은 금지문 m개 중 룰이 옮긴 것이 n개라는 뜻이다.
근거 목록이 실제 출처보다 짧다. 금지예시와 증빙은 지침 제47조와 제49조에서도 온다.

## 4. 불가를 못 내보내는 자리

🔴 이 목록은 오늘 적용하지 않는다. 부분배제 표식이 먼저다. `docs/5_룰/5-1` 5절 미결 1번이다.
핵을 짧게 하면 반대로 너무 잘 걸려서, 일부만 빼야 할 지출을 통째로 막는다.
월세와 관리비가 섞인 질문에 `사무실 관리비` 7자가 즉답 불가를 낸다. 정답은 조건부다.
오늘 실제로 고치는 룰은 rule 440 하나뿐이다.

| 비목 · rule · 조번호 | 원문 | 제안 |
|---|---|---|
| 기계장치 428 · 제39조② | 사무용 공간에 들어가는 집기, 가구, 기구 등은 집행할 수 없으며 | 핵을 품목으로 분해 |
| 외주용역비 427 · 제38조⑩ | 시제품의 시금형을 제작할 수 있으나 양산목적의 금형제작비는 집행할 수 없다. | `양산목적 금형제작비` |
| 외주용역비 427 · 제38조⑨ | 외주용역업체에서 일부 과업을 재하청하는 경우는 사업비를 집행할 수 없으며 | `재하청` |
| 외주용역비 427 · 제38조⑧ | 창업기업등의 귀책사유로 인한 용역계약 파기 시에 발생하는 위약금 및 손해배상금, 지체상금 등은 사업비로 집행할 수 없다. | `위약금` · `손해배상금` · `지체상금` |
| 지급수수료 431 · 제42조⑧ | 보증금 및 관리비는 집행할 수 없다. | `임차보증금` · `관리비` |
| 지급수수료 431 · 제42조⑦1호 | 차량 등의 임차 경비는 집행할 수 없다. | `차량 임차료` |
| 지급수수료 431 · 제42조⑧2호 | 거주형태 공간의 임차료는 집행할 수 없다. | `거주형태 공간 임차료` |
| 광고선전비 434 · 제45조② | 광고 선전을 위해 외주용역을 진행하는 경우, 제38조(외주용역비)를 준용한다. | 사전승인 True |
| 여비 432 · 제22조②4호 | 여비는 지침 제40조에 따라 집행하며 대중교통은 일반석 등급 비용에 한하여 지출한다. | 한도 칸에 등급 상한 |
| 인건비 430 · 제41조⑧ | 일반건강진단 외 추가건강진단 비용은 사업비로 집행할 수 없다. | `추가건강진단비` |
| 기계장치 428 · 제39조④ | 사무용 소프트웨어(MS-Office, 한글, 백신 프로그램 등) 등의 범용성 소프트웨어는 원칙적으로 구매할 수 없으나 사업계획서 상의 제품을 제작 시 필요연관성이 높고, 전문기관의 장 또는 주관기관의 장의 사전검토를 얻은 경우 구매할 수 있다. | 사전승인 True |

광고선전비와 기계장치의 사전승인은 층 합집합이 OR로 묶어 구제한다.
다만 L2 행만 보는 경로는 틀린다.

## 7. 정답셋만 고치면 측정만 고쳐진다

규약④는 그 숫자가 한도인지 심의 임계인지 먼저 가르는 규칙이다.
사람이 정답셋을 쓰는 규칙이면서 룰 스키마 요구사항이기도 하다.
규정에 집행 불가라고 적혀 있는데 룰이 조건부를 돌려주면 그 뒤의 LLM은 이 규칙을 알 수 없다.

| 지침 제38조⑤의 두 숫자 | 성격과 판정 | 룰이 담는 자리 |
|---|---|---|
| 선금의 합계 금액은 전체 용역비의 50% 이하로 한다 | 한도. 초과분 불가 | `한도_유형='비율'`, 값 50 |
| 선급금이 500만원 이상일 경우, 선금보증보험증권을 제출해야 하며 | 임계. 조건부 | 없다 |

`docs/5_룰/5-1` 5절 미결 1번이 선결 조건이다. 룰 유형 18종 분기 스키마 건이다.
4절의 보류와 뿌리가 같다.
