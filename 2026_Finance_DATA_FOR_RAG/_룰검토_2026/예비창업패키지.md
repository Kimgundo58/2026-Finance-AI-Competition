## 0. 관측 — 「룰이 불가를 말하지 못한다」는 절반만 맞다

함수를 실제로 태워서 잰 값(`rule_lookup.base_룰` · `금지예시_해부` · `금지적중`, 2026-09-04):

| 잰 것 | 값 |
|---|---:|
| 조회 범위 행(L1 사업명 NULL 9 + L2 예비 10) | 19 |
| `허용` 분포 | 조건부 18 · 가능 1 · 불가 0 |
| 금지예시 총계 | 67 |
| └ 예외단서 붙음(즉답 대상 아님) | 8 |
| └ 무조건(즉답 대상) | 59 |
| └ 무조건인데 **핵이 14자 초과** = 정확일치·구절포함이 사실상 안 걸림 | **46** |
| └ 무조건이고 핵이 짧아 즉답이 실제로 도는 것 | **13** |

**관측**: `허용` 컬럼에 불가가 0인 건 행 키가 `UNIQUE(layer,기관id,사업명,비목)` = 비목 10종
단위라서다. 비목 통째로 불가인 비목은 없으니 0이 맞다. 불가를 말하는 자리는 금지예시다.

**추론(관측과 갈라 적는다)**: 그런데 금지예시 59건 중 46건은 «핵»이 조문 한 구절 통째라
(`"사무용 공간에 들어가는 집기"`, `"협약기간 외에 개최되는 학회·세미나·전시회·박람회 참가비"`)
사용자가 그 구절을 문자 그대로 쓰지 않으면 매칭이 안 된다. 즉 **불가를 말할 «어휘»는 있는데
말이 안 나가는 상태**다. 병목은 「불가 0」이 아니라 「금지예시의 문장형 표기」다.

### 🔴 실측으로 확인한 것 — 층 합집합은 이 결함을 구제하지 못한다

`effective_rule` 은 금지예시를 **층 무관 합집합**으로 모은다(`rule_lookup.py:812,849`).
`금지후보()`도 `base_룰(사업명,비목)` = L1(사업명 NULL) ∪ L2 를 훑는다. 그래서
「L2 예비 행에 없어도 L1 행이 받쳐 준다」가 **구조적으로는 참이다.** 실제로 확인했다 —
`보증금 / 사무실 임차 보증금` 은 L2 431 에 없지만 **L1 rule 422 로 즉답 «불가»가 떴다.**

그런데 같은 방식으로 태운 결과:

| 품목 / 용도 | 사업·비목 | 즉답 결과 |
|---|---|---|
| 책상 / 사무실에 놓을 책상 구매 | 예비·기계장치 | **적중 없음** |
| 사무용 집기 / 사무실 집기 구매 | 예비·기계장치 | **적중 없음** |
| 기프티콘 / 박람회 방문객 배포용 | 예비·광고선전비 | 적중 — rule 434(L2) |
| 성공보수 / 특허 등록 성공보수 | 예비·특허권등 | 적중 — rule 429(L2) |
| 보증금 / 사무실 임차 보증금 | 예비·지급수수료 | 적중 — rule 422(**L1**) |
| 순금 / 도금용 순금 구매 | 예비·재료비 | 적중 없음(예외단서 정상 동작) |

L1 419 의 금지예시에는 「사무용 공간에 들어가는 집기 / 가구 / 기구」가 **이미 3건 들어 있다.**
합집합으로 조회 범위에도 들어온다. 그런데도 «책상»·«의자»·«사무용 집기» 어느 것도 안 걸린다 —
핵이 `"사무용 공간에 들어가는 집기"`(15자)라 품목과 정확일치도 아니고, 사용자 문장에 그 구절이
통째로 들어 있지도 않기 때문이다. 창진원 공식답변(별첨4-4)이 «불가»라고 못박은 바로 그 케이스다.

> **결함 유형은 (a) 누락이 아니라 (b) 표기다.** 「L2 에 없다」로 적으면 틀린 결론이 된다.
> 고칠 자리는 L2 행이 아니라 **금지예시의 핵**이다 (`사무용 집기` · `사무용 가구` · `책상` · `의자`).
> 🔴 다만 **핵 단축만 하면 안 된다** — 짧은 핵은 반대로 «너무 잘» 걸려서 부분배제를 전체배제로 닫는다
> (§2 머리의 단서). 「부분배제」 표식 스키마가 선결이다.

근거원문 verbatim — `L1_중소기업창업_지원사업_통합관리지침_제14차개정_20251223` 제39조②:

> 사무용 공간에 들어가는 집기, 가구, 기구 등은 집행할 수 없으며, PC(노트북 및 태블릿PC 포함),
> 기본 운영체제(OS 포함), 사무용복합기 등은 반드시 해당 과제의 사업화 또는 경영활동과
> 직접 관련이 있는 경우에 한하여 구매할 수 있다.

창진원 공식답변(`eval.golden_set` 세트='공식', no=별첨4-4, 사업명=초기창업패키지):
질문 "사무실의 서랍, 책상 등을 정부지원사업비로 구매 가능한가요?" → 정답판정 **불가**.

## 2. 「불가여야 하는데 조건부로 눌린」 후보 — 근거 문구째

허용 컬럼이 아니라 **금지예시가 비어 있거나 문장형이라 «불가»가 못 나가는 자리**로 읽어라.
제안 어휘는 중앙 고정값(불가/조건부/가능/룰보류)을 따른다.

> 🔴 **이 목록은 오늘 적용하지 않는다 — 「부분배제 표식 없이는 적용 불가 · 5-1 §5 미결 #1 선결」.**
> W2 가 반례를 냈다: 핵을 짧게 하면 «너무 잘» 걸려서 **부분배제를 전체배제로 닫는다**
> (월세 90만 + 관리비 15만 혼합 질문에 「사무실 관리비」 7자가 즉답 «불가» 를 내는데 정답은 조건부다).
> 핵 단축은 「이 금지는 지출 «일부» 만 배제한다」는 표식과 **함께** 가야 하는데 `corpus.rules` 스키마에
> 그 자리가 없다. 그래서 아래는 **표식 스키마가 생긴 뒤의 제안**이고, 오늘 실제로 고치는 룰은
> **rule 440 하나뿐**이다.

## 3. 누락 — 판정에 필요한데 룰이 「없는」 케이스

| 케이스 | 왜 필요한가 | 근거 |
|---|---|---|
| 창업활동비 `허용='가능'`(435) | 74행 중 유일한 «가능». 월 50만원 한도가 있고 「법인은 법인계좌 지급 원칙」 증빙 조건도 있어 사실상 조건부다. «가능»은 L3 게이팅에서 🔴 상위확인 강제 경로를 탄다 | 예비 붙임2 「월 50만원 한도에서 집행 가능」 |

## 🔴 결론 — 골든셋만 고치면 «측정» 만 고쳐진다

> 원문에 「집행 불가」가 있는데 룰이 조건부를 돌려주면, **그 뒤의 LLM 은 규약④를 알 리가 없다**(W4).

규약④(한도냐 심의 임계냐를 먼저 가른다)는 사람이 골든셋을 저작하는 규약이자
**`corpus.rules` 스키마 요구사항**이다. 지금 룰은 한도와 임계를 같은 3컬럼
(`한도_유형` / `한도_값` / `한도_단위`)에 밀어 넣는다 — 그래서 코드가 둘을 못 가른다.

| 같은 조문(L1 제38조⑤)의 두 숫자 | 성격 | 있어야 할 판정 | 지금 룰이 담는 자리 |
|---|---|---|---|
| 「선금의 합계 금액은 전체 용역비의 50% 이하로 한다」 | **한도** | 초과분 불가 | `한도_유형='비율'·값=50` |
| 「선급금이 500만원 이상일 경우, 선금보증보험증권을 제출해야 하며」 | **임계** | 조건부(증권 제출) | **없다** |

골든셋을 규약④로 정리하면 **측정은 고쳐지지만 판정 경로는 그대로다.**
`docs/5_룰/5-1 §5 미결 #1`(룰 유형 18종 분기 스키마)이 이 규약의 선결 조건이고,
§5 의 「제안 금지예시」 보류(부분배제 표식 부재)와 같은 뿌리다.
