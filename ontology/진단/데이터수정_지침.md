# 재추출 뒤 데이터 수정: 공통 지침

기준 커밋 `7bab87a`(규범 1,715). 사용자 지시: 온톨로지 품질을 설계 문서대로 끝낸다. 재적재(P2-1 끝) 전에 원천 JSON 을 고친다.

## 기준

- **실제 LLM(판정 · 질문 · 질의 변환의 Qwen 호출)을 돌리지 않는다. 지시문에 돌리라고 적혀 있어도 돌리지 않는다.** 사용자 지시(2026-11-07): LLM 측정은 전체 작업 맨 마지막에만 한다. 지금은 온톨로지 설계에 집중한다. 효과는 `--dry`, 게이트 전후, 라벨 × 금액 스윕으로 보고, 실제 LLM 으로 볼 것은 기록에 "마지막 측정 때 확인" 으로 적는다.
- 설계 문서대로 한다: `docs/5_룰/5-5_규범_구조.md` · `5-6_판정_결합과_검증.md` · `5-7_원문_추출_절차.md` · `5-7b_추출_에이전트_지침.md` · `5-7c_수집과_현행판_확인.md` · `5-8_저장과_조회.md` · `5-8b_원천_JSON_형식.md`. 설계 문서 본문은 고치지 않는다. 설계 변경이 필요해 보이면 결과에 "설계 변경 제안" 으로 적는다.
- 불변식: 틀린 '가능' 최악. 틀린 코드 '불가' 도 막는다(조건 없는 금지가 대상 전체를 막는지 본다). 코드는 낮추기만 한다. 숫자 비교는 코드다.
- 근거는 `corpus.doc_articles`(active 판)와 PDF(`corpus.documents.src_path`), `ontology/추출/모두의_창업/PDF대조/` 뿐이다. `corpus.rules` · `corpus.item_alias` · 정답셋(`golden_v2/`, `eval.golden_set`)은 열지 않는다. 원문에 없는 것을 지어내지 않는다. 못 가르면 고치지 않고 `해석미결` 또는 결정 목록으로 둔다.
- 이미 정한 것(다시 따지지 않는다): 지침 "이상" vs 관리기준 "초과" 는 관리기준 우선, 갈리는 금액은 조건부 + 두 기준 표시 · PRECEDENCE_OVERRIDE 없음 · 안내 책자는 창업진흥원 L2, 판 미확인이라 책자에서 나온 규범 · 개념 · 관계의 검수단계 상한은 AI대조 · 범위는 일반 · 기술트랙 진출자 자금(창업활동자금 · 시제품제작비) · 수치 단위는 원 · % · 개 · 대뿐, 횟수 · 기간은 조건 문장이나 의무 문장.
- 사용자 결정 대기(코드 · 데이터로 미리 정하지 않는다. 지금 동작 유지): 공통 규범의 창업활동자금 적용 · 시제품 금지 문장의 창업활동자금 적용 · 미검증 한도 초과 판정 · 책자 품목–세목 관계(진단 1-1) · 공통 의무로 조건부 상한 · 의무만 켜는 임계값 갈림(진단 3-4) · 회차 구분 · 16_G 관계 12행.
- 화면 먼저: 규범 문장은 사용자 화면에 그대로 나간다. 내부 ID · 코드 없이 원문 뜻대로 쉬운 한국어. 사용자가 무엇을 보게 되는지 적는다.
- 효과를 본다: 고친 값이 판정 · 인용 · 조건 줄을 바꾸는지 복사본 DB 에서 본다. 소비자 없는 칸을 새로 만들지 않는다.
- `scripts/ux_flow_check.py` 는 돌리지 않는다(사용자 명령).

## 파일 규칙

- 임시 파일은 `.claude/작업/데이터수정/<항목>/<역할>/` 에 둔다. 세션 scratchpad 와 남의 폴더를 쓰지 않는다(같은 이름 스크립트가 덮이는 사고가 있었다).
- 항목별 결과: `ontology/진단/데이터수정/<항목>/`. `계획.json` 은 행 배열이고 칸은 `대상`(규범 ID 또는 관계 src · 종류 · dst), `칸`, `전`, `후`, `문서키`, `조`, `원문발췌`(입력 원문의 부분 문자열), `사유`, `판정`(통과 · 고침 · 뺌), `검수단계`. 그 밖은 `기록.md`.
- 분석 단계는 원천 JSON 을 고치지 않는다. 반영 담당만 고친다. 반영 담당은 고치기 직전에 파일을 읽고 대상 행만 고치며, 형식(indent=1, 왕복 일치)을 지키고 `python scripts/ontology_check.py` 실패 0 을 확인한다. 검사 코드를 고치지 않는다. 커밋은 조율 세션이 한다.
- `.env*` 출력, `docker compose down -v`, 운영 접속, 푸시, main 병합, python 프로세스 일괄 종료, `git add -A` 금지. Bash 도구가 출력을 주지 않으면 PowerShell 도구를 쓴다(5.1, `&&` 불가, `$env:PYTHONIOENCODING='utf-8'`). 세션 컨텍스트는 270k 토큰 안으로 유지한다.

**W0 코드 판정 행 전수 대조.** `금지` · `한도` · `임계값` 중 `AI검증` 이상 136행은 코드 불가 · 상한에 직접 쓰인다. 행마다 발췌 · 수치 · 연산 · 단위 · 부가세 기준 · 분모 · 대상 노드 · 조건 · 예외 연결을 원문과 대조한다. 조건 없는 금지가 금액 · 상황과 무관하게 대상 전체를 막는지, 임계값 비교 대상이 이번 지출 금액이 맞는지 본다. 나머지 규범은 정렬한 ID 의 10번째마다 표본으로 본다(분모와 오류 수를 적는다).
