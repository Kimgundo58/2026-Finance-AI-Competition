## 쓴 방식

- 끝맺음은 이미 찬 금지 문장과 같은 합니다체. 내부 ID · 표 구분자 없음. 금액은 p29-1/금지/3 의 원문 「50만원 이하」 하나뿐.
- 책자 행은 「창업활동자금으로」 를 넣었다. 책자 품목 금지를 사업비 금지로 읽지 않게 하려는 것이고, 근거는 참고2-p27-1 「창업활동자금으로 구입할 수 있습니다」 등이다.
- 표의 「불가, ○○ 가능」 은 단서까지 적었다. 다른 쪽에 조건이 더 있으면 함께 적었다(아래 p29-1/금지/3).
- 원문발췌는 `발췌_포함` 으로 DB 본문과 대조했고 37행 + 보조 근거 전부 통과. 다른 위치에서 가져온 말은 `사유` 의 "보조 근거" 에 적었다. PDF 를 직접 열지 않고 `PDF대조/표복원` 과 DB 본문을 읽었다.
