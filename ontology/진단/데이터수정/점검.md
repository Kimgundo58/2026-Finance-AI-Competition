- 선급금 코드 불가의 발췌가 「계약 총액의 50%」(별지2 문장)로 바뀌었다. 대체 때 근거 3개를 합쳤고, `_발췌` 가 가장 긴 발췌를 고르기 때문이다(`scripts/ontology_gate.py:91`). 입력 칸 이름은 「용역비 총액」이다. 뜻은 같고 코드는 고치지 않았다.
- 미확인: 프론트가 판정 요청에 `사용일자` 를 넣는지(`server/models.py:110` 은 받기만 한다). 넣지 않으면 지난 기한 줄이 화면에 남는다. 프론트 저장소는 보지 않았다.
- 마지막 측정 때 확인: 2,000만 경계 「두 기준」 줄과 판단불가→조건부 60행이 실제 LLM 판정에 미치는 영향, 사무용 가구 · 갱신심사의 실제 판정, 창업활동비 화면의 지난 기한 줄.
- 독립 재확인: 이 실행 환경에는 별도 에이전트 도구가 없다. 위 관찰은 점검자 혼자 확인한 것이다(코드 줄 · DB 조회 · 실행 출력).
