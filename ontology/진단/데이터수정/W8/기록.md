## 남은 약한 시험 · 미검증

- **CQ-12-4**: 원문 말은 「보증금」(지침 제42조⑧)인데 복사본 `concept_labels` 에 정규화 `보증금` 행이 없다(이 세션 DB 조회). 원천 별칭 추가가 필요해 W8 범위 밖이다. 반영 담당 · 조율 세션 결정. 별도 에이전트 재확인 전.
- **CQ-12-6 동치**: 조문 부분은 이제 잡는다(변이 H). 「창업기업등 = 진출자」 동치를 읽는 조회 함수가 없어 시험하지 않았다. 함수를 새로 만들면 판정 경로 소비자가 없어 넣지 않았다.
- **CQ-12-3**: 두 표기의 정규화 키가 같아 별칭이 아니라 정규화를 시험한다(주장 「같은 세목」 은 두 표기 모두 확인).
- **CQ-09-1 상속**: `적용_규범` 이 `비목:창업/*` 를 경로와 무관하게 늘 넣는다(`ontology_lookup.py:154`). 시험은 대상 = `비목:창업/*` 와 상위 · 하위 · 범위를 본다.
- **A1 관찰(미검증)**: 한도 · 임계값 행의 `수치` 가 NULL 이면 `온톨로지_조회` 가 TypeError 를 낸다(이 세션 변이 실행에서 본 것). 원천 검사가 이런 행을 막는지, 운영 영향이 있는지는 확인하지 않았다. 별도 에이전트 검증 전이라 문제로 보고하지 않는다.
- **CI**: 새 사례는 복사본에서만 돌렸다. CI 잡 `ontology-db` 의 `CI_원문.json` 에 새 기대 조문(지침 제14차 제43 · 49조, 관리기준 제39조)이 있는 것은 확인했고, `문맥_구성` 호출이 import 하는 `orchestrate` 의 최상위 의존(psycopg · openai)은 `requirements-api.txt` 에 있다. CI 실행은 아직 안 했다.
- **실제 LLM**: W8 은 시험 코드만 바꿔 판정 경로 동작이 같다. LLM 으로 볼 것 없음. 마지막 측정 때 확인할 항목 없음.
