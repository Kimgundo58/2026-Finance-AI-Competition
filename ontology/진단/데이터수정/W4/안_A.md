## 3. 관계가 아니라 대상 칸으로 잇는 이유

지침은 "관계로 잇는다"고 적었는데, 지금 구조에서 관계로는 닿지 않거나 검사가 실패한다.

```
적용_규범 (scripts/ontology_lookup.py): 규범.대상 && (시작 노드 + 상위 경로 + 비목:창업/*)

방법 1 비목:창업/재료비 --상위--> 절차:사업비
  └─ 전체_검사 실패 OWL_불만족 (재료비와 그 아래 품목, 오류 14건: 사업비항목 ↔ 절차행위 AllDisjoint)
방법 2 절차:시제품제작@ --사용--> 비목들
  └─ 이미 있다. 레이블_목록만 읽고 적용_규범은 읽지 않는다. 더해도 도달 불변.
방법 3 규범.대상에 비목을 넣는다  ← 이 안
  └─ 전체_검사 통과(HermiT 포함), CQ 53/53 통과 (메모리 패치 하)
```

`/*` 행은 대상을 더하지 않고 **바꾼다**. 절차 노드를 남기면 `_공통_규범` 이 거짓이라 줄이 공통 칸이 아닌 기한 · 금지 · 해당시 칸으로 간다. 시뮬레이션으로 확인했다(더하기: 여비 100만원 기한 0 → 2 · 금지 0 → 1 · 해당시 1 → 2, 공통 18 그대로 / 바꾸기: 공통 18 → 22). 증빙 칸은 남아 노드 연결은 유지된다.

**설계 변경 제안(이 안에 포함 안 함).** 절차 노드를 따라가게 하려면 코드 수정이 필요하다. 절차로만 닿는 규범은 `경로밖_규범` 처럼 문맥 · 조건 문장만 내고 코드 불가에서 빼는 방식이 된다. 안 그러면 6절의 틀린 불가가 생긴다.

## 10. 미확인 · 결정 대기

- 실제 LLM 판정 영향: 미측정. 제안은 코드 판정을 바꾸지 않지만 문맥이 늘어 판정 LLM 출력은 달라질 수 있다.
- 「부채 상환」 + 창업활동비에서 제47조④/금지/1 이 안 나오는 원인: 미확인. 재료비 경로에서는 나온다.
- 인건비 · 교육훈련비 · 광고선전비를 프런트에서 고를 수 있는지: 미확인. `server/catalog._사업_비목` 은 10비목을 돌려주고 라벨 목록에서만 빠진다. 고를 수 있다면 코드 불가 없이 조건부로 나온다(규범 각 54 · 46 · 43행 닿음).
- 지침 제49조⑦ 재원 비율: 진출자의 자기부담 유무를 원문에서 확정하지 못해 사업 단위 절차로 뒀다.
- 데이터로 정하지 않은 사용자 결정: 공통 규범의 창업활동자금 적용, 회차 구분, 16_G 관계 12행.
- 범위 안 행을 W0 조건 칸으로 고치면 이을 수 있는 후보: 제47조④/금지/4 (W0 소관).
