## 내린 결정

1. **저장 위치 `ontology/용어풀이.json`**: 5-8 파일 표에 용어 파일 이름이 없다. 5-8 "저장소 `ontology/`" 에 두되 재추출이 쓰는 `공통_L1.json` · `모두의창업.json` 과 나눴다. `ontology_check.py` 는 사업키 파일만 읽어 영향이 없다.
2. **`term_id` 형식**: `용어:<용어>`, 사업 한정이면 뒤에 `@모두의창업`. 5-8b 개념 ID 규칙과 같다.
3. **출처 수준은 둘**: 6-5 에 정의된 것은 원문 정의와 `일반뜻` 뿐이다. 웹 자료는 쓰지 않았다(6-5 가 허용한 출처가 없다). 일반뜻 행의 근거는 그 말이 쓰인 문장이고, 풀이가 그 쓰임에 맞는지 검증자가 본다.
4. **검수단계는 전부 `AI초안`**: 검증자가 올린다. 값 목록은 진행상황 D1 대로 5-8 목록이다.
5. **후보 범위**: 확정표 칸이 주 출처이고, 6-5 가 출처로 든 질문 표본의 말(출원인 등)과 정의 조문의 말 12개를 더했다(지원서비스 · 사후평가 · 주관기관 자기부담사업비 · 창업기업등 자기부담사업비 · 중소기업 · 창업 · 신산업창업 · 예비청년창업자 · 공공기관 · 행정청 · 금품등 · 공공재정).
6. **제외 기준**: 코퍼스에 없는 말은 6-5 대로 뺐다(코드로 판단). 일상어 · 조각 · 문서표기는 작성 에이전트가 판단했고 애매하면 풀이를 쓰게 했다. 근거 경로에 나오는 지침 · 운영요령 · 세부관리기준 · 집행 가이드는 풀이를 썼다.
7. **공백 표기는 한 행**: 변형 칸은 소비자가 없어 만들지 않았다. P4-6 은 공백을 빼고 맞춰야 한다. 표에 없는 `사전 심의` 는 `사전심의` 행이 맡는다.
8. **CQ 사례 ID 는 `CQ-NN-M`**: 슬라이스 `S-*` 사례는 그대로 두었다. 근거 조문은 질문 칸에 적었다.
9. **CQ-03-3 은 제38조 경로로 썼다**: 원문상 제39조① → 지침 제49조① → 운영요령 제21조도 있으나 `근거_조문` 은 조문마다 경로를 하나만 남긴다(`scripts/ontology_lookup.py:309-313`, 길이가 같으면 먼저 본 경로). 그 경로의 앞부분은 CQ-12-6 이 본다.

## P4-6 에 넘길 것

- 6-5 표에 `일반뜻` 칸이 없다. 적재 때 칸을 둘지, 근거 칸 이름으로 구분할지 P4-6 에서 정한다. provenance 의 `owner_kind` 값도 새로 정한다.
- `rule_lookup._norm` 은 토큰 끝 조사를 뗀다. 실행 결과 `_norm('사전심의')` = `사전심`, `_norm('사전 심의')` = `사전심의` 다. 조문에서 용어를 찾을 때 이 함수를 그대로 쓰면 공백 표기가 갈린다. 노드 조회 영향은 재지 않았다.
- `concept_id` 는 2026-11-07 HEAD 원천의 개념 ID 를 가리킨다. 재추출로 ID 가 바뀌면 재적재 때 `ON DELETE SET NULL` 로 끊긴다.

## 못 한 것

- **재추출 30~37 의 새 후보**: 확정표가 아직 없어 수집하지 않았다. 재추출 뒤 후보 칸을 다시 모아 `용어후보.json` 과 비교한다.
- **CQ 기대 키의 한계**(형식을 새로 만들지 않았다):
  - CQ-05 승인 주체 · 시점, CQ-08 분모 · 지역 값: 기대 키가 없어 규범 ID 포함으로만 본다. 값 자체는 검증자가 원천과 대조한다.
  - CQ-10: L3 `concept_ids` 를 읽는 함수가 형식에 없다(`문맥_구성`, P4-5). L3 연결이 닿는 대상 · 상위 경로까지만 본다.
  - CQ-11: 시행일 · 개정 관계 기대 키가 없다. 문서키가 가리키는 활성 판에서 조문이 풀리는지만 본다. 개정 처리는 `scripts/ontology_revision_check.py` 가 본다.
  - CQ-12: 동치 관계 자체를 확인하는 키가 없다. 별칭 일치와 선언 조문 경로까지만 본다.
- **작성 중 임시 파일 충돌**: 병렬 작성 중 한 에이전트가 같은 임시 폴더의 파일이 다른 배치 내용으로 덮인 것을 보고 입력을 다시 읽었다고 알렸다. 기계 검사(후보 대조 · 발췌)는 통과했다. 풀이와 근거의 짝은 검증자가 908행 전부 봤다(아래).
