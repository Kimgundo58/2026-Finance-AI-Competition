# JSON 변환 기록 (1_재도전_본문_공통인용)

`scripts/extraction_to_json.py` 가 썼다(2026-11-08). 입력 `확정.md` · `입력_원문.md` · `입력_문서키.json` · `schema.json`, 원천 `ontology`, 재추출 아니오. 변환기는 판단하지 않는다. 다음은 `ontology_check.py` 다.

## 집계

```
확정표  개념 줄 11 (신규 6 · 기존 3 · 재사용 2) · 관계 줄 36 (상위 6 · 그 밖 30) · 규범 줄 75 (규범 75 · 근거 추가 0)
규범    확정 75 = 새 행 75 + 교체 0 · 근거만 합친 원천 규범 0
개념    신규 6 = 새 행 6 + 뺀 개념 0 + 원천에 이미 있던 것 0 · 근거 · 별칭만 합친 원천 개념 8
관계    상위 6 → 개념.상위 · 그 밖 30 → 새 행 30 · 근거만 합친 원천 관계 0
파일    공통_L1.json  개념 637→639 · 관계 630→633 · 규범 1072→1072 · 기존 줄을 바꾸지 않음 예
파일    모두의창업.json  개념 535→535 · 관계 215→215 · 규범 659→659 · 기존 줄을 바꾸지 않음 예
파일    재도전.json  개념 0→4 · 관계 0→27 · 규범 0→75 · 기존 줄을 바꾸지 않음 예
```
