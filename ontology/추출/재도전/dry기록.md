# 화면 경로 dry 기록 — 재도전성공패키지 (5-12 ⑦)

2026-11-08 조율 세션. 로컬 `suddoe_ontology`, 원천 커밋 6cef3a4 + 작업 트리(재도전 원천 반영, 커밋 전) 적재 뒤. `orchestrate.판정(dry=True, 기록=False)` 를 화면이 넘기는 인자(사업명 · 확정비목 · 확정세목 · 정규화결과 품목 · 금액 · 부가세 포함)로 부른다. 실제 LLM 호출 없음(정규화결과를 넘겨 정규화를 다시 쓰고, dry 는 판정 생성 직전에 끝난다). `판단불가` 는 dry 종료 표시이고 판정 결과가 아니다.

보는 것: 모델 호출 0, 프롬프트에 다른 사업 문서 표기 0, 코드 판정(금지 · 한도)이 LLM 없이 나는지.

## 읽는 법 (조율 세션, 같은 날 dry 로 확인)

- 「기장대행 수수료」 250,000원 × 1개월은 코드 판정 한도초과로 불가다. 코드판정 `월 250,000원 > 월 200,000원`, 발췌 「월 20만원 이내로 집행 가능하다」, 근거 경로 「재도전성공패키지 세부관리기준 제18조④」. 품목 글이 정식명과 같을 때만 풀린다(별칭은 글자 그대로 맞춘다).
- 「유니폼」 은 조건 있는 금지(일회성 무작위 홍보)라 코드 불가가 아니고 판정 LLM 경로로 간다. 프롬프트에 제21조① 원문 「일회성 무작위」 가 2번 들어간다.
- 「산업용 3D프린터」 는 이 사업 문서 표기가 1 이다. 재도전 확정표에서 기계장치를 다루는 조는 제20조(중고 거래)뿐이다. 문맥이 왜 이렇게 짜였는지는 보지 않았다(미확인).
- 명령에 없는 환경: `HF_HUB_OFFLINE=1`(임베딩 모델을 내려받지 않는다).

스크립트는 `.claude/` 아래라 저장소에 없어 같은 글을 아래에 둔다. 정규화결과에는 `품목` 을 넘긴다(orchestrate 는 `품목` 을 읽는다, `scripts/orchestrate.py:442` · `:775`).

```python
"""화면 경로 인자로 판정() dry 를 돌려 사업 조문 · 게이트 · 다른 사업 유입을 본다. 실제 LLM 없음. 저장소 루트에서 돈다.

  python .claude/작업/조율/사업_dry.py <사업명> "질문|비목|세목|금액|월수" ...
"""
import json, os, sys
from pathlib import Path
루트 = Path(__file__).resolve().parents[3]
sys.path[:0] = [str(루트 / "scripts"), str(루트)]
sys.stdout.reconfigure(encoding="utf-8", errors="replace")
사업 = sys.argv[1]
os.environ.update(SUDDOE_MOCK="0", SUDDOE_ONTOLOGY_PROGRAMS=사업)
import orchestrate as O
s = json.loads((루트 / "ontology/schema.json").read_text(encoding="utf-8"))
표시 = s["문서 표시명"]
다른 = [(k, s["문서키"][k]) for k, v in s["문서사업"].items() if s["사업키"][v] != 사업]
for 줄 in sys.argv[2:]:
    질문, 비목, 세목, 금액, 월수 = (줄.split("|") + [""] * 5)[:5]
    추가 = {"월수": int(월수)} if 월수 else {}
    정규 = {"품목": 질문, "품목명": 질문,   # orchestrate 는 "품목" 을 읽는다(orchestrate.py:442 · :775). 2026-11-08 도약 dry 에서 고침
"금액": int(금액) if 금액 else None, "용도": None, "비목후보": [{"비목": 비목, "신뢰도": 0.9}]}
    r = O.판정(질문, 사업명=사업, 확정비목=비목, 확정세목=세목 or None, 정규화결과=정규, 추가입력값=추가, 부가세구분="포함", dry=True, 기록=False)
    p = r.get("프롬프트") or ""
    글 = json.dumps(p, ensure_ascii=False) if not isinstance(p, str) else p
    print("===", 줄, "| 판정", r.get("판정"), "| 처리", r.get("처리단계"), "| 호출", (r.get("모델") or {}).get("호출수"), "| 프롬프트 글자", len(글))
    print("   이 사업 문서 표기:", 글.count(표시.get(next((k for k, v in s["사업키"].items() if v == 사업), ""), "없음")),
          "| 다른 사업 문서:", {k: 글.count(d) + 글.count(표시.get(k, "@@")) for k, d in 다른})
    print("   조건:", json.dumps(r.get("조건") or r.get("요구조건") or r.get("화면칸") or "", ensure_ascii=False)[:260])
```
