# 조:재도전#제15조②표-2

- 출처: PDF 5쪽 위. 이 쪽만 글자 층이 있으나 쪽 번호와 빈칸뿐이다(`- 5 -` 와 NBSP). 표 글자는 이미지(220dpi)로 봤다. 표 글자는 파란색이다.
- DB 값: `인건비: 월 인건비 x 참여율(최대 100%) x 협약기간 / 임차료: 월 임차료 x 협약기간 / 기자재: 취득가액의 10% 또는 장부상 잔존가치액` 한 줄.
  - 셀 풀림: `:` 3개 · `/` 2개는 PDF 에 없다.
  - 누락: 머리글 행 「구분」 · 「산출 기준」(공백 뺀 6자)이 DB 에 없다.
- 병합 칸: 없음. 곱셈 기호는 PDF 대로 라틴 `x` 다.
- PDF 에 없는 글자: 표 기호 `|` · `---` 뿐이다.
- 검사: 위 `build_restore.py` 의 다중집합 비교. 복원에만 있는 글자는 머리글 6자다.

```
< 표-2. 창업기업등 현물 산출 기준 >

| 구분 | 산출 기준 |
|---|---|
| 인건비 | 월 인건비 x 참여율(최대 100%) x 협약기간 |
| 임차료 | 월 임차료 x 협약기간 |
| 기자재 | 취득가액의 10% 또는 장부상 잔존가치액 |
```
