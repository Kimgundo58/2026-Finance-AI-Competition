## 구현 결정 (문서에 없어 안전한 쪽으로 정한 것)

- 공무원 여비 규정은 인용된 별표1 만 넣었다. 제2호의 금액은 별표2(국내 2,593자) · 별표4(국외 5,738자)에 있으나 재도전이 직접 인용하지 않았다. 금액표가 없으면 숙박비 한도를 수치로 못 적고 「공무원 여비 규정 제2호 기준 확인」 조건이 된다. 판정이 「가능」 대신 「조건부」 로 내려가는 쪽이다.
- 지침 인용은 14차 조를 그대로 dst 로 쓴다(번호 대응 없음).
- 범위 밖 제12조도 블록 ID 가 겹쳐 복원본에 넣었다(예비와 같다).
- 조문 순서는 PDF 대로(제31조 → 제30조[2] → 부칙)다. 입력 명세 순서로 정한다.
- 묶음은 하나다. 범위 전체와 공통 인용을 합쳐도 10,818자로 14,000자 미만이다. 더 묶을 재도전 조가 없다.
- 시행일 마이그레이션은 쓰지 않았다. 로컬 DB 에 이미 같은 값이 있다(`PDF대조/차이목록.md`).
