   └ 본문 주관기관 조 14개 4,658자 뺌 → 범위 안 20조 11,880자

## 구현 결정 (문서에 없어 안전한 쪽으로 정한 것)

- 지침 인용은 14차의 같은 제목 조를 dst 로 쓴다. 13차는 superseded 이고 schema 에 없다. 효력 있는 판에 잇는 쪽이다. 근거 발췌는 원문 표기(「지침 제45조」)를 그대로 둔다. 13차 · 14차 본문 차이는 대조하지 않았다.
- 범위 밖 본문 조도 차이가 있으면 복원본에 넣었다(모두의 창업과 같다). 추출하면서 범위를 다시 볼 때 쓰인다. 붙임1 은 모두의 창업 별지1 처럼 넣지 않았다(소비자 없음).
- 붙임2 복원은 표를 다시 쓰지 않고 `별지_행` 으로 DB 행을 풀었다. 판정 때 같은 함수가 DB 본문에서 행을 풀기 때문이다(`표복원/예비#붙임2.md`).
- 두 묶음 모두 14,000자 미만이다. 예비 범위 전체가 11,880자이고, 공통 인용은 지시대로 따로 두었다. 고정비(약 $6, 한쪽만 확인)는 시험에서 다시 본다(5-12).
