# 초기창업패키지 세부관리기준: 추출 범위

2026-11-08. 문서 doc_id `초기창업패키지 세부관리기준(2025년)`(로컬 `suddoe_ontology`, L2 active, 시행 2025-07-02, `PDF대조/차이목록.md`). 사업키 · 문서키 `초기`.

**기준** (모두의 창업 묶음 A · 예비와 같음, 5-12 · 5-7): 사업비를 쓰는 창업기업 · 대표자의 지출에 닿는 조는 넣는다. 주관기관(초기는 운영사 포함)의 사업비 · 운영 · 평가 · 선정 절차만 다루는 조와 주관기관 붙임은 뺀다. 애매하면 넣는다. 조를 쪼개지 않는다.

## 상한 확인

```
전체 36조 19,410자 (DB 본문 글자)
└ 붙임1(주관기관) 2,418자 뺌 → 16,992자 = 5-12 표 「붙임 · 서식 뺀 글자」 (같음)
   └ 본문 주관기관 · 운영사 조 17개 5,396자 뺌 → 범위 안 18조 11,596자
      └ 추출 입력(복원본 적용) 77블록 11,382자   ← 쪽 번호 · 장절 표제를 빼고 표를 MD 로 다시 써서 줄었다
```

상한 16,992자보다 5,396자(32%) 적다. 5-12 의 「더 줄어든다」 가 초기에서도 맞았다. 셈: `ontology/.tmp_api/P1_초기/scope_count.py`(임시, `ontology_input.블록_만들기` + 복원본, 파일 쓰기 없음).

## 인용 조

범위 안 조가 다른 문서를 인용한 곳 전부(DB 본문을 읽고 「지침 · 운영요령 · 법 · 시행령 · 공고」 표기를 찾음). 공고 위임은 없다(붙임2 「공고·기구」 는 공구의 오탈자). 대조 코드 `ontology/.tmp_api/P1_초기/cited.py`(임시, 읽기 전용): `공통_L1.json` 의 개념 · 관계 · 규범 근거와 규범 ID 에 나온 `조:<문서키>#<조>` 206개, 예비 입력 명세(`ontology/추출/예비/*/입력_명세.json`) · 모두의 창업 입력 명세의 조와 맞춰 봤다. 결과 `cited_out.json`.

**지침 판:** 초기 제1조의 「창업사업화 지원사업 통합관리지침」 은 13차(2025-02-05, 로컬 superseded) 이름이고, 인용 번호도 13차 조 제목과 맞는다(DB 조제목 대조). schema `지침` 은 14차(2025-12-23)라 같은 번호가 다른 조다(14차 제21조 = 협약의 체결, 제44조 = 교육훈련비). 13차 → 14차는 조 제목으로 대응시켰다. 본문은 13차 제13조③ = 14차 제11조③, 13차 제44조 ① · ② · ⑤ = 14차 제48조 ① · ② · ⑤ 첫 줄만 같음을 봤고 나머지 조 본문 차이는 안 봤다. **제2조 호 번호도 다르다**: 13차 6호 총괄기관 = 14차 7호(8호 전문기관 · 9호 주관기관은 같은 번호). 확인은 이 세션 하나뿐이고 별도 에이전트 검증은 하지 않았다.

## 구현 결정 (문서에 없어 안전한 쪽으로 정한 것)

- 지침 인용은 14차의 같은 제목 조를 dst 로 쓴다(예비와 같다). 13차는 superseded 이고 schema 에 없다. 근거 발췌는 원문 표기(「지침 제45조」)를 그대로 둔다. 제2조 호는 14차 번호(7호 총괄기관)로 잇는다.
- 범위 밖 본문 조도 차이가 있으면 복원본에 넣었다(예비와 같다). 붙임1 은 넣지 않았다(소비자 없음).
- 붙임2 복원은 표를 다시 쓰지 않고 `별지_행` 으로 DB 행을 풀었다(`PDF대조/표복원/초기#붙임2.md`).
- 묶음은 하나다(11,596자, 14,000자 미만). 범위 안 글자 전부가 14,000자에 못 미치고 넣을 공통 인용 조가 없다. 다른 사업과 묶지 않았다(사업키가 다르다).
- 마이그레이션은 읽기 확인만 했다(쓰기 시험 없음, 공통 규칙 「쓰기는 지시받은 것만」).

## 설계 변경 제안

- 5-12 ② 의 `인용대응` 에 **호** 번호도 적는 안: 초기는 제2조 호 번호까지 다르다(13차 6호 → 14차 7호). 조 단위 대응만으로는 호가 틀린다. (인용대응 자체는 5-12 ② 에 이미 있다.) 판: 도약 · 창업중심대학은 13차, 재도전 · 초격차는 14차를 인용한다(조율 세션 DB 조 제목 대조, 2026-11-08).
