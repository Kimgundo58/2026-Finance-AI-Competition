# 초격차 스타트업 프로젝트 세부관리기준: 추출 범위

2026-11-08. 문서 doc_id `초격차 스타트업 프로젝트 세부관리기준(제10차)`(로컬 `suddoe_ontology`, L2 active, `version` 제10차, 시행일 NULL). 판 표기는 표지 개정 2026-03-06, 부칙 시행일은 빈칸(`PDF대조/차이목록.md` 「시행일 · 판」). 사업키 · 문서키 `초격차`.

**기준** (모두의 창업 묶음 A · 예비와 같음, 5-12 · 5-7): 사업비를 쓰는 창업기업 · 대표자의 지출에 닿는 조는 넣는다. 주관기관의 사업비 · 운영 · 평가 · 선정 절차만 다루는 조와 주관기관 참고 · 서식은 뺀다. 애매하면 넣는다. 조를 쪼개지 않는다.

## 상한 확인

```
전체 35조 45,720자 (DB 본문 글자)
└ 참고1 · 4(주관기관) 4,634자 뺌 → 41,086자 = 5-12 표 「붙임 · 서식 뺀 글자」 (같음)
   └ 본문 주관기관 · 선정 조 6개(제4 · 6 · 7 · 12 · 13 · 17조) 1,281자 뺌 → 범위 안 27조 39,805자 (DB)
      └ 추출 입력(복원본 적용) 82블록 24,318자
           ← 참고6 행의 양식 제1~10호 13,193자 · 참고5 행의 참고4 표 1,105자 · 참고2 · 3 의 평문 중복
             · 쪽 번호 · 장 표제를 빼고 표를 MD 로 다시 써서 줄었다
```

상한 41,086자는 DB 행 글자라 양식 · 중복이 들어 있다. 실제 추출 입력은 24,318자로 상한보다 16,768자(41%) 적다. 5-12 의 「더 줄어든다」 가 초격차에서 맞았다. 블록 · 글자는 `ontology_input.블록_만들기`(복원본 적용, DB 쓰기 없음)로 셌다(`ontology/.tmp_api/P1_초격차/count.py`).

## 공고 위임

- **제18조②2호**: 현물 기자재는 「취득가액 또는 잔존가치액 이내에서 최초 선정 공고문상에 명시된 비율에 따라 인정」. 공고 위임이다. 다른 범위 안 조 · 참고에는 공고 위임이 없다(DB 본문 「공고」 검색: 장 제목 · 이 호 · 참고2 `공고·기구` 오탈자뿐).
- 폴더의 미적재 공고 `2026년 초격차 스타트업 프로젝트(DIPS) 창업기업 모집공고(기술분야별 주관기관 수록).hwpx`(중소벤처기업부 공고 제2025-661호, 2025-12-29, sha256 앞 12자 3ea63475cd39) 본문에 `★ 현물(보유한 기자재 등)은 공고일 기준 잔존가치액 혹은 구입금액의 20%로 계상` 이 있다(HWPX 글자 읽기, 읽기 전용).
- 「최초 선정」 공고라 선정 연도마다 다르다: 같은 폴더의 2025년 공고는 `잔존가치액 혹은 구입금액의 10%`, 2024년 공고에는 같은 문장이 없다(글자 검색).
- 공고는 DB 에 없어 `ontology_input.py` 입력이 될 수 없다. 이 호는 추출에서 조건 「최초 선정 공고 확인」 으로 두고, 공고 적재 · 추출은 조율 세션이 정한다(메모에 적음).

## 인용 조

범위 안 조가 다른 문서를 인용한 곳 전부(DB 본문 읽기). 대조 코드 `ontology/.tmp_api/P1_초격차/cited.py`(임시, 읽기 전용): `공통_L1.json` 의 개념 · 관계 · 규범 근거와 규범 ID 의 `조:<문서키>#<조>`, 예비 · 모두의 창업 입력 명세의 조와 맞췄다. 결과 `cited_out.json`.

**지침 판:** 초격차 제1조의 「중소기업창업 지원사업 통합관리지침」 은 14차(2025-12-23, schema `지침`) 이름이고, 인용 번호도 14차 조 제목과 맞는다: 참고2 재료비 `지침 제37조` = 14차 제37조 재료비(13차 제37조는 특허권), 제27조 `지침 제75조 및 제76조` = 14차 권리 의무 이전(13차에는 제75조가 없다), 제10조 `제22조 및 제25조` = 14차 협약의 변경. **예비와 달리 옛 판 대응이 필요 없다**(묶음 명세에 `인용대응` 없음). 운영요령 제11조(창업지원사업 예비위원)는 2024-101호 · 2026-82호 제목이 같다. 확인은 이 세션 하나뿐이고 별도 에이전트 검증은 하지 않았다.
