# JSON 변환 기록 (2_초격차_본문_공통인용)

`scripts/extraction_to_json.py` 가 썼다(2026-11-08). 입력 `확정.md` · `입력_원문.md` · `입력_문서키.json` · `schema.json`, 원천 `ontology`, 재추출 아니오. 변환기는 판단하지 않는다. 다음은 `ontology_check.py` 다.

## 집계

```
확정표  개념 줄 27 (신규 27 · 기존 0 · 재사용 0) · 관계 줄 64 (상위 6 · 그 밖 58) · 규범 줄 71 (규범 71 · 근거 추가 0)
규범    확정 71 = 새 행 71 + 교체 0 · 근거만 합친 원천 규범 0
개념    신규 27 = 새 행 25 + 뺀 개념 2 + 원천에 이미 있던 것 0 · 근거 · 별칭만 합친 원천 개념 2
관계    상위 6 → 개념.상위 · 그 밖 58 → 새 행 58 · 근거만 합친 원천 관계 0
파일    공통_L1.json  개념 653→662 · 관계 633→643 · 규범 1072→1087 · 기존 줄을 바꾸지 않음 예
파일    초격차.json  개념 10→26 · 관계 73→121 · 규범 249→305 · 기존 줄을 바꾸지 않음 예
```
