A 는 {L1, L2, unspecified_only} 로 맞게 적었고, B 는 /1 을 범위 all(L1 이 늘 이긴다)로 적고 같은 뜻을 /3 으로 따로 적었다. A 의 조건 값에 B 의 대상(비목:창업/*) · 예외(/3)를 더해 1차 줄과 같은 꼴로 두었다. 1차의 재추출 사유(두 추출 모두 all · 거꾸로 된 /2)는 풀렸다.
2. **제3조 우선순위/3 (일치 · AI검증).** A /2 · B /2 가 같고(L2 > L1 상충시, 「지원사업의 특성에 따라 달리 정하는 사항은 본 기준을 따른다」) 원문대로다. ID 는 1차대로 /3 이고 /2 는 비운다.
3. **제3조 준용 관계 2줄 (일치 · AI검증, 1차에 없던 줄).** A · B 모두 `미특정:요령` · `미특정:지침` 준용을 적었다. 원문이 조를 특정하지 않고 두 문서를 적용한다고 적어 입력 머리 대응표의 미특정 표기를 따랐다.
4. **1차 ID 규범:초격차/참고2/재료비/의무/3 → 규범:초격차/참고2/재료비/요건/3 (B 맞음).** 이번 A · B 모두 「단일 제품 가격 100만원」 을 임계값으로 적지 않고 조건에 두어 1차 재추출 사유(임계값/1)는 풀렸다. 종류는 A 가 의무/4, B 가 요건/4 다. 원문 「… 다량 구매하는 경우, 주관기관 전담인력의 검토 후 사업비 집행을 제한할 수 있음」 은 창업기업에 할 일을 정하지 않고 전담인력의 재량 제한을 판단 말(관련성이 낮은 · 다량)로 정한 것이라 요건이다. 같은 문장의 앞 갈래(재료 수량)는 1차에서도 요건/2 였다. 1차 ID 의무/3 이 변환 점검에서 「확정표에 없는 원천 규범」 으로 나오는 것은 예상된 실패다(조율 세션이 1차 확정표 행을 바꾼다). 100만원은 부품 한 개 단가라 수치 칸 · 구조화 조건에 넣지 않고 자연어 조건에 원문대로 두었다(조건이 있어 코드 불가에 쓰이지 않는다).
5. **요건/2 · 요건/3 (혼합).** 종류는 B(요건), 승인주체 주체:전담인력 은 B, 전제(「… 경우」)를 조건 · 조건근거로, 효과 발췌를 대상근거로 나눈 것은 A 의 칸 배치다. 1차 요건/2 는 조건 없이 두 발췌를 대상근거에 두었다.
6. **요건/4 (일치 · AI검증, 1차에 없던 규범).** A · B 모두 정의 문장 「사업계획서상의 사업화를 위해 소요되는 … 구매하는 비용」 을 요건으로 적었다. 1차 ID 요건/1~3 이 차 있어 다음 순번 /4 를 썼다.
7. **요건/1 (B).** 「구매하고자 하는 재료」 는 재료비로 사는 것 전체를 말해 대상은 비목:창업/재료비(B · 1차)다. A 는 품목:창업/재료 로 좁혔다.
8. **의무/1 (A).** 단서 「협약기간 … 내 납품이 완료되지 않은 경우 … 환수 조치 가능」 은 의무를 어긴 때의 제재라 결과.제재 다(A). B 는 따로 의무/2 로 적었다. A 가 조건에 둔 「협약기간은 … 간주」 는 규범을 좁히는 전제가 아니라 정의라 조건에 넣지 않고 문장과 대상근거, 1차의 정의 관계로 남겼다. 이번 A · B 는 그 정의 관계를 적지 않았으나 원문대로이고 1차에서 두 추출이 일치했으므로 1차 줄을 그대로 둔다. 기한일은 납품(사용) 기간 끝이라 쓰지 않는다.
9. **허용/1 (A).** 운반비는 입력_기존노드 의 세목:창업/지급수수료/운반비 를 재사용했다(A). B 의 품목:창업/운반비(신규)는 같은 뜻의 중복이고 상위가 없다. 허용이라 판정을 올리지 않는다.
10. **의무/4 (B).** 원문에 증빙 시점이 없어 시점을 뺐다(B). 1차 · A 는 집행 후 로 적었다.
11. **금지/2 (일치).** B 가 더한 구조화 조건 「비목 = 비목:창업/재료비」 는 5-7d 꼴이 아니고 이 문장에 없는 말이라 쓰지 않았다. 자연어 조건 「국외 기업과의 구매 거래 시」 가 있어 코드 불가에 바로 쓰이지 않는다(`scripts/ontology_gate.py:607`). 전수 대조 뒤(조율 세션 기록): 금지/2 는 조건 「재료를 국외 기업에서 구매하는 경우」 · 판정 수정 · AI대조 로 바뀌었다(../전수대조.md:17). 「재료」 전제는 재료비 칸이라는 위치에서 온 것이고 조건근거 발췌로 받치지 않는다.
12. **금지/1 · 의무/2 문장.** 금지/1 은 A · B 의 「재료비로」(1차는 「사업비로」), 의무/2 는 A 의 「꼭 필요한」 이 원문(「제작 필요 연관성이 높고」)을 넘어 1차 문장에 사업계획서 문구를 더해 고쳤다.
13. **개념.** 품목:창업/금속 · 컴퓨터부품 의 연결종류는 A 「문맥」 · B 「추론」 이 값 목록(원문명시 · 해석) 밖이라 1차의 원문명시(표 재료비 행 배치)를 둔다. 기존 개념(재료 · 원료 · 데이터)의 상위 줄은 원천에 상위가 있어 옮기지 않았다(1차와 같다). B 의 절차:특화지원 · 기본지원 · 후속지원@초격차 는 쓰는 규범이 없어 넣지 않았다(2_초격차_본문_공통인용 제2조에 같은 ID 가 있다).
