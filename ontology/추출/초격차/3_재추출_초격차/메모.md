# 재추출 메모 — 초격차

1_초격차_사업비 · 2_초격차_본문_공통인용 검증에서 다시 볼 2블록을 추출한다(5-12 ⑤, 1회).

초격차 스타트업 프로젝트 세부관리기준(판 표기 2026-03-06 개정, 부칙 시행일 빈칸). 사업키 · 문서키는 초격차다. 규범 ID 는 규범:초격차/<조문 키>/<종류>/<순번>, 조문 ID 는 조:초격차#… 이고 ontology/초격차.json 에 넣는다. 계층: 세부관리기준 L2, 요령 · 지침 L1.
블록: 제3조(적용범위) · 참고2 재료비(초격차 창업기업 사업비 집행기준 표의 재료비 행).
원문 사정: 참고2 블록은 복원본 ontology/추출/복원/초격차.json 블록을 썼다(입력 머리 `[원문결함]`). 블록 ID 는 /<비목> 이고 표 행이 비목 이름 칸 · 기준 칸으로 이어진다. 원문 오탈자는 고치지 않고 발췌한다.
인용: 지침 인용 번호는 14차 번호 그대로다. 「요령 및 지침」 처럼 조를 말하지 않는 인용은 입력 원문 머리 대응표대로 미특정 표기를 쓴다.
판은 사용자가 현행으로 정한 로컬 판이다(5-12).
