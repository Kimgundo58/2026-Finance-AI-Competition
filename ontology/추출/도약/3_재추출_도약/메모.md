# 재추출 메모 — 도약

1_도약_본문 · 2_도약_별지_공통인용 검증에서 다시 볼 5블록을 추출한다(5-12 ⑤, 1회).

창업도약패키지 세부관리기준(2025-06-09). 규범 ID 는 규범:도약/<조문 키>/<종류>/<순번>, 조문 ID 는 조:도약#… 이고 ontology/도약.json 에 넣는다. 계층: 세부관리기준 L2.
블록: 제10조(정부지원사업비 배정) · 제11조②(성공환원형 기본지원사업비) · 제29조①표-10(창업기업 사업비 구성 비율) · 제29조②(자기부담 현물 계상) · 별지서식/별지3/③(성공환원금 성실 납부 중 폐업 예시).
제29조 · 별지서식 블록은 복원본 ontology/추출/복원/도약.json 을 쓴다(표-10 은 MD 표). 별지3 은 제42조① 성공환원금 미납 환수의 예시 표다. 표 안 날짜 · 금액은 예시다.
용어: 「기본지원사업비」 는 성공환원형에 선정된 창업기업이 일반형 선정 시 배정받은 정부지원사업비다(제2조 6호). 「성공환원형」 은 일반형에 선정된 도약기 기업 중 정부지원사업비의 환원을 확약한 창업기업에 추가지원사업비를 지원하는 유형이다(제2조 3호). 「총사업비」 는 정부지원사업비 + 자기부담사업비(현금 · 현물)다(표-10).
판은 사용자가 현행으로 정한 로컬 판이다(5-12).
