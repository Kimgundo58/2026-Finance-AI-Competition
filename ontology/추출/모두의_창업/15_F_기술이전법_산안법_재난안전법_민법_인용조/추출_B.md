# 추출_B — 15_F_기술이전법_산안법_재난안전법_민법_인용조

입력 블록 12개를 조문 ID 순서대로 적었다. 규범은 L1 공통이라 계층 L1 · 적용사업 없음이고, ID 는 메모대로 `규범:공통/<문서키>#<조문>/<종류>/<순번>` 이다.
개념 표시: (기존) 은 입력_기존노드.json, (신규) 는 이 묶음에서 처음 나온 노드, (앞 항) 은 이 묶음의 앞 블록에서 이미 신규로 적은 노드다.
정의 관계의 방향은 `조문 -정의-> 개념` 으로 통일했다. 같은 조 안의 항 참조("제1항에 따라" 등)는 관계로 적지 않았다.
