PART 3 창업활동자금

| 구 분 | 내 용 |
|---|---|
| 지원 금액 | 진출자 1인당 200만원(부가가치세 포함) |
| 필수 여부 | 선택 사항(미사용 또는 일부 사용 → 평가에 반영 없음) * 단, 부적정 집행 시 감점 |
| 지원 방식 | 신한 클린 선불카드를 발급하여 200만원 충전 및 사용 |
| 사용 범위 | 창업 아이템의 사업화·고도화에 필요한 5개 비목 |
| 결제 수단 | 발급받은 선불카드로만 결제 가능 |
| 증빙 방식 | · 1건 10만원 미만 : 증빙 면제(카드 승인내역으로 갈음) · 1건 10만원 이상 : 건별 증빙 제출 · PG 결제 등 사용처 미확인 건 : 금액과 무관하게 건별 증빙 제출 필수 |
| 사용 기간 | 카드 충전일~11.30.(월) * 기간 종료 후 잔액은 소멸·회수 |

① [전용카드로만 결제] 개인 카드·계좌이체·현금으로 결제한 건은 별도로 지급되지 않습니다.
② [PG 결제는 반드시 증빙] 금액이 작더라도 온라인 결제는 주문상세내역서 또는 결제 완료 화면 스크린샷+실물·서비스 사진을 남겨 주셔야 합니다.
③ [50만원 초과 건 사전승인] 1건에 50만원 초과 건은 멘토기관의 사전승인을 받은 후 집행하여 주시길 바랍니다.
④ [사업자 지출증빙 사용 금지] 보유하신 사업자·법인의 지출증빙으로 처리하거나 부가가치세를 환급받으시면 환수 및 제재 대상입니다.
⑤ [창업활동보고서 제출] 성실히 작성하여 기한 내 제출하지 않으시면 이미 사용한 금액이 환수되고 참여가 제한될 수 있습니다.
