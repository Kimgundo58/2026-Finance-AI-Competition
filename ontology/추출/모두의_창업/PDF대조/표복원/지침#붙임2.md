【붙임 제2호】
(Ⅱ) 창업기업등 참여제한 및 사업비 환수조항

| 세부사유 | 참여제한 기간 | 사업비 환수 | 제재등급 |
|---|---|---|---|
| 가. 거짓이나 그 밖의 부정한 방법으로 정부지원사업비를 교부받거나 창업지원사업에 참여하여 수행한 경우 |  |  |  |
| 1) 거짓이나 그 밖의 부정한 방법으로 창업기업등이 자료를 허위, 위조·변조·표절로 작성 및 제출한 경우 | 5년 | 전액 환수 | - |
| 2) 창업기업등이 현물을 허위로 대응한 경우 | 3년 | 전액 환수 | - |
| 3) 창업기업등이 협약체결 이후에 신청 또는 선정 자격이 부적합으로 확인된 경우 |  |  |  |
| - 고의성이 있는 경우 | 1년 | 전액 환수 | - |
| - 고의성이 없는 경우 | - | 잔액 환수 | - |
| 나. 정당한 사유 없이 사업수행을 포기한 경우 | 1년 | 전액 환수 | - |
| 다. 정부지원사업비를 지급 목적과 다른 용도로 사용한 경우 |  |  |  |
| 1) 창업기업등이 고의로 정부지원사업비를 횡령, 편취, 유용 등 부정하게 사용한 경우 | 3년 | 전액 환수 | - |
| 2) 타 정부지원사업과 사업비를 혼용 또는 자기부담사업비로 활용하는 경우 | - | 해당 금액 환수 | 경고 |
| 라. 자료 및 사업결과물을 허위, 위조‧변조‧표절하여 제출한 경우 |  |  |  |
| 1) 사업신청부터 수행에 관한 일체의 자료 및 사업결과물을 허위, 위조‧변조‧표절하여 제출한 경우 | 3년 | 전액 환수 | - |
| 마. 창업기업등이 정당한 사유 없이 ｢보조금 관리에 관한 법률｣ 또는 ｢공공재정 부정청구 금지 및 부정이익 환수 등에 관한 법률｣에 따른 환수금 또는 제재부가금을 납부하지 아니한 경우 | 3년 | - | - |
| 바. 사업의 수행 과정 및 결과가 극히 불량하거나 사업목적을 달성하지 못한 경우 |  |  |  |
| 1) 협약기간 내 사업계획(창업 포함)을 이행하지 못한 경우 | 1년 | 전액 환수 | - |
| 2) 정당한 사유 없이 휴·폐업한 경우 | 1년 | 전액 환수 | - |
| 3) 정당한 사유로 과제 수행을 포기하거나 실패하는 경우 * 대표자의 사망, 천재지변 등 불가항력적이거나 정당한 사유로 사업계획 미이행 또는 휴·폐업한 경우 ** 전염병 등 국가 재난상황에 따른 영향으로 수행하고 있는 사업의 사업계획 미이행 또는 중단‧포기‧실패가 발생하는 경우 *** 기타 상기 항목에 준하는 사유로 창업기업등에게 귀책사유가 없는 경우 | - | 잔액 환수 | - |
| 사. 정당한 사유 없이 사업 관련 자료 제출·보고 요구에 따르지 않은 경우 |  |  |  |
| 1) 정당한 사유 없이 전문 및 주관기관의 점검·자료제출 요구에 응하지 않는 경우 | - | - | 경고 |
| 2) 보고서 등 서류제출을 정당한 사유 없이 2주 이상 지체하는 경우 | - | - | 경고 |
| 3) 주관기관의 서류제출 및 프로그램 참석요청에 불응하는 경우 | - | - | 경고 |
| 4) 협약기간 내 사업비의 복원 요청에 2주 이상 불응한 경우 | - | - | 경고 |
| 5) 주관기관의 장이 요청하는 각종 보고서에 대하여 기한 내에 제출하지 않는 경우 | - | - | 주의 |
| 6) 창업기업등 대표자가 2주 이상 연락 두절인 경우 | - | - | 주의 |
| 아. 창업지원사업에 참여한 창업기업등이 정당한 사유 없이 대표자를 변경한 경우 | 1년 | 전액 환수 | - |
| 자. 그 밖에 창업기업등이 협약에서 정한 사항을 위반한 경우로서 해당 사업을 수행하기 부적합하다고 인정하는 경우 |  |  |  |
| 1) 창업기업등 의무사항을 이행하지 않은 경우 |  |  |  |
| - 자산 유지관리 의무 기간 내 폐업 등으로 자산 유지관리 의무를 이행할 수 없는 경우 | - | 해당 금액 환수 | - |
| 2) 단순 착오, 지침 미숙지 등으로 사업비를 부적절하게 집행한 경우 |  |  |  |
| - 협약기간 내 단순 착오, 지침 미숙지 등으로 사업비를 부적절하게 집행한 경우 * 협약기간 이내인 경우 ‘해당금액 반납 및 적정용도로 집행가능’ | - | 해당 금액 반납 | 개선 요청 |
| - 협약기간 종료일 이후에 확인된 경우 | - | 해당 금액 환수 | - |
| 3) 그 밖에 해당 사업을 수행하기 부적합하다고 인정하는 경우 |  |  |  |
| - 협약기간 내 사업과 관련된 문제로, 형사 소추 또는 민사로 소제기된 경우 * 협약기간 내 무혐의 또는 소취하가 확정된 경우 잔여사업비 사용가능 | - | - | 일시 중단 |
| - 협약기간 내 금융기관으로부터 채무불이행 또는 국세‧지방세 체납 등으로 규제중인 경우 | - | - | 일시 중단 |
| - 전문기관 또는 주관기관으로부터 3회 이상 경고를 받은 경우 | 3년 | 전액 환수 | - |
| - 기타 사업운영위원회에서 사업 중단이 필요하다고 판단하는 경우 | - | - | 일시 중단 |

* 상기 항목 중, 둘 이상을 위반한 경우에는 참여제한 기간을 합산하여, 최대 7년까지 사업 참여를 제한

* 협약기간 내 제재 및 환수사유가 발생한 경우 ‘중단’, 협약기간 종료 후 제재 및 환수사유가 발생한 경우 ‘실패’ 처리

* 기타 사업운영위원회에서 창업지원사업을 수행하기 부적합하다고 판단하는 경우 참여제한 및 환수에 대해 사업운영위원회는 열거된 다른 사유와의 유사성과 위반의 경중을 판단하여 참여제한기간 및 사업비 환수 규모를 확정

* 주의 2회 = 경고 1회(협약기간 내)

* 정해진 기간 내 정부지원사업비 환수에 응하지 않을 경우, 채권추심 진행

* 창업기업등이 사업비 환수 통보를 받고 환수금을 반납하지 않을 경우, 채권환수 절차가 종결될 때까지 전문기관에서 지원하는 창업지원사업 참여를 제한하고 참여 중인 경우에는 사업비 집행을 중단
