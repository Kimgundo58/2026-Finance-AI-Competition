카드 발급개요

| 구 분 | 내 용 |
|---|---|
| 카드명칭 | 모두의 창업 창업활동자금 카드 |
| 사전준비 | 본인명의 국내 은행계좌 1개 보유 필요 (본인 인증수단으로 사용) |
| 명 의 | 진출자 본인 명의로 발급 * 미성년 진출자 : 법정대리인 명의 발급 후 별도 매칭 절차 필요 * 외국인 진출자 : 외국인등록번호 등 고유번호 입력 후 발급 가능 |
| 발급 방법 | 진출자에게 발송되는 알림톡·이메일 내 URL을 통해 직접 신청 → 사용 등록 → 등록 익일 충전 * (사용 등록) 신한카드 홈페이지 > [개인] 로그인 > 카드 > 카드 사용 등록 또는 신한카드 콜센터(1544-7000) |
| 잔액 조회 | 신한카드 앱 또는 고객센터를 통해 확인하실 수 있습니다. |
| 분실·훼손 | 신한카드 고객센터(1544-7000)에 분실 신고 후 재발급을 신청하시고, 멘토기관에 즉시 통보하여 주십시오. |

결제가 승인되지 않는 경우
- 카드사 자체 정책에 따라 결제가 거절될 수 있습니다. 아래 사유에 해당하는지 먼저 확인 하여 주십시오.

| 사 유 | 내 용 |
|---|---|
| 제한 업종 | 클린카드에서 자동 차단되는 업종입니다. (참고 1(25p)). |
| 제한 업종 | 자동 차단 업종 유흥·향락 유흥주점, 단란주점, 노래방, 안마시술소, 사우나 등 |
| 제한 업종 | 자동 차단 업종 사행성 카지노, 복권, 경마·경륜·경정, 도박 관련 업종 |
| 제한 업종 | 자동 차단 업종 주류·담배 주류 및 담배 판매업 |
| 제한 업종 | 자동 차단 업종 환금성 업종 귀금속·금은방, 상품권 판매점, 전당포 |
| 제한 업종 | 자동 차단 업종 부동산·금융 부동산 매매, 대출·보험 등 금융상품 |
| 제한 업종 | 자동 차단 업종 기 타 골프장, 총포류 판매 등 지침상 제외 업종 |
| 제한 업종 | ※ 차단 업종의 구체적 범위는 가맹점의 업종 등록에 따라 결정됩니다. 같은 품목이라도 개별 가맹점의 등록 업종에 따라 결제 가능 여부가 달라질 수 있습니다. |
| 해외 결제 | 국내 전용 카드이므로 해외 가맹점 결제 및 외화 결제는 승인되지 않습니다. 해외 사업자의 서비스라도 원화로 결제되는 경로(국내 인앱결제, 국내 결제대행, 국내 총판·리셀러)를 이용하시면 결제가 가능합니다. |
| 취소수수료 발생 건 | 철도·고속버스·항공·공연 예매 등 취소 시 수수료가 부과되는 결제는 선불카드 이용약관 상 승인되지 않습니다.(현장 결제 포함). |
| 잔액 부족 | 충전 전이거나 잔액이 결제금액보다 적은 경우입니다. |
