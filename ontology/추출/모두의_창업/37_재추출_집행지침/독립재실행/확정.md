# 확정 추출표 — 37_재추출_집행지침 독립 재실행 (묶음 21 재추출, 검증자)

입력: 이 폴더의 추출_A.md · 추출_B.md · 비교.md(대상 목록을 못 본 추출), 입력_원문.md · 입력_기존노드.json, 원본 HWPX(`corpus.documents.src_path`). 재추출_대상.md · 메모.md 는 대상 행 확인에, 이전 확정.md · JSON_변환기록.md · ontology/공통_L1.json 은 비교용으로만 봤다. 형식은 5-7b 추출표에 `| 판정 …` · `| 검수단계 …` 칸을 더했다.
읽는 법: 재추출_대상.md 의 13행(규범 9 + 관계 4)만 적었다. 이 표에 없는 행은 지금 원천 값 그대로다. A · B 의 순번은 쓰지 않았고 ID 는 지금 원천 기준이다(대응은 결정 로그).
`판정` 칸: `일치` A · B 가 값 · 연산 · 효과를 같게 읽었고 원문 확인(칸 표기가 스키마 밖이어도 원문을 잘못 읽은 것이 아니면 일치) · `수정` 둘 다 원문과 다르거나 둘 다 적지 않아 검증자가 정한 값. 이 경우 AI대조다.
`달라지는 값` 칸: 지금 원천과 달라지는 값만 적는다. `검수단계만` 은 값은 그대로 두고 단계만 바꾼다는 뜻이다. 종류가 바뀌는 행은 새 종류의 ID 로 적고 옛 ID 를 같은 칸에 적는다.
`조건` 은 지금 원천의 `조건.자연어`, `결과.문장` 은 화면 문장이다. 발췌는 칸 앞에 조문 ID 가 없으면 그 블록의 입력 원문에서 따왔다.
쟁점 · 대상 밖 차이는 `## 결정 로그` 에 적었다.
