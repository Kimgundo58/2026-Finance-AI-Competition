# JSON 변환 기록 (36_재추출_모집공고, 묶음 17 재추출)

입력은 `확정.md`, 산출물은 `ontology/모두의창업.json` (2026-11-07). `공통_L1.json` · `schema.json` · `ontology_check.py` 는 바꾸지 않았다. DB 에 적재하지 않았고 커밋하지 않았다. 상태는 **구성요소 확인, 원천 검사 통과, 화면 경로 미연결**이다.

행은 일회용 코드로 교체했고 코드는 저장소에 남기지 않았다. 쓰기 직전에 파일을 다시 읽어 시작 때와 같은지 확인했다. 이 세션에는 다른 에이전트를 띄울 도구가 없어 아래 내용은 전부 혼자 확인했다. 사용자에게 문제로 알리기 전에 재확인이 필요하다.

## 교체한 행

규범 7행 모두 같은 ID 를 제자리에서 교체했다. 순번 · 행 순서 · 종류 · 수범자 · 수치(null) · 예외 · 승인주체 · 해석미결(false)은 그대로다. 검수단계는 전부 **AI대조 → AI대조** 로, AI검증으로 올린 행은 0이다(결정 로그 첫 항: 두 추출이 독립이 아니다).

- 조건: 자연어 칸을 확정표 문장 1개로 바꿨다. 구조화는 빈 칸 그대로다.

관계 1행: `조:모집공고#p16-1 -준용-> 미특정:공모전 아이디어 보호 가이드라인` 검수단계 **AI검증 → AI대조**. 근거 발췌는 같다.

개념 1개 추가(개념 목록 끝): `절차:사업비계좌@모두의창업`, 정식명 "사업비 계좌", 별칭 없음, 상위 null, 적용사업 모두의 창업 프로젝트, **AI대조**, 근거 `조:모집공고#p17-1` "창업진흥원이 지정한 은행 계좌 (사업비 계좌)".

## 확정표와 다른 점 (5건)

선례대로 옮긴 것(1):

1. 근거 칸: `조건근거` 는 `근거.조건`, `대상근거` 와 라벨 없는 `근거` 는 `근거.대상`(10_E 변환기록 3번). `판정` · `모르는 것` · `용어 후보` 칸은 저장하지 않는다.

변환하면서 판단한 것(4):

2. `결과.문장` 키를 지웠다. 확정표 행에 없어서다. 기존 쉬운 문장을 함께 두면 확정표에 없는 값이 남는다. 화면 영향은 아래 "적재 뒤 확인할 것" 1번.
3. 신규 개념의 정식명 · 근거: 표에 칸이 없다. 정식명은 ID 끝과 표의 용어 후보대로 "사업비 계좌", 근거는 그 행의 대상근거를 썼다. 공통 노드 `절차:전용계좌` 의 별칭 "사업비 계좌" 와 표현이 같다. 적용사업이 달라 별칭 검사는 통과하고, `노드_결정` 은 둘 다 돌려주며 호출자가 품목 · 세목만 고르므로(`ontology_lookup.py:66,440,453`) 지금 판정 경로에는 닿지 않는다. 합치지 않았다(확정표 "모르는 것").
4. 재사용 개념 행은 바꾸지 않았다. 표에 개념 근거 칸이 없고 대상 행이 아니어서다. 그 결과 이 블록 근거가 개념에 없는 곳이 있다: `절차:아이디어접수@`(p14-2 · p15-1), `절차:아이디어심사@`(p15-1), `절차:자격부적합@`(p16-1). 규범 근거에는 있다.
5. 대상에서 빠진 노드는 지우지 않았다. `절차:대리신청@` · `절차:동시수행불가창업지원사업@` · `절차:전용계좌` 는 다른 행이 계속 쓴다.

## 적재 뒤 확인할 것

코드 읽기로 확인했고 실제 적재 · 실행은 하지 않았다.

1. 확정표 머리말은 조건 · 결과.제재 문장이 "화면에 그대로 나간다" 고 했는데 지금 코드와 다르다. 문장은 `결과.문장 → 결과.조건문장 → 가장 긴 발췌 → 자연어` 순이고(`ontology_gate.py:91`), `결과.제재` 를 읽는 코드는 `scripts/` · `server/` 에 없다(`제재` 키 검색). 7행은 이제 쉬운 문장 대신 원문 발췌가 문장으로 쓰인다. p17-1/요건/2 도 가장 긴 발췌인 "지정 은행의 계좌개설 및 거래가 불가한 자의 경우 선정이 취소될 수 있음" 이 쓰인다.
2. 7행은 화면 경로에 닿지 않는 것으로 읽힌다. `적용_규범` 은 대상 노드 · 상위 노드 · `비목:창업/*` 규범만 가져온다(`ontology_lookup.py:154,158`). 대상이 사업 노드이거나 비목 계층 밖 절차 노드라 시작 노드에서 닿지 않는다. 판정 효과는 측정하지 않았다(not wired). `--cq-test` 는 미실행이다.
3. p17-1 에서 같은 문구 "사업비 계좌" 가 의무/6 은 `절차:전용계좌`, 요건/2 는 `절차:사업비계좌@` 로 갈린다. 의무/6 은 대상 행이 아니라 그대로 뒀다. 같은 노드인지 원문이 말하지 않으며 데이터 수정 때 정할 일이다.
4. 재추출 30~35 의 JSON 변환기록이 이 작업 시작 때 없었고 `모두의창업.json` 도 HEAD 와 같았다. 이후 묶음 담당은 이 파일을 다시 읽고 고쳐야 한다.
