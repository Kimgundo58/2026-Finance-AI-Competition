# JSON 변환 기록 (36_재추출_모집공고, 독립 재실행)

입력은 이 폴더의 `확정.md`, 산출물은 `ontology/모두의창업.json` (2026-11-07). `ontology/공통_L1.json` 은 대상 행이 없어 이 작업에서 건드리지 않았다(작업 트리의 변경은 다른 묶음 것이다). `schema.json` · `ontology_check.py` 도 바꾸지 않았다. DB 에 적재하지 않았고 커밋하지 않았다. 상태는 **구성요소 확인, 원천 검사 통과, 화면 경로 미연결**이다.

## 확정표와 다른 점

값이 다른 곳은 0건이다. 표에 칸이 없어 정한 것 3건:

1. 근거 칸: 라벨 없는 `근거` 는 `근거.대상` 그대로다(10_E 변환기록 3번 선례, 이전 변환과 같음). 승인주체를 위한 근거 칸은 형식에 없어 추가하지 않았다. 대상 발췌에 "법정대리인 동의" 가 들어 있다.
2. [4] `조건 없음` 은 `{"구조화": [], "자연어": []}` 로 적었다. 5-8b 예시와 같은 빈 조건 모양이다.
3. 재사용 개념 행은 바꾸지 않았다(표: "검수단계는 기존 값 유지", 근거 칸 없음). 그래서 개념 근거에 해당 블록이 없는 곳이 그대로 있다: `절차:아이디어접수@모두의창업`(p14-2 · p15-1), `절차:아이디어심사@모두의창업`(p15-1). 규범 근거에는 있다. `주체:법정대리인` · `주체:미성년자` 는 p15-1 근거가 있다.
