## 적재 뒤 확인할 것

원천 JSON 을 교체 전 사본과 함께 `ontology_gate.게이트` 에 넣은 시뮬레이션이다. 해당 규범만 넣었고 실제 적재 · 화면 경로 · 판정 LLM · `--cq-test` 는 하지 않았다. 판정 효과는 측정하지 않았다(not wired).

1. **`p10-1/의무/2` 가 할 일에서 빠진다.** 조건.자연어가 생겨 `해당시` 가 False → True 가 되고(`ontology_gate.py:80-82`), `_조건_할일` 이 해당시를 뺀다(`orchestrate.py:903`). 화면 칸은 전후 모두 `공통사항` 이다(`ontology_gate.py:932`). 전원 의무인데 "해당할 때만" 으로 다뤄지는 셈이다. 표 칸을 그대로 옮겨 생긴 일이라 고치지 않았다. 실행 세션이 원하면 자연어를 비우고 `근거.조건` 만 두면 된다.
2. 문장 교체 4행은 시뮬레이션 화면 문장에 그대로 나왔다(`p9-1/의무/3` · `p10-1/의무/2` · `p16-1/의무/1` · `p14-1/의무/8`). `p14-1/의무/8` 문장에 "붙임 2", "간이 증빙" 이 있다. 용어 풀이가 붙는지는 미확인이다.
3. `p11-2/한도/4` 는 전후 같다. 조건 문장은 가장 긴 발췌 "50만원은 물품 1개(1대)를…판단합니다." 이고, 넘는지와 안내는 `_미확정한도_안내` 가 낸다(52만원 · 포함 "넘을 수 있습니다"). 47만원 · 모름도 ×1.1 로 넘을 수 있다고 나온다. 문장을 표대로 넣을지는 실행 세션이 정한다.
4. `--cq-test` 는 재적재 뒤 돌린다. 능력질문.json 이 `p9-1/의무/3` · `p14-1/의무/8` ID 를 각 1번 쓰고, 옛 문장은 0번 쓴다. ID 가 그대로라 영향이 없을 것으로 본다.
5. `p9-1/의무/3` · `p10-1/의무/2` · `p16-1/의무/1` 에 `결과.기한일` 이 없어 `_기한_지남` 이 이 의무를 빼지 못한다(`ontology_gate.py:504-507`). 연도가 원문 조항에 없다는 "모르는 것" 과 같은 이유로 넣지 않았다.
