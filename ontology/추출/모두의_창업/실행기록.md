## 확인 못 한 것

- 이 세션 로그만 봤다. 다른 세션이 더 일찍 돌린 적이 없다고 단정하지는 못한다.
- 재실행의 독립성은 파일 읽기와 셸 명령 정규식으로만 봤다(`ontology/` 경로 · `corpus.` · `psql` · 대상 파일명 0건). 추출자가 시작할 때 자동으로 받는 CLAUDE.md · 메모리 색인의 영향은 보지 않았다.
- 검증자 · JSON 변환 에이전트의 프롬프트 대조는 하지 않았다. 스크립트 옵션과 로그 모델은 Opus 5.5 high 다. `JSON_변환기록.md` 의 「다른 에이전트를 띄울 도구가 없다」는 그 변환 세션 자신을 말한다.
