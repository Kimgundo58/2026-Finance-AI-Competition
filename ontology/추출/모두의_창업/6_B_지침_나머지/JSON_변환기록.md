# JSON 변환 기록 (6_B_지침_나머지)

입력은 `확정.md`, 산출물은 `ontology/공통_L1.json` · `ontology/모두의창업.json` (2026-11-07). DB 에 적재하지 않았다. 상태는 **구성요소 확인, 원천 검사 통과, 화면 경로 미연결**이다.

표 행은 일회용 코드로 읽어 JSON 을 만들었고, 코드는 저장소에 남기지 않았다. 아래 내용은 전부 이 세션 혼자 확인했다. 독립 에이전트 재확인은 없으므로 사용자에게 문제로 알리기 전에 재확인이 필요하다.

## 확정표와 다른 점 (15건)

1. 쓰이지 않는 개념 5개 제외: `절차:점검결과/적정` · `절차:점검결과/부적정` · `주체:임직원` · `주체:중소벤처기업부장관` · `주체:평가위원회`. 규범 · 관계 어디서도 쓰이지 않는다.
2. 상위 27행을 개념.상위로 옮기고 근거를 합쳤다(지시한 모델링).
3. `절차:조기완료 -상위-> 절차:성공판정` 은 개념(AI검증)과 검수단계가 달라 개념.상위 + 관계 행(AI대조, 문맥조문 제53조⑨)을 함께 둔다(5_B 4번 선례).
4. `품목:창업/사후환급금` 은 표에 상위가 없어 `비목:창업/*` · 해석 + 관계 행 AI대조를 뒀다. 고아 검사 통과용(5_B `부채상환` 선례). 근거는 제49조② 금지 문장.
5. 기존 상위를 바꾼 4개. `절차:자기부담사업비` 창업기업등사업비 → 사업비(결정 로그 지시). `절차:자기부담현금` · `현물` 자기부담사업비 → 창업기업등자기부담사업비(표. 옛 상위는 경로에 남는다). `절차:정부지원사업비` 는 [창업기업등사업비, 사업비] 두 상위로 하고, 옛 해석 연결은 관계 행(해석 · AI검증, 근거 제49조⑦)으로 값을 보존했다.
6. 결정 로그의 "둘의 관계는 JSON 단계에서 정한다": 사업 노드를 같은 이름 공통 노드 아래에 뒀다(`절차:점검@모두의창업` 선례). 사업비 · 사업비반납 · 사업비정산 · 최종평가 · 회계감사 · 사후점검 6개. 해석 · 관계 행 AI대조, `모두의창업.json`. `절차:사업비@모두의창업` 은 기존 상위를 유지해 상위 2개다.
7. 동치 `주체:총괄기관 → 주체:중소벤처기업부` 의 `적용조문` 은 표에 칸이 없다. 검사가 요구해 `["조:지침#제2조"]` 로 좁혔다. 동치를 읽는 런타임은 없다.
8. 별칭 충돌 2건: 기존 `주체:총괄기관` 별칭 "중소벤처기업부", `주체:전문기관` 별칭 "창업진흥원" 을 유지하고, 새 노드 정식명을 "총괄기관 중소벤처기업부" · "전문기관 창업진흥원" 으로 뒀다(5_B `지식재산권 등록비용` 선례). 문장을 이어 붙인 표기다.
9. `표-12` · `표-13` 규범의 `원문결함` 표시를 JSON 칸으로 옮기지 않았다. 발췌 조각이 DB 제54 · 67조 본문에 그대로 있고, `입력_원문.md` 에 표 ID 블록이 없어 표시하면 `복원본_없음` 이 된다. 조문 ID 는 표 ID 그대로다. 결함은 칸 배치이고 글자가 아니다.

11. 정식명 · 별칭은 표에 칸이 없어 원문 표기로 정했고 ID 끝은 별칭으로 뒀다. 결과 값은 낱말만으로 뜻이 안 서서 "점검결과 계속" · "최종평가결과 최우수" 처럼 썼다.
12. 별칭: 결정 로그의 분할상환 · 총사업비 · 전문 채권 추심업체 · 추심업체. 그 밖에 원문 표기 "창업사업 통합정보관리시스템"(제2조 16호) · "불인정 금액"(제60조②).
13. 조건의 ` · ` 와 쉼표는 쪼개지 않고 한 문장으로 뒀다(선례). 제63조① · 제67조⑦ 은 "또는" 뜻인 각 호가 한 문장에 들어 있다. 우선순위 `자연어` 는 목록이다.
14. 근거 칸: 수치 규범이 없어 라벨 없는 발췌는 전부 대상 칸이다.
15. 개념 근거는 표에 칸이 없어 5_B 순서(관계 발췌 → 이름을 포함한 규범 발췌 중 가장 짧은 것 → 원문 이름 → 대상 · 증빙 규범 발췌)로 달았다. 못 단 개념-블록 6건(제25조③ 협약기간, 제53조② · ⑧ 사업중단, 제60조③ 사업비정산, 제66조① 사업포기 · 사업중단)은 다른 블록 근거가 있어 근거 없는 개념은 0이다.

적용하지 않음: 결정 로그의 "설계 변경 제안"(시행일 규범 종류). 로컬 `documents.시행일` 은 이미 2025-12-23 이다.

## 적재 뒤 확인할 것

범위: 작업 트리 코드와 원천 JSON 으로 `게이트` 를 메모리에서 돌린 시뮬레이션(변환 전 대 지금)과 코드 읽기다. 실제 적재 · 화면 경로가 아니고 판정 LLM 영향은 재지 않았다. `세목미정` 줄은 넣지 않아 5_B 표와 1줄 차이가 날 수 있다.

### ② 금지가 코드 불가를 내지 않는다 (의도대로)

결정 로그의 "조건 없이 금지 게이트에 쓰면 안 된다"는 지켜진다. 위 사례에서 게이트 종류는 전부 없음이다.

```

  평가 None → 금지조건 줄 (ontology_gate.py:324-326)

```

