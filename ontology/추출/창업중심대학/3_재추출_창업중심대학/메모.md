1_창업중심대학_사업비 · 2_창업중심대학_본문_공통인용 검증에서 다시 볼 14블록을 추출한다(5-12 ⑤, 1회).

창업중심대학 세부관리기준(2025-05-30). 사업키 · 문서키는 창업중심대학이다. 규범 ID 는 규범:창업중심대학/<조문 키>/<종류>/<순번>, 조문 ID 는 조:창업중심대학#… 이고 ontology/창업중심대학.json 에 넣는다. 계층: 세부관리기준 L2.
블록: 제14조(창업기업의 의무) · 제24조①(조기완료) · 제28조①(자기부담사업비) · 제28조②#2(현물부담분) · 제31조① · ②(사업비 관리) · 제32조①(사업비 사용) · 제35조[2]②(권리 의무 이전) · 참고3 기계장치 기준 · 지급수수료 기술이전비 · 지급수수료 사무실임차료 · 교육훈련비 기준 · 참고5 사업비 집행 · 청구 금액별 · 창업기업의 권리 · 의무 이전.
원문 사정: 제28조는 원문에 ② 가 두 번이라 둘째(현물부담분)는 제28조②#2 다. 원문이 제35조를 두 번 써서 DB 둘째(권리 의무 이전)는 제35조[2] 다. 참고3 · 참고5 블록과 복원본이 있는 조는 복원본 ontology/추출/복원/창업중심대학.json 블록을 썼다. 참고3 블록 ID 는 /<비목>/기준 · /<비목>/유의사항, 지급수수료만 /지급수수료/<항목> 이고 비목 이름은 ID 에만 있다. 참고3 /집행기준 의 「※ 2천만원(VAT포함) 이상의 사업비 집행 건(인건비 제외)의 경우 비교견적서 제출 필수」 는 집행기준 표 전체에 걸린다. 참고5 는 창업중심대학(주관기관)과 창업기업 문장이 섞여 있다. 원문 오탈자는 고치지 않고 발췌한다.
조건: 제28조① 「모집공고의 자기부담사업비 부담비율」 · 참고5 「‘창업기업 모집공고문’ 기준」 은 폴더에 해당 공고가 없어 조건 「공고 확인」 으로 둔다. 「전문기관(의 장)이 별도로 정하는」 기준(제24조③ · 제32조③)은 조건 「전문기관 확인」 이다.
인용: 지침 인용 번호는 13차 번호다. 관계 dst 는 입력 원문 머리의 대응표로 쓰고 발췌는 원문 표기 그대로 둔다. 기술이전비의 「기술의 이전 및 사업화 촉진에 관한 법률 제35조」 는 조:기술이전법#제35조 다.
