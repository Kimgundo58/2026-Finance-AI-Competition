```

규범    확정 240 = 새 행 240 + 교체 0 · 근거만 합친 원천 규범 0
개념    신규 58 = 새 행 58 + 뺀 개념 0 + 원천에 이미 있던 것 0 · 근거 · 별칭만 합친 원천 개념 97
관계    상위 0 → 개념.상위 · 그 밖 25 → 새 행 25 · 근거만 합친 원천 관계 0
파일    공통_L1.json  개념 553→610 · 관계 623→623 · 규범 1060→1060 · 기존 줄을 바꾸지 않음 예

```
