# 창업중심대학 세부관리기준: 추출 범위

2026-11-08. 문서 doc_id `창업중심대학 세부관리기준2025년 개정`(로컬 `suddoe_ontology`, L2 active, 시행일 NULL · version 비어 있음, 판 표기 표지 · 부칙 2025-05-30, `PDF대조/차이목록.md`). 사업키 · 문서키 `창업중심대학`.

**기준** (모두의 창업 묶음 A · 예비와 같음, 5-12 · 5-7): 사업비를 쓰는 창업기업 · 대표자의 지출에 닿는 조는 넣는다. 주관기관(창업중심대학)의 사업비 · 운영 · 평가 · 선정 절차만 다루는 조와 주관기관 참고 · 서식은 뺀다. 애매하면 넣는다. 조를 쪼개지 않는다.

## 상한 확인

```
전체 44행 49,775자 (DB 본문 글자)
└ 참고1 · 2(주관기관) 7,793자 뺌 → 41,982자 = 5-12 표 「붙임 · 서식 뺀 글자」 (같음)
   └ 본문 주관기관 · 선정 조 17개 5,387자 뺌 → 범위 안 25행 36,595자 (상한의 87%)
      └ 추출 입력(복원본 적용) 110블록 28,401자
           참고5 행 11,390 → 5,054   양식 제2~7호(DB 에서 참고5 행에 섞여 있음)를 뺐다
           참고3    11,589 → 10,448  점검표 중복 · 조각을 뺐다
           참고4     4,694 → 3,498   세목 표 중복 · 조각을 뺐다
           본문 · 부칙 8,922 → 9,401  쪽 번호 · 장절 표제는 뺐지만 부칙 시행일 4줄을 되살리고 표를 MD(병합 칸 반복)로 다시 써서 늘었다
```

5-12 의 「붙임 · 서식 뺀 글자」 41,982자는 참고1 · 2 만 뺀 값이다. DB 에서 【양식 제1~7호】 가 참고5 행 안에 있어(차이목록) 서식 글자(약 7,000자: 양식 MD 표 4,615 · 꼬리 2,368)가 상한에 들어 있었다. 입력은 상한보다 13,581자(32%) 적다. 5-12 의 「더 줄어든다」 가 맞았다.

### 참고1 의 창업기업 지원금 줄

참고1 인쇄 17쪽 첫 행 「사업화지원(창업기업 지원금) | • 창업기업 사업화 지원금: 인건비, 시제품 제작비, 지재권 취득비 등 창업기업의 창업활동에 소요되는 자금으로 창업기업별 협약 금액 내 집행 | 창업기업별 한도 내」. 주관기관 사업비 구성표의 한 비목 줄이고, 창업기업 지출에 대한 내용은 「협약 금액 내 집행」 한 가지다. 집행 기준 · 금지 · 증빙은 참고3~5 에 따로 있다. 참고1 의 나머지(4,900자 이상)는 주관기관 인건비 · 운영비 기준이라 조를 쪼개지 않는 기준으로 참고1 전체를 뺐다. 이 판단으로 빠지는 창업기업 규범은 「창업기업별 협약 금액 내 집행」 한 줄이고, 범위 안에서 같은 뜻의 문장은 제30조① 「창업사업화 지원비는 변경이 불가」(주관기관 쪽 문장)뿐이다. 조율 세션이 넣기로 하면 참고1 5,268자(복원 전 평문, 셀 풀림)를 복원해 넣어야 한다.

## 인용 조

범위 안 조가 다른 문서를 인용한 곳 전부(복원본 · DB 본문 정규식 + 읽기, 임시 `ontology/.tmp_api/P1_창업중심대학/cited.py`). 대조 코드 `…/cmp_cited.py`(읽기 전용): `공통_L1.json` 의 문자열에 나온 `조:<문서키>#<조>` · `규범:공통/<문서키>#<조>` 201개와 `ontology/추출/*/*/입력_명세.json` 의 조를 맞춰 봤다.

**지침 판:** 제1조의 「창업사업화 지원사업 통합관리지침」 은 13차(2025-02-05, 로컬 superseded) 이름이고 인용 번호도 13차 조 제목과 맞는다. schema `지침` 은 14차(2025-12-23)다. 13차 → 14차는 조 제목으로 대응시키고, 제목이 다른 제62조는 본문 세 항을 읽어 맞췄다. 13차 제43조⑨ · 14차 제47조⑨, 13차 제21조①3 · 14차 제25조①, 13차 · 14차 제2조11호(전담인력)는 본문을 읽어 같은 뜻임을 확인했다. 나머지 본문 차이는 안 봤다. 확인은 이 세션 하나뿐이고 별도 에이전트 검증은 하지 않았다. 운영요령은 2024-101 → 2026-82 조번호가 같다(5-7 묶음 C).

## 구현 결정 (문서에 없어 안전한 쪽으로 정한 것)
