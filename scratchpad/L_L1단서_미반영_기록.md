# 레인 L — L1 단서절 미반영 조사 기록 (2026-09-06)

산출: `scratchpad/L_L1단서_미반영.json` (14 항목 — 조사한 조 10개 전부 포함, 0건인 조도 기재)

## 방법 (재현 가능하도록 신호 목록을 먼저 고정)

```
신호 목록  다만 · 원칙적으로 · 예외적으로 · 부득이한 경우 · 인정하는 경우 ·
          생략하게 할 수 있다 · 제외하고 · 승인을 받은 경우 · 그러하지 아니하다
```
L1 제36~45조 전문(본문 직접 열람)에서 이 신호가 나오는 문장을 전부 뽑고,
「당사자가 창업기업인가 주관기관·전문기관인가」로 먼저 걸렀다(㉠). 창업기업 향인 것만
8개 사업 rule 의 금지예시 배열 + 사전승인_조건 텍스트와 대조했다.

## 🔴 신규 발견 — 방향이 반대인 사례 (제42조⑦1호)

이 레인의 원래 질문은 "L1 의 단서를 사업이 놓쳤는가"인데, 초격차(rule 450, 차량임차)는
**반대** 다 — L1 은 "차량 등의 임차 경비는 집행할 수 없다"를 위임 문구 없이 flat 으로
정했는데, 초격차 자체 세부관리기준(참고2)이 "사업과 직접적인 연관성이 있는 특정 사유가
있는 경우 주관기관 전담인력의 사전 검토 후 집행 가능"이라는 예외를 스스로 만들어
금지예시에도 반영했다. L1 제42조엔 제38조②처럼 "사업별로 정할 수 있다"는 위임이 아예
없어서, 이 완화가 유효한지 근거가 불분명하다. **틀린가능**(원래는 막혀야 하는데 룰이
열어준 경우)에 해당할 수 있어 별도 표시했다.

## ㉢ 를 지키려 한 부분 — "미반영 ≠ 결함"

제39조④(범용 S/W)는 예비창업·초기창업·모두의창업 3개 사업에 해당 룰 자체가 없다.
이건 "무조건 금지로 잘못 등록"된 게 아니라 "룰이 아예 없는" 것이라 **위험 없음**으로
분류했다 — 다만 사용자가 이 3개 사업에서 "범용 S/W 사도 되나"를 물으면 룰 테이블이
답을 못 주는 **커버리지 공백**이라는 점은 별도로 적어뒀다(위험도와는 다른 관측).
