## 3. 결과는 어땠는지

### (1) `사업명 IS NULL` 9행 = «적재 사고가 아니라 설계»
```

layer=L2 · 사업명 있음 · 65행
교차 0. L1(통합관리지침)은 사업 무관 공통 규범이라 사업명 NULL 이 정상
```

### (2) 🔴 P0-3 의 출발 근거(rule 450)가 «틀린 서술» 이었다
- L1 통합관리지침 제42조⑦-1 = "차량 등의 임차 경비는 집행할 수 없다"(단서 없음) ✅
- 🔴 그러나 rule 450 근거에 «초격차 참고2» 가 실재하고, 그 원문:

   «사전 검토 후 집행 가능»"  (참고3 에 같은 취지 2건 더)
- => 룰은 «지어내지 않았다». ai-4e 도 독립적으로 같은 결론(28행 중 «창작» 0건)
- => 오너 결정: **L2 가 이긴다 · rule 450 은 정확** (2026-09-06)

### (3) 오너 지시 「세부관리기준 제3조를 뒤져 채운다」 → **채울 것이 없다**
5사업 제3조는 전부 «L2 vs L3» 만 말한다. L1 은 문장에 등장하지 않는다.
```
도약 제3조      "주관기관의 내부규정과 상충되는 경우 본 관리기준을 우선한다"
재도전 제3조     "주관기관의 내부규정과 상충되는 경우 본 관리기준을 우선한다"
창업중심대학 제3조 "창업중심대학의 내부규정과 상충되는 경우 본 관리기준을 우선한다"
```
**검출력 증명** (키워드 4개 «각각» 따로 · L1 문서 제외):
```
             우선 적용  우선적용  지침을 우선  달리 정하는
예비/초기/도약/재도전/창업중심대학    0    0    0    0
[대조] 초격차                   1    0    1    2
[대조] 모두의                   1    0    0    1
```
=> 0건이 «표기 차이» 가 아니라 **실제 부재**다.

