```
  scratchpad/최종계획_0906.md      전체 계획에서 «네 레인» 절만

절대 규칙

절대 규칙
 1. DB 는 «읽기 전용». INSERT/UPDATE/DELETE 금지. 반영은 중앙이 한 번에 한다
 2. scripts/ 아래를 고치지 마라. GPU 를 켜지 마라. git commit 하지 마라
 3. 산출은 «네 파일 하나» 에만 쓴다: scratchpad/{네 산출파일}
 4. 🔴 원문에 없으면 «없다». 아는 지식으로 보충하지 않는다
 5. 🔴 eval.golden_set 을 «재료» 로 쓰지 마라 (골 레인 제외).
    만드는 것은 corpus.doc_articles 에서만 나온다. 정답지는 잴 때만 쓴다
 6. 모르면 「없음」이 아니라 «보류» 로 빼고 이유를 적는다

  PYTHONIOENCODING=utf-8 를 반드시 앞에 붙인다

작업 도중 지켜라
  · 새 파일을 scratchpad/ 밖에 만들지 마라
  · 다른 레인의 산출 파일을 읽거나 고치지 마라
```

## S1 : 골A-전반 — 본세트 미검수 «표 아닌» 90건
```

그 194건 중 «근거가 표 조항(참고N·붙임N·별지N)» 인 104건은 0단계 후에 본다.

  ④ 정답근거가 비었거나 근거원문이 빈 문항은 따로 표시
```
