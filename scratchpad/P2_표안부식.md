## 발견 상세

### 1. 빈 셀 — 초격차 참고5, "업무추진비" 행
```
| 업무추진비 | 업무추진비 |  | 사업추진비 | 동 사업 관련 회의 및 간담회비 |  |
```
3번째 칸("한도")이 비어 있다. 같은 표의 다른 5행(프로그램운영비 30%이상·인건비 기관한도내·
운영비 기관한도내·여비 10%이하·자산취득 5%이하)은 전부 값이 있다 — 이 행만 비었다.
🔴 **원본(PDF)에서도 비었는지는 확인 못 했다.** 업무추진비는 성격상 %상한이 없을 수도 있어
"복구가 흘렸다"와 "원래 없다"를 이 세션에서는 가르지 못한다 — «확인불가»로 남긴다.
(참고: 6번째 "비고" 칸도 여비 행 1곳만 값이 있고 나머지 5행은 비어 있다 — 이건 비고 칸이
원래 대부분 비는 구조로 보여 결함으로 안 셌다. 3번째 칸과는 성격이 다르다)

### 2. 순서 — 정상이나 원본 미대조 1건 (L1 제36조)
`scratchpad/0단계_표순서교정.py`가 4분면 순서를 교정한 문서는 **5개**뿐이다:
초격차(제10차)·예비창업패키지·초기창업패키지·모두의창업·창업중심대학. **L1 통합관리지침(제36조가
속한 문서)은 이 5개에 없다** — 순서 교정을 받은 적이 없다.
직접 읽어 보니 제36조의 표는 재료비→외주용역비→기계장치→특허권→인건비→지급수수료→
여비→교육훈련비→광고선전비→기타 순으로 canonical 순서와 일치했다. 그런데 이게
"원래 4분면이 아니라 문제가 없었던 것"인지 "우연히 순서가 안 뒤집힌 것"인지는 PDF 원본의
페이지 레이아웃을 봐야 안다 — 이 세션은 안 봤다. **정상으로 보이지만 원본 미대조로 표시한다.**
나머지 7개는 전부 순서교정 대상(5문서)에 속하거나(6개 조) 애초에 순서 문제 보고가 없던
문서(모두의 별지1 — 라운드운영비 체계라 canonical 비목 순서 자체가 해당 없음)다.
