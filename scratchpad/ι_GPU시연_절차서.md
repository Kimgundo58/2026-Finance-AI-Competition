## ⑤ 스모크 — 판정 1건 성공까지

```bash
# (a) 정규화
curl -s -N -X POST https://<서비스도메인>/api/normalize \
  -H "Content-Type: application/json" \
  -d '{"질문":"노트북 150만원짜리를 사업비로 사도 되나요?", "사업명":"예비창업패키지"}'
```
```
성공표시  SSE 스트림에 `event: 결과` 가 뜨고 그 data 안에 "품목"·"금액" 등이 채워져
         있다. `event: 오류` 가 뜨면 실패 — 메시지·종류 필드를 본다
```
```bash
# (b) 판정 — (a)의 결과 JSON 을 그대로 정규화 자리에 넣는다
curl -s -N -X POST https://<서비스도메인>/api/judge \
  -H "Content-Type: application/json" \
  -d '{"정규화": {...(a)의 결과...}, "사업명":"예비창업패키지"}'
```
```
성공표시  SSE 에 `event: 판정` 이 뜨고 "판정" 필드가 가능/조건부/불가/판단불가 «넷 중
         하나»다(내용이 뭐든 이 넷 중 하나면 파이프라인은 성공이다). 이어서
         `event: 결과` → `event: 완료` 까지 스트림이 끝까지 간다
실패시   어디를 보나 — 서버 로그의 "judge 실패 — 판단불가로 닫음"(main.py:812) 줄을
         먼저 본다. LLM실패면 vLLM 이 그새 다시 죽었거나(④를 다시), 프롬프트가
         한도(40,960토큰)를 넘겨 조용히 잘렸을 가능성(8-3_GPU.md §6) — 이 경우 답은
         나오지만 «질문과 무관한» 판정이 나온다. 내용을 읽어서 질문과 맞는지 사람이
         눈으로 확인해야 한다(로그만으론 안 잡힌다)
```
