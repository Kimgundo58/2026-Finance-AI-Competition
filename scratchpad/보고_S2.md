# S2 — 인증·테넌트 격리 (2026-09-03) · 공격 55건 실행 / 통과 55 · 실패 0
🔴 **「org_id 를 아무도 모른다」는 방어가 아니었다.** `load_org_programs.py` 가 `uuid5(uuid5(DNS,"suddoe.org"), 공백뗀 기관명)` 로 만든다 — 네임스페이스는 레포에, 기관명은 공개. **413행 중 411행을 이름만으로 재계산했다**(나머지 2행은 L3 픽스처). 슬러그를 숨기는 건 «우리가 안 흘린다» 일 뿐이고, 실제 방어는 **`SUDDOE_ORG_PARAM=0`** 하나다.

**① 만든 파일** `server/auth.py`(토큰해석 Supabase RS256/ES256+JWKS캐시 · 데모 HS256 · `현재주체` Depends · `OrgId주입` ASGI 미들웨어 · `slug()` HMAC) · `server/routes_orgs.py` · `db/init/01_schema.sql`(`pw_hash` NOT NULL 해제 «만», 라이브 DB 에도 ALTER 적용) · 회귀 `scratchpad/attack_s2.py`(39) `attack_mw.py`(16) — 중앙이 `tests/` 로 옮겨줄 것.

**② main.py 패치 텍스트** (직접 수정 안 함)
```python
from server import auth, routes_l3, routes_orgs, routes_plans, routes_tasks  # 68행
app.add_middleware(auth.OrgId주입)       # 317행 CORS 근처. 🔴 없으면 auth.py 는 무력
app.include_router(routes_orgs.router)   # 330행 뒤
```
미들웨어인 이유: `routes_plans` 등이 `org_id` 를 «직접» 읽는데 소유 밖이다. 라우터가 보기 전에 쿼리스트링을 토큰값으로 갈아끼우면 **라우터 무수정으로** 전 경로에 걸린다(임시 배선). `@app.middleware("http")` 대신 순수 ASGI 인 건 SSE 응답을 안 감싸려고.

**③ 심사위원 = (b) 클릭마다 임시 org.** (a) 고정 org 는 «게스트 공용버킷 금지» 를 이름만 바꿔 되풀이한다 — 금지된 건 NULL 이 아니라 «공유» 라, 심사위원이 둘 이상이면 첫 화면부터 남의 계획이 섞인다. (b) 의 비용은 정리뿐이고 TTL 로 접힌다. org_id 는 uuid4(이름에서 재계산 불가) · `[데모] ` 접두로 `/api/orgs` 제외 · 보존 24h > 토큰 2h(정리가 살아있는 토큰을 못 앞지른다) · 동시 상한 200(인증 없는 «쓰기» 라 필수).
🔴 정리는 자식을 «먼저» 지운다 — `decisions.org_id` 가 ON DELETE SET NULL 이라 org 만 지우면 그 판정이 `org_id IS NULL`, **격리하려던 데모가 정리 순간 게스트 공용버킷으로 흘러든다.**

SSE 가 한꺼번에 도착한 건 미들웨어가 아니라 TestClient 였다 — 미들웨어 없는 대조군이 같은 값이었다.

**⑤ 프론트 계약 변화**
- 신규 `GET /api/orgs?q=&사업명=&페이지=&크기=` → `{총건수,페이지,크기,항목:[{slug,기관명,사업명[]}]}`. **org_id 없음.** 검색은 공백을 떼고 맞춘다.
- 신규 `POST /api/demo/session` → `{access_token,token_type,expires_in,기관명,slug}` → 이후 `Authorization: Bearer`.
- 기존 `?org_id=` 는 **그대로 동작**(R4). 토큰을 같이 보내면 토큰이 이기므로 둘 다 보내도 안전.
- 401/403 신규 지점은 «토큰을 보냈는데» 위조·만료·미등록일 때뿐. 마감 전 헤더로 갈아타 둬야 심사 직전 `SUDDOE_ORG_PARAM=0` 이 가능하다.

**넘길 것** — 🔴 **`requirements-api.txt` 에 `pyjwt[crypto]==2.13.0` 을 넣어야 한다.** 이 파일은 내 작업 중 다른 세션이 만들었고 pyjwt 가 없다(소유 밖이라 안 건드렸다). 미설치면 토큰 경로가 503 «거부» 로 떨어져 안전하긴 하나 **인증이 통째로 죽는다** — 컨테이너 배포 전 필수. 로컬은 설치해 뒀다. `main.py` 도 다른 세션이 고치는 중인데 위 패치 앵커(68·317·328~330행)는 지금도 그대로다. 환경변수 `SUDDOE_JWKS_URL`(필수)·`DEMO_SECRET`·`SLUG_SECRET`·`ORG_PARAM`(기본1)·`JWT_AUD`(기본 authenticated)·`DEMO_TTL/보존초/상한`; 비밀 미설정은 개발기본값+`logging.warning` 으로 알린다. Supabase 매핑 열쇠가 `sub` 이 아니라 `email` 인 건 `accounts` 에 sub 컬럼이 없고 허용 스키마 변경이 pw_hash 하나뿐이라서 — `accounts.sub UUID UNIQUE` 를 넣으면 `_계정조회()` 한 함수만 바뀐다.
