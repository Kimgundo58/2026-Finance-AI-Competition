## 갈래 C — 어휘 체계가 «다르다» (TIPS)
```
TIPS   11.  연구개발비 산정기준 및 조정      12,527자
       16.  연구개발비의 관리 및 사용         8,682자
```
🔴 **TIPS 는 「사업비 비목」이 아니라 「연구개발비」 체계다.**
   직접비·간접비·연구수당 같은 말을 쓰는데 우리 비목 10종에 그 개념이 없다.
   골든셋 저작메모에도 이미 적혀 있다: "item_vocab 에 '간접비' 가 없다 — 비목매핑 불가"
   -> **TIPS 는 별칭을 만들기 전에 「비목 10종으로 매핑이 되는가」 부터 답해야 한다.**
      되면 매핑표를, 안 되면 「TIPS 는 판단불가」를 제품 결정으로 못박는다.


## 산출 형식 (룰검산.py 가 검사한다)
```json
{"비목":"지급수수료", "별칭":["사무실 임대료"], "사업명":"예비창업패키지",
 "근거":{"doc_id":"...", "조번호":"붙임2"},
 "원문발췌":"<조 본문에 문자 그대로 있는 문장>"}
```
🔴 상식 별칭(맥북->기계장치)은 «안» 만든다. LLM 이 이미 안다(실측 65.1%).
   규정을 안 읽으면 모르는 것만 만든다.
