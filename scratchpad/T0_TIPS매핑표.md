## 1. 창업비목 → RND비목 대응표 (원문 근거 포함)

```
인건비          -> 인건비                (11.다.1)<인건비> "참여연구자 급여+4대보험+퇴직급여충당금")
재료비          -> 연구재료비             (11.다.1)<연구재료비> "시약·재료 구입비")
기계장치        -> 연구시설·장비비         (11.다.1)<연구시설·장비비> "연구시설·장비, 지정 보육공간 임차료")
                🔴 단, "사무용 PC·프린터·복사기·사무용 S/W"는 여기가 아니라
                   <연구활동비> 라)"연구실 운영비"다(11.다.1) — 골든셋 T22가 이 경계에 걸린다
외주용역비      -> 위탁연구개발비          (16.나.1)"주관연구개발기관이 일부를 위탁할 때 지급하는 비용")
                🔴 단, 소규모 "시험제품 등 외주가공"은 <연구재료비> 나)에 별도로 있다
                   ("보유시설 부족 등으로 시험제품 등을 외주가공 하는 경우 소요비용을 현금 계상")
                   — 창업패키지의 "외주용역비"가 이 둘 중 «어느 규모» 를 말하는지 문항마다 갈린다
지급수수료      -> 🔴 «단일 대응 없음» — 세목별로 흩어진다(아래)
                   회의비·전문가활용비·연구인력지원비·그밖의비용 -> 연구활동비 (대다수)
                   지정 보육공간 임차료(=사무실임차료 대응물) -> 연구시설·장비비 (좁은 조건에서만)
                   기술자료 임치(=기술보호비 대응물) -> 간접비 "연구지원비-연구보안관리비"
                   지식재산권 출원·등록비(=특허권등 대응물) -> 간접비 "성과활용지원비"
                   회계감사비·법인설립비·보험료·운반비·보관료·세무기장료·기계장치수리비 ->
                     🔴 원문 어디에도 명시가 없다. «대응 없음»으로 본다(억지로 안 만든다)
여비            -> 연구활동비(가.출장비)   (11.다.1)<연구활동비> "출장비용으로 운임·일비·숙박비·식비")
교육훈련비      -> 연구활동비(사.연구인력지원비) (11.다.1) "교육ㆍ훈련 비용, 학회ㆍ세미나 참가비")
광고선전비      -> 🔴 «대응 없음» — 11./16. 전체에 광고·홍보·마케팅 관련 문구가 «한 건도 없다».
                   확인 방법: 두 조 전문(합 21,209자)을 "광고|홍보|마케팅|홈페이지|배너"로 훑어
                   0건 — «있으면 보일 조건»을 만들어 확인했다
특허권등무형자산취득비 -> 간접비(성과활용지원비 "나. 지식재산권 출원·등록비")
                🔴 central이 "불명"이라 한 것 — 존재는 확인됐다. 다만 창업패키지에서는 이걸
                   «직접비» 성격 독립 비목으로 다루는데 TIPS는 «간접비» 하위 세목이다. 위치가
                   다르다는 것 자체가 구조적 차이 — 그대로 옮기면 틀린다

🔴 창업비목 체계에 «없는» RND 고유 비목 둘
   연구수당      TIPS 고유(11.다.1)<연구수당> "해당연도 수정인건비 합의 20% 이내"). 창업쪽엔
                이 개념이 없어 골든셋에서 "인건비"로 잘못 뭉뚱그려졌다(T08, 아래)
   학생인건비    TIPS 고유(16.가."대학 학생연구원 학생인건비"). 마찬가지로 "인건비"로
                잘못 뭉뚱그려졌다(T03, 아래) — item_vocab.TIPS 에는 이미 별도 행으로 있다
```

   11.다.1)자)"그 밖의 비용"이 "연구개발과제와 직접 관련이 있는 ... 비용"만 열거하고
   광고·홍보·마케팅은 어디에도 없다. 「명시적 금지문」은 없고 「그런 비목 자체가 없다」뿐이다
