## 6. 독립 확인 — rule 450 · precedence_rules (ai-33 요청)

### ✅ (1) rule 450 은 예외를 «지어내지 않았다»
`corpus.rules` rule_id=450 근거 = 초격차 세부관리기준(제10차) 제18조 · 같은 문서 **참고2** · L1 통합관리지침 제42조.
금지예시[0] = "차량(승용차·화물차·이륜자동차 등) 임차 경비**(사전 검토·승인 시 예외)**".
=> 기존 서술 「룰이 스스로 만들어 붙였다」는 **틀렸다**. ai-33 정정이 맞다.

### ✅ (2)(3) precedence_rules 9행 — 독법 일치
- L1>L2 `unspecified_only` : prec 6 초격차 · 8 모두의창업 · 9 TIPS = **3**
- L2>L3 `all` : prec 1 예비 · 2 초기 · 3 재도전 · 4 도약 · 5 창업중심대학 · 7 모두의창업
- 모두의창업만 둘 다 보유 → L1>L2 없는 사업이 정확히 **5**
- 「`범위='all'` 행이 L1 을 암묵적으로 담는가」 → **아니다**. 우선 L2 / 열위 L3 이고 원문이 "**내부규정**"(=주관기관=L3). L1 은 문장에 없다.

### ✅ (4) 부재 검정 — 대조군으로 검출력 증명
「우선 적용」 조문 적중수: 예비0 · 초기0 · 재도전0 · 도약0 · 창업중심대학0 / **초격차1 · 모두의1 · TIPS8**
=> 0건이 표기 차이가 아니라 **실제 부재**.

### 🔴 (5) 다만 «완전한 공백» 은 아니다
5사업 원문에도 운영요령·통합관리지침이 뜨는데 두 종류였다:
- **제1조(목적)** — "지침에 **위임된** 사항을 규정" → 위임 관계지 우선순위 선언 아님
- **제N조(해석)** — "본 관리기준에 **명시되지 않은** 사항 … 전담기관의 결정 및 해석에 따른다"
  (예비 45·32 / 초기 43·31 / 재도전 34·30 / 도약 46·45·40 / 창업중심대학 41)

### 🔴🔴 (6) 새 발견 — P3-c 에 직접 영향
- 창업중심대학 **제36조(해석)** = "**운영요령, 지침, 관리기준**에 명시되지 않은 사항 → 총괄기관장"
- 창업중심대학 **제41조(해석)** = "본 **관리기준**에 명시되지 않은 사항 → 전담기관장"
같은 사업인데 **연도판마다 해석조의 포섭 범위가 다르다**. 룰을 어느 판에서 뽑았느냐로 답이 갈린다.
=> P3-c 는 행마다 근거 doc_id 의 **판** 을 같이 확인해야 한다.

### 🔴 (7) 운영 결론 정정 — 「P3-a 는 의심을 못 낸다」는 너무 세다
규칙 부재 ≠ 아무 말도 못 함. 해석조가 처리 절차를 명시하고 있다:
> L1 금지 ↔ L2 예외 충돌 + 우선순위 선언 없음(5사업) → **조건부(전담기관 확인 필요)** 로 떨어뜨린다

법령 해석이 아니라 **원문이 명시한 절차**라 오너 결정 없이 세울 수 있다.
=> 의심 기준을 「충돌 시 조건부여야 하는데 가능/불가로 단정했는가」로 바꾸면 P3-a·P3-c 가 지금 그대로 점검 가능.

### (8) (a)/(b) 해석 — 단정 보류에 동의, 다만 무게는 기울어 있다
