## 3. `verified`·`허용` 분포(조건부73·가능1·불가0) — 이건 «안 바뀐 게 맞다»

DB 실측(위 §0)이 여전히 조건부73·가능1·불가0 이라, 아래 문서들의 이 숫자는 **낡지 않았다**
(그대로 둬도 됨 — 참고용으로만 남긴다):
```
docs/0_현황.md:58 · docs/0-3_초록이_가린다.md:16 · docs/4_검색/4-5_적재_지표.md:20 ·
docs/5_룰/5-1_룰_테이블.md:59 · docs/5_룰/5-3_검수_절차.md:18 · docs/9-4_판정이_조건부로_수렴한다.md:27
```
단, `docs/7_백엔드/DB_재현_0902.md:57`("전체74/verified74/미검수0, 검수일 08-31 53·09-03 21")은
날짜 세부가 09-03 이후 검수분(74-53-21=0 인데 실제로 09-05·09-06 에도 룰 작업이 있었다) —
verified 총량은 안 바뀌었지만 "검수일 내역"이 최신 룰E·G1~G3·W-2 반영분을 안 담고 있을 수
있다. **행수·verified 는 안 낡았고, "검수일 내역 나열"만 확인 필요**로 표시한다.

확인 안 됨 — **고치지 말고 세 값의 관계부터 확인이 필요**하다고만 표시한다.
