# A-3 + B — 심층질문 배선 (레인 Y)

계약은 ai-8c·ai-7d 사이에서 먼저 확정한 뒤 착수했다. DB 읽기전용·DDL 미적용·LLM 호출 불변.

## 바뀐 파일
```
server/models.py        심층질문항목·심층질문선택지·심층질문근거·답변항목 신설
                         정규화응답.심층질문[] · 판정요청.답변[] 추가
server/main.py           _심층질문마스터()·_심층질문_선별()·_사용자F값_조립() 신설
                          _실_정규화() 가 out["심층질문"] 을 채운다
                          _실_판정() 이 orchestrate.판정(사용자F값=...) 을 넘긴다
                          _목_정규화 에 "심층질문": [] 추가(목/실 키 동형성 유지)
scripts/orchestrate.py   판정() 시그니처에 사용자F값=None 추가(동결 인터페이스 — 안 넘기면
                          바이트 단위로 종전과 같다)
                          (5)전제해소 호출부: f값 = f값_경로키(_f사실); 있으면
                          f값.update(f값_경로키(사용자F값)) 후 전제해소(f값=f값)
tests/test_contract.py   "정규화결과" 계약에 "심층질문" 추가(안 하면 test_정규화응답_모델이_계약과_같다 가 깨진다)
```

## A-3 — 정규화 응답에 실리는 모양
```jsonc
{
  "심층질문": [
    {
      "code": "성공보수아님",
      "질문문": "...",                 // ai-7d A-1 산출. 컬럼명은 corpus.check_items.질문유형 등으로 «가정» 했다
      "유형": "예아니오",               // 4종 임시(예아니오/선택/숫자/텍스트) — A-2 확정 시 조정
      "선택지": [],
      "근거": {"doc_id": "...", "조번호": "제40조"},   // 필수, check_items.근거[0]
      "필요F필드": ["정부지원_현금"]     // 컬럼명 그대로. dotted-path 로 미리 안 만든다
    }
  ]
}
```
🔴 **컬럼 이름 가정** — `corpus.check_items` 에 아직 A-1·A-2 컬럼이 없다(질문문·질문유형·
선택지·필요F필드). 코드는 이 넷을 가정하고 짰고, `_질의()` 가 실패를 삼켜 컬럼이 없는
동안은 `심층질문` 이 그냥 빈 리스트로 나간다(고장이 아니라 "아직 안 켜짐"). 실제 컬럼명이
다르게 오면 `server/main.py` 의 `_심층질문_컬럼` dict 하나만 고치면 된다.
🔴 `유형` 컬럼명은 «질문유형»으로 잡았다 — `check_items` 에 이미 `유형`(기타/계약/비교견적,
`할일.유형` 용)이 있어서 겹치면 컬럼 두 개가 같은 이름을 못 쓴다.

## B — 판정요청이 답을 받는 모양
```jsonc
{ "정규화": {...}, "확정비목": "...", "답변": [{"code": "성공보수아님", "값": true}] }
```
`_사용자F값_조립()` 이 `code -> 필요F필드` 를 마스터에서 찾아 `{"정부지원_현금": true, ...}`
모양으로 바꾸고, `orchestrate.판정(..., 사용자F값=그값)` 으로 넘긴다.

## 병합 순서 — 사용자 답변이 DB 값보다 우선
```python
f값 = f값_경로키(_f사실)              # DB 스냅샷(지난 판정 시점일 수 있다) 먼저 깐다
if 사용자F값:
    f값.update(f값_경로키(사용자F값))  # 방금 화면에서 답한 값이 최신이라 나중에 덮는다
```

## 🔴 실측 — 「답한 것은 즉시검증, 안 한 것만 인라인요청」
DB 없이 순수 함수 레벨로 재현했다(`전제해소`·`f값_경로키` 는 DB 인자를 안 씀 — `cur` 는
미매핑 적재에만 쓰이고 이번 케이스엔 안 걸린다):
```
_f사실 = {}                              (DB 에 아직 아무 값도 없다고 가정)
사용자F값 = {'정부지원_현금': 1000000}    (방금 심층질문에 답함)
전제목록 = [
  {사실:"정부지원 현금이 100만원을 넘는다", 매핑:['F1.정부지원.현금']},  # 답변으로 채워짐
  {사실:"겸직 여부",                       매핑:['F4.겸직']},           # 안 채워짐
  {사실:"알 수 없는 전제",                 매핑:[]},                    # 미매핑
]
결과:
  즉시검증   = ['정부지원 현금이 100만원을 넘는다']   ✅ 답한 것
  인라인요청 = ['겸직 여부']                         ✅ 안 한 것만
  미매핑     = ['알 수 없는 전제']
```
추가로 「DB 값보다 사용자 답변이 우선」도 확인함 — `_f사실={정부지원_현금:500000}` 위에
`사용자F값={정부지원_현금:2000000}` 을 얹으면 병합 결과가 2,000,000 (사용자 값)이 된다.
