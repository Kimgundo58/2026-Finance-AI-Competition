## 칸별 규칙 — 무엇을 넣나
| 칸 | 넣을 것 |
|---|---|
| 허용 | 가능/조건부/불가. 🔴 원문이 "집행불가"라고 «못 박은» 비목만 불가로 바꾼다 |
| 한도_유형 | 금액 / 비율 / 개수 |
| 한도_값 | 숫자만 (50, 300000, 1) |
| 한도_단위 | 🔴 **12자 이내**. `%`, `대/인`, `원/인/일`. 문장을 넣지 마라 |
| 사전승인 | 사전승인이 필요하면 true |
| 사전승인_조건 | 문장형 조건 전부. "협약기간 내 납품·사용 완료에 한해" |
| 금지예시 | 품목·행위 열거. "귀금속", "퇴직급여충당금" |
| 증빙 | 증빙서류 이름 배열 |
| 근거 | [{doc_id, 조번호}] — 어느 조에서 가져왔는지 |

🔴 **한 비목에 한도가 2개 이상이면** → 한도_값에는 «가장 자주 걸리는 하나» 만 넣고,

## 🔴 추가 — 제안 JSON 과 «같이» 내야 하는 계수 (중앙 요청, 0905 밤)

전량 run 을 돌리기 «전» 에 「이번 실험이 효과를 잴 수 있나」를 판단하는 근거다.
GPU 를 켜기도 전에 알 수 있어서 부분셋 시험($1.6)보다 싸다.

```
① 허용을 바꾼 행 수      조건부 -> 불가 가 몇 행 / 조건부 -> 가능 이 몇 행
② 그 행이 걸리는 골든 문항 수 = n   ← 🔴 게이트는 ①이 아니라 «이것» 에 걸린다
```

🔴 **①(행 수)로 판단하지 마라 — 0905 밤 실측으로 두 번 틀렸다.**
```
룰 행수  ->  걸리는 골든 문항 n  ->  실제 뒤집힌 문항 m      (m <= n)
                                     m 은 run 이 끝나야 안다
```
- **넓은 룰 1행이 좁은 룰 20행보다 크다.** 74행 중 **9행은 사업명이 NULL**(전 사업 공통)
  이고, 그 9행만으로 골든 **254/315** 에 걸친다. 행 수로 세면 이게 「9행뿐」로 읽힌다
- 그래서 계수기는 (사업명,비목) 쌍 조인 «과» 비목 단독 조인을 **둘 다** 센다

②의 조회 (읽기 전용):
```sql
SELECT count(*) FROM eval.golden_set g
WHERE (g.평가범위 IS NULL OR g.평가범위 NOT LIKE '범위밖%')
  AND (g.사업명, g.비목) IN ( (여기에 «허용을 바꾼» 행의 (사업명,비목) 을 나열) );
```

⚠️ 조인의 한계를 알고 써라 (실측):
```
채점대상 295 중  비목이 있는 것 258 · 사업명이 있는 것 269
서로 다른 (사업명,비목) 조합 = 81  (룰은 74행)
→ 비목이 없는 37문항은 이 조인으로 «안» 잡힌다. 그래서 ②는 하한에 가깝고,
   상한으로 쓰려면 「비목 없는 37건은 못 셌다」를 같이 적어야 한다
```

🔴 **n(②)이 5 이하면 전량으로도 효과를 못 잰다** — m <= n 이므로 대응비교 정지 조건
(뒤집힌 문항 5건 이하)에 반드시 걸린다. 이건 run 전에 «증명»되는 유일한 결론이다.
   그 경우 「이번엔 못 잰다」를 **run 전에** 중앙에 알린다. 룰은 넣되 효과 주장을 안 하면 된다.

🔴 **반대쪽은 증명되지 않는다.** n 이 커도 m 이 0 일 수 있다(룰을 바꿨는데 판정이 안 바뀜).
   그래서 계수기는 «✅ 측정 성립» 을 **절대 찍지 않는다.** 최선이 `⚠️ 못 잰다고 증명되지는
   않는다` 다 — **이 ⚠️ 를 통과로 읽지 마라. ✅ 를 기다리면 영영 안 온다.**

### 문서 밖에 하나 더 — 놓치기 쉽다

```
~/.claude/.../memory/rules-cannot-say-no.md
  "74행이 조건부 73·가능 1·불가 0" <- 작업이 성공하면 «이 기억이 틀린 게 된다»
  -> 고치거나 지운다. MEMORY.md 색인 줄도 같이
```

### 규칙

- **100줄 상한**을 지킨다. 넘치면 문장을 줄이는 게 아니라 문서를 쪼갠다
- **관측과 추론을 시각적으로 가른다** — 같은 어조로 붙여 쓰면 읽는 사람이 못 가른다
- 숫자는 **DB·run 출력에서 직접 뽑아 적는다.** 세션 보고서를 옮겨 적지 않는다
- 고친 파일마다 «무슨 근거로 바꿨나»(run 번호·쿼리)를 커밋 메시지에 남긴다
