## 2. 관측 — TIPS 내부에서도 «문맥별로 갈린다», 단일 오탈이 아니다

🔍관측 (문서에 실제로 그렇게 적혀 있다는 사실):
```
증빙서류가 다른 자리(붙임3 매칭표)   -> 분리      (연구재료비만 요구하는 증빙이 따로 있다)
공통 금지사유를 나열하는 자리(붙임3) -> 병합      (같은 사유가 둘 다에 적용되니 한 행으로 묶음)
사용기준 조문(16.)                   -> 병합      (①~⑥ 번호 하나로 묶여 있다)
산정기준 조문(11.)                   -> 분리
국가 공통 정산서식(별첨1·별지3[8])   -> 분리      (TIPS 가 만든 서식이 아니라 시행령 제26조 국가양식)
```
💭추론 (위 관측에서 내가 짐작한 것 — 문서가 직접 말한 게 아니다):
```
「16.이 병합한 이유는 ①~⑥ 번호매기기의 서술 편의로 보인다」— 16. 원문 어디에도
"편의상 묶었다"는 말은 없다. 다른 이유(예: 16.을 쓸 당시 참조한 판본이 병합형이었다 등)일
수도 있다. 확인된 것은 «금액이 실제 갈리는 자리(증빙·정산)에서는 TIPS 자신도 항상 분리해서
쓴다»는 관측뿐이고, 「병합은 서술 편의에서만 나온다」는 그 관측에 대한 내 해석이다.
```

## 3. 갈래별 결과 — 오너가 고를 때 실제로 갈리는 것

### 11.(분리) 를 정본으로 택하면
- 내 산출 17건 중 **비목="연구시설·장비비 및 연구재료비" 로 묶인 3건**이 영향을 받는다
  - 근거 11.의 연구시설·장비비 정의 1건 → 비목 "연구시설·장비비" 로 재라벨(그대로 옮기면 됨)
  - 근거 11.의 연구재료비 정의 1건 → 비목 "연구재료비" 로 재라벨(그대로 옮기면 됨)
  - 근거 16.의 병합 조문 발췌 1건("③ 연구시설·장비비 및 연구재료비\n㉮ 기술개발사업과...") →
    **둘 중 어느 쪽에도 깔끔히 안 붙는다** — 원문 자체가 병합 표현이라 그대로 두면 정본(분리)과
    문구가 어긋난다. 처리 방법(양쪽에 중복 배치 / 그대로 두고 "원 조문은 병합형" 주석만 붙임)은
    오너 결정 필요
- 상위 규범(시행령·사용기준고시·국가 정산서식) 과 일치한다

### 16.(병합) 을 정본으로 택하면
- 내 17건은 그대로 둔다(재라벨 0건)
- 시행령 별표2, 사용기준고시 제8·9·23·24조, 국가 공통 정산서식(별첨1·별지3[8]) 과는
  **항목 개수가 안 맞는다** — 정산서식에 "3) 연구시설·장비비 / 4) 연구재료비" 두 줄로
  금액을 따로 적어야 하는데, 우리 쪽 비목 정의가 하나면 그 두 줄에 각각 얼마를 적을지
  나눌 근거가 우리 데이터엔 없다

## 4. 매핑 금지는 그대로

이 문서는 TIPS 내부 경계(11. vs 16.)만 다룬다. TIPS 비목을 창업 계통 10종에 매핑하는 것은
여전히 오너 확정 사항(안 함)이며, 이 조사와 무관하게 유지된다.
