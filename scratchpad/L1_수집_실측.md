## 지켰다 — 확인
```
· 로그인·결제·우회 필요 자리 — «없었다»(TIPS DRM 은 뚫으려 시도 안 하고 멈췄다.
  🔴 TIPS는 오너 지시로 «미결 — 더 조사 안 함», 이번 재조사 대상 아님)
· 원본 삭제 — 전부 세션 임시폴더($TMP)에만 있고 프로젝트에 반영 안 함, 적재도 안 함
· 실패 갈래 구분 — 「목록에 없음」(창업중심대학, 두 목록 400+건 전수조사 후 확정)
  vs 「받았고 완전일치」(모두의창업, 재조사로 이번에 뒤집힘 — 처음엔 "JS라 못 뚫음"
  이었으나 실제로는 평범한 GET+ajax 였다) vs 「받았는데 DRM」(TIPS, 미결) 을 각각
  다르게 적었다
· 사이트 두드리기 — kised 2회(mid 두 개) + k-startup 상세/ajax/파일 각 1회 +
  목록 4회(검색 2회는 0건 확인용, big 2회는 200건씩). 병렬 없이 순차로,
  User-Agent 명시(Mozilla/5.0), Referer 항상 포함, 세션 쿠키는 warm-up 1회만
  시험(효과 없었음 확인 후 중단 — 로그인 우회 시도 아님, 검색기능 자체가 GET
  파라미터 방식이 아니었을 뿐)
```
