## 1. docs/6_LLM/6-3_평가와_정답셋.md — 한 줄 추가

> **`설정.정답고정.지문` 이 다른 두 run 은 hit@k·일치율을 빼면 안 된다.**
> 코퍼스가 같아도 정답 청크 집합이 다르면 같은 것을 잰 게 아니다.
> 지문이 «없는» run(≤195)은 이 지문이 생기기 전 run 이다 — 소급해 채우지 않는다.

근거 — 0단계 표복구 실측
```

run 195 정답고정 = "eval.golden_chunks(D3)"    글자 하나 안 다르다
그 사이/이후 golden_chunks 404행 -> 399행, gold 380·389 가 조번호 -> 원문일치
= 정답 청크 집합이 달라졌는데 라벨은 그대로였다
run 196 정답고정 = {"표":"eval.golden_chunks(D3)", "지문":"g399-f6-q315-144be751"}
```
