# S3 보고 — 판정 경로 (Q2·Q3·R7)  2026-09-03

## ① 바꾼 것 — `server/main.py` 세 자리
- `_실_판정` **Q2** `orchestrate.판정(..., _비목고정=body.확정비목 or None)`
- `_실_판정` **R7** 확정비목이 `정규화.비목후보` 밖이면 `전제` **맨 앞**에 한 줄(새 이벤트 없음).
  `{사실, 근거조항:null, 매핑:[], 미충족시:"판단불가"}` — 후보가 비었거나 확정비목이 없으면 안 붙는다
- `_실_정규화` **Q3** 폼 `비목후보` 를 LLM 1회로 채운다(헬퍼 `_폼_비목후보()` 신설) + 내부 키 `누락필드`·`_출처` 제거. **소유 밖은 안 건드렸다**

## ② 태워 본 결과 (DB 살아 있음 / vLLM **죽어 있음** → 가짜 vLLM 스텁으로 배선까지만 태움)
| 사례 | 입력 | 출력 |
|---|---|---|
| 폼 정규화 | LLM 이 `기계장치.71·회식비.66(enum밖)·재료비.22·지급수수료.05` 4건 | 후보 3건, **전부 enum 안**(회식비 탈락) |
| 폼 정규화 | LLM 연결거부 | `비목후보:[]` 로 물러남, 다른 키 전부 살아있음 (정규화 200 유지) |
| 판정 ① | 확정비목 `기계장치`(후보 안) | `_비목고정=기계장치` 전달, 경고 **없음** |
| 판정 ② 🔴 | 확정비목 `지급수수료`(후보 밖) | `_비목고정=지급수수료` 전달, 전제[0] 에 경고, 기존 전제는 뒤로 밀림 |
| 판정 ③④ | 후보 `[]`+확정비목 있음 / 확정비목 `None` | 둘 다 경고 없음 (`_비목고정` 은 각각 값·None) |
| 판정 (실경로) | ② 를 `SUDDOE_MOCK=0` 으로 SSE 왕복 | 200, 경고 실림. 판정값은 **가짜 LLM 이라 판단불가** — 품질 아님 |
- 프롬프트에 `_합성_질문()` 문장이 안 들어간 것을 실제 전송 본문으로 확인했다(품목·금액·용도·사업명 줄로만 감)

## ③ SSE 캡처 대조 (코드 읽기 아님 — `r.text` 파싱)
- judge, 목·실 **양쪽 모두**: `진행→진행→진행→판정→해야할일→인용→전제→참조사슬→결과→저장→완료` = 계약과 일치
- normalize, 폼·자연어 **양쪽 모두**: `진행→필드×5→결과→완료` 로 동일
- 닻을 바꿔 대조: `tests/test_contract.py` 의 `계약` 표를 직접 읽어 → **빠짐 0 · 늘어남 0**. `--selftest` 도 전부 통과 (pytest 는 금지라 안 돌렸다)

## ④ 목/실 남은 차이
- **키는 이제 완전히 같다** (정규화 11키 · 판정 8키, 목=폼=자연어). 값만 다르다
- 🔴 **R7 경고는 목 모드에 안 나온다** — `_실_판정` 안에 있고 목은 그 함수를 안 탄다.
  둘 다 덮으려면 `judge()` 의 `yield _sse("전제", ...)` 바로 앞이 맞는 자리인데 **내 소유 밖이라 손대지 않았다. 승인 요청**

## ⑤ 프론트에 알려야 할 응답 변화
1. 폼 경로 `/api/normalize` 의 `비목후보` 가 이제 **채워져 온다** (전엔 항상 `[]`). 화면 9 기본 선택에 쓸 수 있다
2. `/api/judge` 의 `전제` 첫 줄이 «사용자가 후보 밖 비목을 골랐다» 경고일 수 있다. 키 모양은 기존과 같다
3. 실서버 정규화가 목엔 없던 `누락필드`·`_출처` 를 몰래 싣고 있었다 → **뺐다**. 쓰고 있었다면 알려달라
4. 확정비목이 판정 결과를 실제로 바꾼다 — 같은 정규화라도 비목이 다르면 다른 판정이 나온다(캐시 열쇠엔 이미 들어 있었다)

## ⑥ 미검증 — 실물 LLM 이 없다
- vLLM 연결거부(포트 8000). Q3 프롬프트가 **실제 Qwen 에서 뭘 뽑는지 안 봤다** — 검증한 건
  «배선·스키마·enum 필터·실패 시 물러남» 이지 «비목이 맞다»·«판정 4-way 값» 이 아니다
- 🔴 «코드가 바뀌었다» 는 «판정이 나아졌다» 의 증거가 아니다. GPU 뜨면 골든셋으로 다시 재야 한다
- `_비목고정` 이 엔진 안에서 후보를 필터하는 동작은 이미 측정된 사실로 받고 다시 안 쟀다 (내가 잰 건 «넘어간다» 까지)
