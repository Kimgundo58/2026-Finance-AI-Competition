# 인F — LibreOffice+H2Orestart 헤드리스 HWP→PDF 조사 (2026-09-06)

## 결론
🔴 **못 쓴다.** 테스트한 4건 전부 「지금 한컴 산출물과 표가 같은가」를 통과 못 했다
(기준: 표가 하나라도 다르면 못 쓴다). 이번 대회 범위 밖 산출물이라 지침대로
파이프라인엔 손 안 댔다.

## 설치 절차 (이 세션에서 직접 실행·확인함)
```
1. winget install --id TheDocumentFoundation.LibreOffice --silent
     -> LibreOffice 26.8.0.3, ~530MB, 관리자 권한 필요 (VCRedist 종속)
     🔴 이 머신에 지금 설치된 채로 남아있다 — 정리 필요하면 알려달라
2. GitHub ebandal/H2Orestart 최신 릴리스(v0.7.13, 2026-06-27) .oxt 다운로드
     https://github.com/ebandal/H2Orestart/releases/latest
3. unopkg add "H2Orestart.oxt"
     🔴 --shared(전체 사용자) 는 관리자 쓰기권한 없어 실패
     세션 전용 프로필(-env:UserInstallation=...claude_lo_test_profile)에 개인 설치로 우회 성공
     unopkg list 로 등록 확인함 (ebandal.libreoffice.H2Orestart 0.7.13)
4. 변환: soffice --headless --norestore -env:UserInstallation=<프로필> 
          --convert-to pdf --outdir <출력폴더> "파일.hwp"
     4건 전부 에러 없이 PDF 생성됨 (exit 0) — "변환 자체"는 된다
```

## 대조 대상
`_hwp변환/` (한컴오피스 수동변환 산출물, 현재 파이프라인 기준) vs 세션에서 만든 LO 변환본.
표 추출은 pdfplumber(요구사항 고정버전 0.11.10, 이 조사 전용 --user 설치, 프로젝트 venv 안 건드림).
HWP 원본 + 한컴 PDF가 둘 다 있는 문서 4건으로 좁혀졌다 — 나머지 사업(창업도약·창업중심대학·
모두의창업·TIPS·재도전2026·초격차제10차)은 이 저장소에 원본 HWP 가 없거나(PDF만 조달됨)
이미 HWPX 라 이 조사 범위 밖이다.

| 문서 | 한컴 쪽수/표수 | LO 쪽수/표수 | 표 개수 일치 | 텍스트 완전일치 |
|---|---|---|---|---|
| 예비창업 2025 | 9 / 13 | 18 / 14 | 🔴 불일치 | 0/13 |
| 초기창업 2025 | 10 / 14 | 19 / 15 | 🔴 불일치 | (미측정, 개수부터 다름) |
| 재도전 2025 | 7 / 6 | 12 / 6 | ✅ 일치 | 0/6 |
| 초격차 2025 | 10 / 48 | 53 / 47 | 🔴 불일치 | (미측정, 개수부터 다름) |

## 관측 (측정값)
- 쪽수가 4건 전부 부풀었다 (2.0배·1.9배·1.7배·5.3배) — LO 산출물이 원본보다 훨씬 길다
- 표 개수가 같았던 유일한 문서(재도전)도 표 6건 중 텍스트 완전일치 0건
  - 표[2]: 한컴본은 외주용역 점검항목 7개가 한 셀에 다 들어있는데, LO본은 첫 항목만
    남고 나머지가 표 구조 밖으로 흩어졌다 (셀이 «잘렸다», 요약이 아니다)
  - 표[1]: 특수기호 글자가 다른 유니코드로 재매핑됐다 (`` → `\U000f02ef`,
    둘 다 사용자정의영역PUA 코드포인트라 원문과 다른 코드값이면 검색·비교가 깨진다)
  - 나머지 4건도 헤더 텍스트가 표 슬롯째로 밀려 있다 (표[3]~[5])

## 추론 (관측과 갈라 씀 — 확정 안 됨)
- 쪽수 팽창의 유력 후보는 **폰트 이름 불일치**다. 이 머신엔 Hancom Office 가 깔려있어
  HANBatang·HANDotum(함초롬 계열로 추정되는 파일) 이 Windows 폰트로 실제 있다 —
  그런데도 부푼 걸 보면, HWP 내부가 참조하는 한글 폰트명과 시스템 등록명이 안 맞아
  LibreOffice 가 폭이 다른 대체 폰트로 렌더링했을 가능성이 크다
  🔴 폰트 치환 로그를 직접 떠서 확정하지는 않았다 — 시간 예산상 4건 표 대조까지가
  이번 조사의 목표였다
- H2Orestart 는 공식 문서상 **HWP v5 만 지원**(v3 는 안 됨). 이 저장소 HWP 가 전부
  v5 인지는 개별 확인 안 했다

## 못 한 것
- 폰트 치환을 직접 맞춰서(Tools>Options>Fonts 치환표) 재시도하는 실험 — 안 함
  (대회 범위 밖이라 시간을 더 안 썼다. 됐다면 결론이 바뀔 여지는 있다)
- 나머지 34건(38건 중 4건만 테스트)은 원본 HWP가 이 저장소에 없어 대조 불가
- HWPX 경로(초격차 제10차 등)는 이 조사 대상이 아니다 (질문이 HWP→PDF 한정)

## 산출물 정리 상태
- LibreOffice 26.8.0.3: 이 머신에 **설치된 채로 남아있다** (winget, 시스템 전역)
- H2Orestart: 세션 임시 프로필에만 설치, 기본 프로필엔 없음
- 변환 PDF 4건 + 대조 스크립트: 세션 임시 폴더(AppData\Local\Temp\lo_out, ...\scratchpad)에만
  있고 저장소엔 안 넣었다
- 🔴 정리(LibreOffice 제거 등) 필요 여부는 오너 판단 — 임의로 지우지 않았다
