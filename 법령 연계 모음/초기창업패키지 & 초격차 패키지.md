# 세부관리기준 파일별 참조 법령·행정규칙 정리

- 대상: 초기창업패키지 세부관리기준 3개년(2023·2024·2025), 혁신분야 창업패키지(신산업) 2023, 초격차 스타트업 1000+ 프로젝트 2024·2025·제10차 개정안 — 총 7개 파일
- 검토 방법: HWP/HWPX 전문(본문·표·붙임·양식 포함) 텍스트 추출 후 통독 + 패턴 검색 교차 확인
- 표기: **법령** = 법률·대통령령, **행정규칙** = 지침·요령·고시, **기타** = 법령은 아니나 외부 기준·시스템을 준용하는 것
- "조항 미특정"은 법령명만 있고 조문 번호가 없는 경우
