# 문서_법령_링크모음

창업지원사업 세부관리기준(초기창업패키지·초격차·예비창업·재도전·창업도약·창업중심대학·모두의 창업·민관 TIPS) 관련 자료 6건에서 추출한 외부 법령·행정규칙을 **law.go.kr Open API 검색 키워드 기준**으로 통합 정리한 문서.

- 통합 원본: `초기창업패키지 & 초격차 패키지.md`, `예비창업패키지.pdf`, `재도전성공패키지.pdf`, `모두의_창업_프로젝트.pdf`, `창업중심대학 & 창업도약패키지.pdf`, `민관TIPS.pdf`
- **§1 마스터 목록**: 중복 제거한 법령·행정규칙 전체. `검색키워드` 열의 문자열을 그대로 `query=`에 넣으면 됨 (법령명한글 완전일치 기준).
- **§2 law.go.kr에서 찾을 수 없는 항목**: 크롤링 대상에서 제외하거나 별도 수집처 사용.
- **§3 문서별 참조 조항**: 원본 자료별 상세.

Open API 호출 형식 (참고)
- 법령 목록: `https://www.law.go.kr/DRF/lawSearch.do?OC={ID}&target=law&type=XML&query={검색키워드}`
- 법령 본문: `https://www.law.go.kr/DRF/lawService.do?OC={ID}&target=law&type=XML&ID={법령ID}` (조문 단위 `JO=000767` 형식 = 제767조)
- 행정규칙 목록: `https://www.law.go.kr/DRF/lawSearch.do?OC={ID}&target=admrul&type=XML&query={검색키워드}`
- 웹 직링크: 법령 `https://www.law.go.kr/법령/{검색키워드}` / 조문 `https://www.law.go.kr/법령/{검색키워드}/제767조` / 행정규칙 `https://www.law.go.kr/행정규칙/{검색키워드}`
