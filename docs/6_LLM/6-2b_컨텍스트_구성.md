# 6-2b. 컨텍스트 구성 (B0~B6)

이 문서가 답하는 질문:
- 판정(④) 프롬프트는 어떤 블록을 어떤 순서로 넣나
- B0 시스템 지시는 불가와 조건부를 어떻게 구분하나
- B4 룰 결과와 B5 기업 프로필에는 무엇이 들어가나

> 출력 JSON 형식·인용·인젝션 방어는 [[6-2_출력_스키마]].

## 4. 컨텍스트 구성 B0~B6

| 순서 | 블록 | 데이터 출처 |
|---|---|---|
| B0 | 시스템 지시(고정) | 고정 |
| B1 | L3 원문 + 문장 ID | RAG(`l3_articles`) |
| B2 | 검색 원문 top-5 + 문장 ID | RAG(`chunks`) |
| B3 | 참조 확장(깊이1) + 문장 ID | RAG(`refs`) |
| B4 | 룰 결과(비교 끝난 문장, 원시값 금지) | RULE |
| B5 | 기업 프로필 요약(누락 표시) | 기업 프로필 |
| B6 | 질문+지시(맨 뒤 고정) | (1) 출력 |

코드: `scripts/assemble_context.py` · `프롬프트_구성()`
```python
    블록: list[str] = [시스템_프롬프트]
    if l3:
        블록.append(_기관규정_블록(번호, l3))
    if 검색:
        블록.append(_검색규정_블록(cur, 번호, 검색))
    if 참조확장:
        블록.append(_참조조항_블록(cur, 번호, 참조확장))
    if 룰결과:
        블록.append(_룰요약_블록(룰결과))
    if 프로필요약:
        블록.append(_프로필요약_블록(프로필요약))
    ...
    블록.append(_질문_블록(질문, 정규화, _s(번호.n)))
```

B0 판정 정의에 "불가/조건부 구분선"이 있다.
"조건·한도·사전승인·증빙이 붙으면 조건부"만으로는 546·615처럼 계획 자체가 위반인 건도
"조건을 붙이면 되는 것"으로 읽힐 수 있어, 문구를 이렇게 정의한다: "조건부 = 질문에 적힌 계획을
그대로 두고 절차만 더하면 되는 경우 / 불가 = 계획대로 하면 위반이 확정되는 경우도 불가다 —
시점·규모·대상 같은 계획 자체를 바꿔야 한다면 조건부가 아니다." + 경고 "불가한 것을
조건부라 답하는 것도 같은 오답이다"("불가를 가능이라"뿐 아니라 "불가를 조건부라"도 오답으로
잡는다 — 골든셋 불가 182·룰 불가 0 의 조건부 편중이 이 비대칭에서도 왔다). V4(판단불가 유도를
약화한 프롬프트 버전)는 이 경고를 별도 문단으로 분리해 두 기준이 섞이지 않게 했다(B0 현재 길이 850자).

코드: `scripts/assemble_context.py` · `시스템_프롬프트`
```python
  조건부    허용되나 조건·한도·사전승인·증빙이 붙는다.
            질문에 적힌 계획을 그대로 두고 절차만 더하면 되는 경우다
  불가      규정이 금지하거나 한도를 넘는다.
            질문에 적힌 계획대로 하면 위반이 확정되는 경우도 불가다 —
            시점·규모·대상 같은 계획 자체를 바꿔야 한다면 조건부가 아니다
...
"불가한 것을 조건부라 답하는 것" 도 같은 오답이다. 조건을 붙이면 될 것처럼 적으면
사용자는 그대로 집행한다.
```

B5 는 없는 컬럼(`협약총액`)을 물어 항상 `None`이었고, 그 실패가 트랜잭션을 중단시켜 뒤의
모든 조회(검증·전제확인·증빙_발급처·decisions 기록)까지 빈 결과를 반환했다. 컬럼을 바로잡고
실패해도 트랜잭션을 롤백 후 복구하게 고쳤다 — 협약기간·정부지원액이 프롬프트에 **처음으로** 포함된다.

B4 금지예시 상한 기준은 "토큰"이 아니라 "생략된 항목을 게이트 A 가 대신 걸러 주는가"다. 옛 방식(앞 8개만 포함하고
나머지 "외 N종")은 생략된 항목에 **예외단서 붙은(조건부)**
항목이 섞이면 게이트 A(금지목록, 무조건 항목만 즉시 반환)가 걸러내지 못해 '가능' 오판으로 이어진다. 지금은 **예외단서
붙은 항목은 개수와 무관하게 전부 포함하고, 무조건 항목만 8개로 제한한다**("외 N종"도 무조건분만
센다). 허용예시는 상한 대상이 아니다(조건부/무조건 판별기가 허용예시엔 없다). 실측: 생략되는
금지예시 119→99개, 그중 조건부 11→0개.

코드: `scripts/rule_lookup.py` · `_예시_문장()`
```python
        분류 = [(x, 금지예시_파싱(x)["무조건"]) for x in 목록]
        무조건 = [x for x, 무 in 분류 if 무]
        남음 = max(0, len(무조건) - 최대)              # 잘리는 것은 무조건 항목뿐이다
        표시할_무조건 = 무조건[:최대]
        보임 = [x for x, 무 in 분류 if not 무 or x in 표시할_무조건]   # 원래 순서 유지
```

문장 ID 는 항 단위 부여, B1→B2→B3 통합 연번. 매핑표에 없는 인용은 (6)에서 폐기(환각 차단).

코드: `scripts/assemble_context.py` · `_문장ID_생성기.원문블록()`
```python
        줄 = [f"## {제목}", 래퍼_시작]
        for 종류, _id, 표시헤더, 본문, 항호 in 항목들:
            ...
            for 항, 조각 in 항_분할(본문):
                self.n += 1
                ...
                self.문장맵[_s(self.n)] = (종류, _id, 키)
                줄.append(f"[{_s(self.n)}] {표시헤더}\n{조각}")
        줄.append(래퍼_끝)
```
