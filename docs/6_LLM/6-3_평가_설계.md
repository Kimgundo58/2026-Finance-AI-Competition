# 평가 설계

이 문서가 답하는 질문:
- 무엇으로 채점하는가
- 지금 점수는 얼마고 어떻게 읽어야 하는가
- run 을 언제 비교해도 되는가

> 정답셋(golden_set) 자체가 어떻게 구성·재구축됐는지는 [[6-3b_정답셋_관리]].

## 1. 지표

| 지표 | 정의 |
|---|---|
| 치명 오답률 | 정답 불가/조건부인데 "가능" — 1순위 |
| 판정 일치율 | 4-way 일치 |
| 인용 정확도 | 인용 조항이 실제 근거인가(사람 채점) |
| 판단불가율 | 최소화 아니라 균형 — 0%면 원칙 위반, 50%면 제품 가치 상실 |

선택 기준: 치명 오답 0 제약 하에서 판단불가율 최소. 기준은 결과를 보기 전에 정한다.

## 2. 실측 (2026-09-01, `eval.runs` run_id=189)

⚠️ **최신은 run_id=202 (320문항 · 67.5% · 다수결기준선 59.8 · +9.5)** — 수치는 [[0_현황]]이 기준.
run_id=191(93문항)은 그 아래 옛 산출로 남긴다(비교하지 않는다, 세트 구성이 다르다).
🔴 **정정(2026-09-07)** — `채점대상` 컬럼은 치명오답 판정 코드에서 **안 읽힌다**(이전 진단
오류). 치명오답은 코드 정의(1건)·넓은 정의(25건) 두 갈래로 따로 센다 — [[기록/2026-09-07]].

```text
                     격리(D6)      실전 E2E(A12-V0)
  판정 일치율         84.7%   ->    67.5%
  치명 오답률          0.0%   ->     0.0%
  인용 정확도        100.0%   ->    29.7%
  판단불가율           0.0%   ->     6.5%
```

모델 `Qwen/Qwen3-32B-AWQ` · vLLM 0.11.0 · `guided_json` · temperature 0(배포 구성 그대로,
그 경로가 살아있던 시점의 실측 — 지금은 DashScope Qwen3.7-plus, [[6-1b_LLM_백엔드]]).

판단불가 5건은 `max_tokens=1500` 잘림이다 — 모델이 스스로 판단불가를 고른 횟수는 0.
인용 정확도 29.7%는 검색이 만든 숫자다(검색 hit@5 55.4%). 프롬프트로는 못 고친다.
판단불가율은 모델선택과 실패경로로 갈라 센다. 지금 6.5%는 전부 실패경로다.

**2026-09-02 실측: 정답셋은 113행이고 채점 분모는 93이다.**
재도전 6 · TIPS 2 문항이 이미 들어와 있다. 재도전·TIPS 0건이라는 서술은 낡았다.
남은 미측정은 L3 오버레이와 숨은 한도다.

## 3. 운영 규칙

무엇이든 바꾸면 정답셋 재실행 — **점수 없이 머지 금지.** 모델 비교 시 검색 결과를 고정한다.
조건이 다른 run 끼리 비교 금지(`eval.runs.설정`에 사업필터·정답출처·분모·규정 모음 버전이
전부 박혀 있다).

🔴 **2026-09-06 — 한 세션 안에서 경계선이 여럿 생겼다.** 아래 중 하나라도 다르면 그 run 은
이전 run 과 "조건이 다른 run"이다. `eval.runs.설정`에 다 안 박혀 있을 수 있는 것도 있으니
비교 전에 날짜·커밋으로 직접 갈라라:
```
① B0 정의    407자(~09-05) → 644자(`7736797`) → 850자(`c13526e`, 불가/조건부 구분선)
② 배관 개방  「폐포 없이 먼저 판정하고 모자라면 붙여 다시」(④') — 호출수 상한 3회 고정
③ 사전승인_조건 병합  first-non-null → UNION(`8ae285f`) — 외주용역비 등 21개 조합 문구 증가
④ 캡 기준    토큰 → 안전망 유무(`72a5fb7`) — 금지예시 조건부는 항상 전부 싣는다
⑤ 코퍼스 변경  금지예시 294→358·허용예시→225([[5_룰/5-1_룰_테이블]] §3-2) ·
             golden_set verified 113→307·정답판정 5건 변경(545·546·566·615·552, [[6-3b_정답셋_관리]])
```
run 을 비교하려면 최소한 이 다섯 축이 같은 커밋 시점인지부터 확인한다.
