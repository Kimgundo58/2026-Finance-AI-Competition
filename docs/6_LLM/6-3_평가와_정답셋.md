# 평가와 정답셋

이 문서가 답하는 질문:
- 정답셋은 어떻게 구성되는가
- 무엇으로 채점하는가
- 지금 점수는 얼마고 어떻게 읽어야 하는가

## 1. 정답셋 구성 — 목표 70±

| 구성 | 문항 | 채점 |
|---|---:|---|
| 별첨4(창진원 공식 답변) | 7 | 판정 일치율 + 인용 정확도 |
| 직접 작성(창업기업 유효분) | 33 + 공통1 | 판정 일치율 + 인용 정확도 |
| 적대적(부정행위 사례집 변환) | 27 | 치명 오답률 |
| 연구재단 QA 홀드아웃 | 10~15 | 인용 정확도만(도메인 불일치) |

전량 `verified=true`(2026-08-31, `eval.golden_set` 77행, 본세트50/적대적27).
정답판정 분포: 불가52 / 조건부23 / 가능2 — "가능"이 2건뿐이라 치명 오답률 측정에 맞다.
**검색 대상에 넣기 금지**(정답 유출, 항구적). 연구재단 QA 는 홀드아웃을 뗀 나머지만 사례 인덱스로.

## 2. 지표

| 지표 | 정의 |
|---|---|
| 치명 오답률 | 정답 불가/조건부인데 "가능" — 1순위 |
| 판정 일치율 | 4-way 일치 |
| 인용 정확도 | 인용 조항이 실제 근거인가(사람 채점) |
| 판단불가율 | 최소화 아니라 균형 — 0%면 원칙 위반, 50%면 제품 가치 상실 |

선택 기준: 치명 오답 0 제약 하에서 판단불가율 최소. 기준은 결과를 보기 전에 정한다.

## 3. 실측 (2026-09-01, `eval.runs` run_id=189)

⚠️ **최신은 run_id=191 (93문항 · 65.6% · 기준선 +12.9 · 치명 0 · 프롬프트 초과 0)**. 더 최신 run 이 있을 수 있다 — 지금 어디까지 됐는지는 [[0_현황]]과 대조한다.

```
                     격리(D6)      실전 E2E(A12-V0)
  판정 일치율         84.7%   ->    67.5%
  치명 오답률          0.0%   ->     0.0%
  인용 정확도        100.0%   ->    29.7%
  판단불가율           0.0%   ->     6.5%
```

모델 `Qwen/Qwen3-32B-AWQ` · vLLM 0.11.0 · `guided_json` · temperature 0(배포 구성 그대로).

🔴 판단불가 5건은 `max_tokens=1500` 잘림이다 — 모델이 스스로 판단불가를 고른 횟수는 0.
🔴 인용 정확도 29.7%는 판정 단계가 아니라 검색이 만든 숫자다(검색 hit@5 55.4%) — 프롬프트로
   못 고친다.
🔴 판단불가율은 «모델선택/실패경로»로 갈라 센다 — 지금 6.5%는 전부 후자.
🔴 정답셋 77문항은 표본이 좁다(사업 6종·org 없음) — 재도전·TIPS·L3오버레이·숨은 한도 미측정.

## 4. 운영 규칙

무엇이든 바꾸면 정답셋 재실행 — **점수 없이 머지 금지.** 모델 비교 시 검색 결과를 고정한다.
조건이 다른 run 끼리 비교 금지(`eval.runs.설정`에 사업필터·정답출처·분모·규정 모음 버전이
전부 박혀 있다).
