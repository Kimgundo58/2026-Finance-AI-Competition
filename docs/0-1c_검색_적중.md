# 0-1c. 검색 적중 — 어디서 못 닿나

> 판정 정확도 본문은 [[0-1_판정_정확도]]. 여기는 «근거에 닿는가» 만 둔다.
> 🔴 **닿는 것과 맞히는 것은 다르다** — 도달은 적중의 거의 필요조건이지 충분조건이 아니다.


🔴 **분모가 오염돼 있다** — 골든셋 315 중 **60건이 정답 근거에 «구조적으로»
도달 불가**다(P1 적용대상형 22 · P2 포인터형 38). P2 는 진입점 조가 순수 포인터라
어떤 임베딩으로도 안 뜬다(실측 도달 1/38). 실제 검색 성능은 **295−38=257 분모**로 다시
재야 한다. 처방은 임베딩 튜닝이 아니라 **인덱싱 설계**다.
상세는 `scratchpad/골든셋검토_G1_구조적미스.md`.

🔴 **2026-09-06 갱신 — 이 절의 63.2%/64.7%/47.1%/22.2%(길이구간)·문서별 수치는
run194(근거적중 51.3%) 조건에서 잰 것이다.** run195 은 근거적중 70.3%로 올랐다
([[0-1_판정_정확도]] 참고 — 실패경로 축소가 주 원인). 길이구간·문서별 세부 분해는
run195 기준으로 재측정하지 않았다 — **확인불가로 남긴다.** 아래 숫자를 run195 의
70.3%와 나란히 놓고 「그때도 지금도 이 분포」로 읽지 마라.

🔴 **기각된 가설**: 「긴 청크가 임베딩 1024토큰 캡에 잘린다」 — 15,945자짜리도 761토큰.
캡 근처도 안 간다.
