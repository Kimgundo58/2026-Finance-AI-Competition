# 9-2. 백엔드 · 프론트 미결

백엔드에서 사람이 정해야 하는 것과, 프론트 문서끼리 충돌하는 것을 모았다.
상세는 `docs/7_백엔드/` 에 있다. 아래는 2026-09-02 밤 기준으로 열린 것이다.
법적 지적사항은 [[9-1_법적_지적사항]], 제품·설계 미결은 [[9_미결]] 에 있다.

## 열린 항목

| # | 항목 | 상태 |
|---|---|---|
| BE1 | 게스트를 `expense_plans` 에 무는 방법 | 오너 판단 대기 |
| BE2 | AI CHAT(화면 12)을 만드는가 | 문서 넷이 서로 반대 |
| BE3 | `db/init/04_agent.sql:14` 의 `\set ON_ERROR_STOP on` 을 지울 것인가 | 실 배포 영향 없음 |
| BE4 | `org_id` 가 인증이 아니라 자기신고다 | 인증 설계가 선행조건 |
| BE5 | 쓰기 IDOR 3곳 | BE4 와 같은 뿌리 |

BE1 은 `org_id` 가 uuid + FK 라 `guest_<hex>` 가 타입에서 거부된다(실측).
제3안(nullable `guest_key TEXT`)은 테넌시 축이 둘이 되고 RLS 가 그 축을 안 본다.

BE3 은 `psql` 전용 문법이다. 리포에 psycopg 로 `db/init` 을 태우는 코드가 없어 실 배포 경로에
결함은 없다. 재현 도구를 짜는 사람만 걸린다.

## BE4 · BE5 — 신원이 자기신고다

`org_id` 를 쿼리 파라미터로 받는다. 남의 uuid 를 알면 그 기관 계획을 읽고 할일을 쓸 수 있다
(실측 200/200/201).

지금 만든 것은 스코핑 필터다. 정직한 호출자에게 남의 것이 안 섞인다는 뜻이고, 접근 제어는 아니다.
완화 요인은 `org_id` 가 122비트 uuid 이고 이를 노출하는 엔드포인트가 0개라는 것뿐이다.

🔴 **화면 3(기관 선택)용 기관 목록 API 가 `org_id` 를 실어 내보내는 순간 그 방어가 사라진다.**
그 API 를 만드는 사람이 이 항목을 반드시 봐야 한다.

RLS 는 받쳐주지 않는다. 2026-09-02 실측으로 지금 아무것도 안 막는다.
이유가 둘이고 각각 단독으로 충분하다.

1. `tenant` 11개 표 전부 `relforcerowsecurity=false` 라 소유자에게 정책을 강제하지 않는다
2. 앱이 `postgres` 로 붙는데 그 롤은 `rolbypassrls=true` 다. `FORCE` 를 켜도 우회된다

정책을 무시하고 `l3_articles` 17행이 그대로 보인다.
실질 방어는 애플리케이션 `WHERE` 하나뿐이고, 그 `WHERE` 가 자기신고 `org_id` 를 믿는다.
두 약점은 직렬이 아니라 같은 지점이다.

BE5 의 쓰기 IDOR 은 세 곳이다.

- `POST /api/l3/upload` — `org_id` 를 믿어 남의 기관 이름으로 문서를 올린다(202 + 그 org 로 행 생성)
- `POST /api/plans` — body 의 `org_id` 를 검증 없이 쓴다
- 할일 쓰기 경로 — 쿼리 `org_id` 를 믿는다

🔴 **셋 다 뿌리가 BE4 라 개별 패치가 아니라 신원 검증 한 곳으로 풀어야 한다.**
낱개로 두면 또 하나씩 새로 발견된다.

## BE2 — 프론트가 앞서 있고 백엔드가 못 받는다

> **정정 (2026-09-02).** 이 항목은 원래 데이터요구서 하나만 계약 반대편이고 안 만드는 쪽이 맞다였다.
> 그 판단이 틀렸다. 프론트 실물 번들(101,215자)을 받아 대조하니 다섯 다 이미 만들어져 있었다.
> `데이터요구서_0901` 은 계약과 싸운 것이 아니라 만들어진 프론트를 받아적은 것이었다.
> 구현하지 마라는 지시는 이미 만든 걸 버리라는 말이 되어 철회한다.

| # | 화면 | 프론트 실물 (번들 실측) | 서버 |
|:--:|:--:|---|---|
| 1 | 12 | AI CHAT UI 완성 (물어보기·전송·quick-reply) | 경로 없음 |
| 2 | 13 | 집행일정 쓰기 완성 (추가 5회·저장·삭제·완료) | 표시만 |
| 3 | 9 | 지급수수료 하위 16종 배열 실재 | `/api/vocab` 10종 |
| 4 | 4 | `accept:.pdf,.hwp,.hwpx,.doc,.docx` | DOC·DOCX 415 |
| 5 | 4 | 첨부 3MB · 최대 10개 | 30MB — 실물이 더 엄격 |

정할 것은 만들 것인가가 아니다. **이미 만든 것을 백엔드가 받을 것인가**다.

- 1 · 3 · 4 는 프론트가 만들었는데 서버가 못 받는 자리다
- 2 는 `localStorage`(`checkumait-clean-schedules-v2`)로만 돌아 서버 없이도 산다
- 5 는 그대로 두면 된다

AI CHAT 은 실물도 목이다. `setTimeout` 1200ms 고정응답이고 네트워크 호출이 0건이다.
UI 는 있고 두뇌가 없다. 다섯을 한 번에 정하면 된다.
