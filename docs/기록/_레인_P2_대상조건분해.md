## 🔴 0. 분해 규칙 (안 적히면 수가 아니다)

핵을 공백 어절로 끊고 **오른쪽 끝부터** 훑어 «지출명으로 끝나는 첫 어절» 을 찾는다.
한국어는 머리명사가 뒤에 온다 — 「4대사회보험 미가입 임직원의 **교육훈련비**」.

```
지출명접미  (비|료|금|액|운임|비용|수수료)$      어절 끝에 붙어야 한다
대상        찾은 그 어절            조건  나머지 전부(코드 몫. 이번 측정에선 안 쓴다)
대상없음    끝까지 못 찾음 → 이 핵은 지출명을 아예 안 담고 있다
```

문항·스코프·오탐 정의·음성대조는 앞 측정과 **같은 배관**이고 후보 문자열만 갈아끼웠다.
(a) C1 핵 통째 = 비교 기준선 · (b) C1 대상만. 축도 그대로 둘(축1 dry 품목+용도 · 축2 질문 원문).

## 1. 분해부터 절반이 막힌다

**C1 고유핵 62 = 대상있음 30 + 대상없음 32.** 절반(52%)이 지출명을 안 담고 있다.

```
대상없음 예 — 「시제품과 유사한 제품에 대한 제작 경험이 없는 업체」
              「4대사회보험에 가입하지 않은 인력」
              「협약기간 내 납품·사용이 완료되지 않은 건」
```

무엇을 샀는지가 문자열에 없다. **대상만 대조하는 안이 원리적으로 못 닿는 자리**다.
수를 맞추려고 규칙을 늘리지 않았다 — 규칙과 못 잡은 것을 둘 다 적는다.

## 🔴 2. 남은 30개의 대상은 19종뿐이고, 그건 사실상 «비목» 이다

```
교육훈련비 · 교통비 · 기계·장비 · 기술평가비 · 멘토링비 · 비용 · 사무실임차료 · 선금 ·
선행기술조사비·우선심사청구비 · 숙박비 · 여비 · 운임 · 임차료 · 자부담금액 · 잔액·이월액 ·
재료 · 적립·퇴직금 · 충전액 · 평가비
```

여비·교육훈련비·재료·기계·장비는 **비목 이름 그 자체**이고, 숙박비·멘토링비는 그 하위항목이다.
그러니 「대상만 의미 대조」는 **`비목확정()` 이 이미 하는 일을 임베딩으로 다시 하는 것**이다.
새 정보가 없다.

## 3. 판정 — 오탐 0 에서 0건 (양 축 · 양 변형)

| 축 | | 오탐 0 임계 | **참불가** |
|---|---|---:|---:|
| 축1 dry 품목+용도 | (a) C1 핵 통째 | 0.775 | **0** |
| | (b) C1 대상만 | 0.800 | **0** |
| 축2 질문 원문 | (a) C1 핵 통째 | 0.750 | **0** |
| | (b) C1 대상만 | 0.650 | **0** |

앞 측정에서 나온 「오탐 0 에서 5건」은 전부 **C1 이 아닌 핵**(C2·C3·C4)에서 나온 것이었다.
C1 안에서는 통째로도 대상만으로도 0 이다. ai-e8 지시대로 오탐을 허용하는 임계는 안 적는다.

## 🔴 4. 음성 대조가 진짜보다 «낫다» — 신호가 없다는 뜻이다

문항을 **다른 사업의 후보 풀**과 붙인 대조가 오탐 0 에서 축2 **2건** · 축1 **1건**을 낸다.
진짜 짝은 0 건이다. **대조가 본측정을 이겼다.** 우연 수준도 못 넘는다.

**왜 대상만 쪼개면 더 나빠지나** — 「여비」·「교육훈련비」는 그 비목의 문항 **전부**에
똑같이 붙는다. 정답이 불가든 가능이든 구분이 안 된다.
**변별력을 갖고 있던 건 조건 쪽이었다.** 조건을 떼면 그나마 있던 정밀도까지 사라진다.
앞 측정에서 「조건 때문에 오탐이 난다」고 읽었는데, 그 조건이 동시에 **유일한 변별 정보**였다.

## 5. 결론

**내가 낸 안은 안 된다.** 임계를 올려 오탐을 0 으로 만들면 적중도 0 이고,
그 전에 이미 절반(32/62)이 대상을 안 담아 못 닿는다.
남은 30 의 대상은 비목 어휘라 새 정보가 없고, 음성 대조에도 진다.

🔴 **이건 「임베딩으로 안 된다」가 아니라 「이 분해로는 안 된다」다.**
축1 이 여전히 dry 조각을 재고 있고 축2 는 배포 조건이 아니라는 앞 문서의 유보는 그대로다 —
다음 run 에 `원출력.정규화` 가 실리면 축1 은 다시 재야 한다.
