### 인수인계 기록을 한 곳 정정했다

`백엔드_동결상태_0901.md` 는 L3 고장을 「쿼리 자체가 매번 죽는다」로 적었다.
**실측하면 갈린다** — `org_id` 를 `uuid.UUID` 객체로 넘기면 **성공**하고, **str** 로
넘기면 죽는다. HTTP 쿼리 파라미터는 항상 str 이라 **결론(실서버 100% 404)은 같지만**,
원인을 「파라미터 타입 문맥」으로 좁혀야 고칠 자리가 보인다.

고칠 길이 둘이었다. 캐스트(`%s::text IS NULL`)도 실측으로 되살아나지만
**그 길은 게스트가 남의 기관 L3 를 읽는 구멍을 연다**(태워서 확인). 그래서
`_org조건()` 파이썬 분기로 갔다 — `l3_documents.org_id` 가 NOT NULL 이라 게스트는 0행이다.
