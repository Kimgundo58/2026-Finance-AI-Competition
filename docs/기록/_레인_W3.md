### 판단
- **호출은 항상 모듈 접두어**(`db.connect(...)`) — `from _lib.db import connect` 로 이름만
  들여오지 않는다(ai-ae Q3 승인). 지역변수 `conn`·함수 `연결()` 과 겹칠 자리가 많아서다
- **`connect()` 의 `autocommit` 기본값은 False 유지**(ai-ae 확인). 읽기 전용 병렬 경로
  (retrieve·eval_retrieval·orchestrate 등, 2026-08-31 DDL 교착 실측)만 명시적으로
  `autocommit=True` 를 넘긴다 — 쓰기 경로까지 기본값으로 끌어올리면 문장 단위 원자성이 깨진다
- **sys.path 조작은 "닭-달걀"이라 완전히 없애지 못한다.** `_lib` 자체가 scripts/ 밑
  서브패키지라 `from _lib import paths` 를 하려면 그 전에 scripts/ 가 이미 sys.path 에
  있어야 한다. 그래서 각 파일에 최소 부트스트랩 한 줄(`sys.path.insert(0,
  os.path.dirname(os.path.abspath(__file__)))` 류)은 남기고, 나머지(repo root 계산·
  중복삽입 가드·추가 경로)만 `paths.ensure_on_path()` 로 옮겼다
- **ROOT 변수가 sys.path 말고 다른 용도로도 쓰이는 파일은 ROOT 계산 자체를 안 건드렸다**
  (agent_a2·agent_a4·stage2_chunk — `ROOT / "scripts/_work/..."` 로 데이터 경로를 만드는 데도
  쓰고 있었다). sys.path.insert 줄만 `paths.ensure_on_path()` 로 바꾸고 ROOT 정의는 그대로 둠
- **`import psycopg` 는 `.connect()` 외 다른 용도로 쓰는 파일에서만 남겼다** — `seed_rules.py`
  가 유일하다(`psycopg.errors.LockNotAvailable` 를 잡는다). 나머지는 전부 제거
- `case_search.py` 의 중복삽입 가드(`if ROOT not in sys.path`)는 ai-ae 지시대로 제거 —
  `paths.ensure_on_path()` 가 이미 가드를 갖고 있다. 단 `ROOT` 자체는 `_F_오염검사.json` 경로
  조합에도 쓰여서 변수 정의는 남겼다
- 🔴 `adapter.py`·`judge_run.py` 는 함수 시그니처·이름을 안 건드렸다(ai-ae 지시) — DSN·
  sys.path·connect 호출부만 교체
