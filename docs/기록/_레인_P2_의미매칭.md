## 2. 임계값 곡선 · 음성 대조

음성 대조 = 문항을 **다른 사업의 후보 풀**과 붙인 것. 정답과 무관한 짝이라 여기서 나오는
수가 곧 우연 수준이다. 이걸 못 넘으면 신호가 없는 것이다.

| 임계 | 축1 적중/참/오 | 축1 대조 | 축2 적중/참/오 | 축2 대조 |
|---:|---|---|---|---|
| 0.600 | 36 / 20 / 16 | 21/10/11 | 50 / 29 / 21 | 29/13/16 |
| 0.625 | 33 / 17 / 16 | 20/ 9/11 | 38 / 24 / 14 | 22/10/12 |
| 0.675 | 18 /  9 /  9 | 13/ 5/ 8 | 20 / 15 /  5 | 7/ 2/ 5 |
| 0.725 |  9 /  4 /  5 |  4/ 1/ 3 |  7 /  6 /  1 | 2/ 1/ 1 |
| **0.750** | 5 / 2 / **3** | 4/ 1/ 3 | **5 / 5 / 0** | 1/ 1/ 0 |
| 0.775 | 1 / 1 / **0** | 1/ 1/ 0 | 2 / 2 / 0 | 0/ 0/ 0 |

최대코사인 분포 — 축1 불가 중앙 **0.576** vs 비불가 **0.564**(차 0.012) ·
축2 불가 **0.621** vs 비불가 **0.593**(차 0.028).

## 3. 그래서 0/113 은 몇이 되나

**오탐 0 을 지키는 선에서 축2(유리한 축) 5건 · 축1(실제 배관) 1건.** 분모는 정답 불가 49.

- 순증 최대는 축2 t=0.625~0.675 의 **+10** 인데 그때 오탐이 14·5 다 —
  채택기준 ① **치명 오답 0** 을 깬다. 「불가」 즉답에 근거까지 달려 나가는 오탐이다
- 축1 은 음성 대조와 **구분이 안 된다**(모든 임계에서 참:오 ≈ 1:1, 대조도 1:1).
  축2 는 대조를 넘는다(t=0.675 에서 15:5 대 2:5). 즉 **신호는 질문 원문에만 있고
  게이트 A 가 실제로 쥐는 본문에는 없다**
- 🔴 **임계값이 사업 사이에서 안 옮겨간다.** 최대코사인 중앙이 풀 84 는 0.737, 풀 57 은
  0.562 다. t=0.750 의 적중 5건은 공통(37핵) 3 · 창업중심대학(84핵) 2 이고
  **예비창업+초기창업 40문항에서는 0** 이다. 전역 임계 하나로는 못 쓴다

## 🔴 4. 오탐이 잡음이 아니라 «가장 닮은 문항» 이다 — 이게 핵심이다

임베더는 주제를 **정확히** 찾아낸다. 그런데 걸리는 게 하필 정답이 「가능」인 문항이다.

| 문항 | 정답 | 걸린 금지예시 | cos |
|---|---|---|---|
| 415 | **가능** | 4대사회보험에 가입하지 않은 인력 | 0.716 |
| 421 | **가능** | 4대사회보험 미가입 임직원의 교육훈련비 | 0.722 |
| 417 | **가능** | Re:Born 멘토단 또는 그 자격기준을 **충족하지 않는** 자에게 지급하는 멘토링비 | 0.749 |
| 425 | **가능** | 협약기간 내 납품·사용이 **완료되지 않은** 건 | 0.723 |

넷 다 「가입했다 / 자격을 갖췄다 / 기간 내 완료했다」라서 가능인 문항이다.
**금지는 부정·조건에 걸려 있는데 임베딩은 부정을 인코딩하지 않는다.** 관측 C 에서
고유핵 155 중 **C1 조건서술형이 62(40%)** 였다 — 그 40% 에서 의미 대조는
「닮았다」와 「금지다」를 못 가른다. 재현율을 올리면 **가장 위험한 자리부터** 올라간다.

**추론** — 별칭이 안 닫히는 이유(유한 목록 대 무한 표현)는 맞지만, 임베딩으로
바꾸면 실패의 «모양» 이 바뀐다: 별칭은 **못 잡는 쪽**으로 틀리고(놓침 49, 틀린불가 0),
의미 대조는 **잘못 잡는 쪽**으로 틀린다. 게이트 A 는 근거를 달아 즉답하는 자리라
후자가 더 비싸다. 임계를 오탐 0 까지 올리면 이득이 1~5건으로 줄어든다.

## 5. 안 한 것 · 안 닫힌 물음

- 배선 안 했다. 임계 채택 제안도 안 한다 — 판단은 ai-e8 자리다
- **품목·용도가 들어오면 이 측정은 다시 해야 한다.** 축1 은 조각을 잰 것이고 축2 는
  배포 조건이 아니다. P4 실물 run 에 `원출력.정규화` 가 실리면 그때가 참값이다
- 부정·조건을 다루는 안(핵을 「조건」과 「대상」으로 쪼개 대상만 의미 대조하고 조건은
  코드로 검사)은 재 보지 않았다. 지시 범위 밖이라 손대지 않았다
- 「금지예시 113개」는 문항 수와 섞인 듯하다 — 금지예시는 **294**(무조건 266 · 고유핵 155,
  스코프 적용 후 실제 후보 158종)이고 **113** 은 범위밖 포함 정답셋 문항 수다. 분모는 93
