# P2 — 「가능 25.0%」·「판단불가 0.0%」를 문항으로 열었다

2026-09-03 · ai-e8 지시. 산출은 **갈래별 개수**이고 「몇 건이 열리나」는 내지 않는다.
코드 수정 0 · DB `read_only=True`. run 191 · 정답셋 93문항.

## 🔴 0. 세는 규칙 (세기 전에 적었다. 어느 갈래를 기대하는지는 적지 않는다)

정답=가능 16문항 각각에 대해, 그 비목의 근거 조문이 붙인 조건을 짚고 —

```
(ㄱ) 조건 충족이 질문 문장에 «적혀 있다»   → 시스템이 조건을 검사하면 열릴 수 있는 자리
(ㄴ) 질문이 조건을 말하지 않는다           → 모델이 알 길이 없다
(ㄷ) 근거 조문에 조건이 없다
```

🔴 **이건 정규식이 아니라 내가 16문항을 읽고 판정한 것이다.** 판정자가 나 하나라 교차검증이
없다. 갈래별 gold_id 를 전부 적어 두니 다른 세션이 같은 문항을 다시 읽어 대조할 수 있다.

## 1. 가능 16건 — **(ㄱ) 13 대 (ㄴ) 3** ((ㄷ) 0)

| 갈래 | n | gold_id | 예측 |
|---|---:|---|---|
| **(ㄱ) 조건 충족 명시** | **13** | 338 · 414 · 415 · 416 · 417 · 418 · 419 · 420 · 421 · 422 · 423 · 424 · 425 | 가능 4 · **조건부 9** |
| **(ㄴ) 질문에 조건 없음** | **3** | 376 · 409 · 412 | 조건부 2 · 판단불가 1 |

(ㄱ) 의 모양 — 질문이 조건을 그대로 적는다:
- g414 「**4대사회보험에 모두 가입된** 직원을 **협약 시작 후에 채용**해 **참여율 100%**」
- g419 「**사업자등록증이 있는** 업체에 **1,500만원**(심의 기준 2천만원 미만) · **유사 제품 제작
  경험이 있는** 업체 · 저희 대표자가 **재직한 적도 없습니다**」 — 조건 넷을 한 문장에 담았다
- g418 「서울특별시 1박 **9만원**」(한도 10만) · g417 「**자격기준을 충족하는** 멘토 · **25만원**」(한도 30만)

(ㄴ) 의 모양 — 조건을 안 밝힌 일반 질문이다:
「정부지원사업비로 인건비 집행이 가능한가요?」(409) · 「제품 광고비를 집행가능한가요?」(412) ·
「온라인 쇼핑몰 입점비를 사업비로 낼 수 있나요?」(376)

**잃은 11건 중 9건이 (ㄱ)** 이다 — 질문이 조건 충족을 적어 줬는데도 조건부로 갔다.

### 🔴 그런데 이 13 은 문항 «문체» 의 산물일 수 있다

(ㄱ) 13 중 **12 가 보강 세트**다((ㄴ) 3 은 본세트 1 · 공식 2).
ai-a3 가 밝힌 대로 보강은 **라벨 균형용**으로 쓰인 문항이다 — 정답을 「가능」으로 만들려면
조건 충족을 문장에 적을 수밖에 없다. 즉 **「조건이 질문에 적혀 있다」가 규정의 성질이 아니라
문항 설계의 성질일 수 있다.** 실사용자가 「4대사회보험에 가입된 저희 직원이」라고 먼저
써 줄지는 다른 문제고, 여기서 안 쟀다. **13 은 이 문체에서의 상한이다.**

🔴 (ㄴ) 3건에 대해 「정답셋이 틀렸다」고 말하지 않는다. 산출은 13:3 이라는 수까지다.

## 2. 판단불가 7건 — 7건 중 6건이 «규정이 답을 안 하는» 자리다

| gold_id | 사업 / 비목 | 왜 판단불가가 정답인가 | 예측 |
|---|---|---|---|
| 426 · 427 | **TIPS** / 광고선전비 · 지급수수료 | `corpus.rules` **0행**. 위임 계통이 다르다 | **가능** · 조건부 |
| 428 | 모두의창업 / 창업활동비 | 제31조 「세부사항은 **전문기관의 장이 별도로 정할 수 있다**」 | 조건부 |
| 429 · 430 · 431 | 모두의창업 / 광고선전비 · 교육훈련비 · 인건비 | **제33조①의 진출자 사용가능 비목 5개에 없다** | 조건부 |
| 432 | 재도전 / 재료비 | 현물 계상 축 | 조건부 |

**공통 구조: 정답이 「이 사업·비목에는 규정이 답을 안 한다」는 «부재» 다.**
시스템은 부재를 보고하는 대신 상위 지침에서 끌어와 조건부를 뱉는다.

### 🔴 2-a. TIPS 2건은 룰 경로가 «이미» 정답을 알고 있다

```
base_룰('TIPS', None)            → 0행
effective_rule('TIPS','광고선전비') → None
```
그리고 `rule_lookup.base_룰` 의 주석이 직접 적어 뒀다 — *「TIPS 는 rules 0행 → None →
**판단불가가 맞다**」*. 그런데 판정은 가능·조건부로 나갔다. **룰이 낸 정답을 파이프라인이
안 쓴다** — 룰 없음을 「판단불가」가 아니라 「룰 정보 없음, LLM 이 청크 읽고 판단」으로 처리한다.

**「사업 룰 0행 → 판단불가로 닫는다」를 재 봤다:**

| | |
|---|---:|
| 대상 문항 | 2 |
| 얻는 것 | **+2** |
| 잃는 것 | **-0** |
| **순증** | **+2** |

강등코드 경로(순증 **-21**, [[_레인_P2_허용감사]] §4)와 **부호가 반대**다. 작지만 손실이 0 이다.
🔴 다만 분모가 2 다. 그리고 이건 **측정이지 채택 제안이 아니다** — 배선은 내 자리가 아니다.

### 2-b. 모두의창업 4건은 룰이 «있어서» 안 잡힌다

`effective_rule` 이 None 인 문항은 TIPS 2건뿐이다(골든 비목 기준 그 외 0건).
모두의창업 4건은 `corpus.rules` 에 행이 **있어서** 조건부가 나온다.

그런데 제33조①은 진출자가 쓸 수 있는 비목을 **재료비·외주용역비·무형자산취득비·지급수수료·
여비 + 기타 전문기관의 장이 인정하는 비목**으로 못박는다. 광고선전비·교육훈련비·인건비는
그 목록에 없다(인건비 제27조는 **주관기관** 인건비다). 그런데 `corpus.rules` 에는 모두의창업
10비목이 전부 있고 10행 모두 근거로 제33조를 단다.

**관측: 룰 테이블이 근거 조문보다 넓다.**
**추론(관측 아님): `corpus.rules` 에 «대상»(주관기관/진출자) 축이 없어서다.** 컬럼에
`대상` 이 없다 — `eval.golden_set` 과 `chunks` 에는 있다. 세목 축 부재
([[_레인_P2_세목축_제안]])에 이은 **두 번째 축 부재**로 보인다. 확인 안 했다.

## 3. 산출 정리

```
가능 16      (ㄱ) 조건 충족이 질문에 있다 13  ← 그중 9건을 조건부로 잃었다
             (ㄴ) 질문에 조건이 없다        3      🔴 (ㄱ) 13 중 12 가 보강 세트다
판단불가 7    규정 부재가 정답             6      TIPS 2 + 모두의창업 4
             그 외                       1      432 현물 축
```
