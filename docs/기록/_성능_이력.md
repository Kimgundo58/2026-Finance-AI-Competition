## 누락 가능성

이 표는 절 제목에 `%` 또는 `→`/`->` 가 박힌 것만 기계적으로 뽑았다. 본문 안에만 있고
제목에는 없는 수치(예: 결과보고.md 각 축 세부 실측표)는 안 잡힌다 — 필요하면 해당 날짜 파일
또는 `2026-08-31_축별보고.md` 를 직접 열어라.
