비어 있는 게 이 시점에 가장 중요한 결정이 됐다.

### 함정 — 🔴 `guided_json` 이 무음으로 무시됐다

가장 값비싼 발견이다.

```python
"extra_body": {"guided_json": 스키마}      # ← 무시된다
```
`extra_body` 는 **파이썬 OpenAI SDK 문법**이다. HTTP 를 직접 치면 서버가 그 키를 모르고
**에러 없이 그냥 버린다.** 첫 실행에서 모델이 이렇게 답했다:

```json
{"결과": "불가", "근거": ["S02"], "이유": "S02에 따르면 ..."}
```
스키마는 `{판정, 요약, 해야할일, 인용, 전제}` 인데 **필드 이름을 제멋대로 지었다.**
내용은 맞았는데(정답 "불가", 근거 S02 정확) 파서가 못 읽어 전부 판단불가로 강등됐다.

최상위로 옮기니 즉시 스키마대로 나왔다. vLLM 0.11 은 `guided_json` ·
`structured_outputs` · `response_format(json_schema)` 셋 다 받는다 — 셋 다 실측 확인.

**S번호 enum 도 실제로 닫혔다** — `{"인용": {"items": {"enum": ["S01","S02","S03"]}}}` 로
넣으니 모델이 그 안에서만 골랐다. 환각 인용이 디코딩 단계에서 막힌다.

### 함정 — 팟마다 드라이버가 다르다

## 2026-08-31 · DB 전수 감사 + `documents` 메타 결손 복구 + 감사 스크립트 상설화

**조각조각 나오는 게 문제**라 전수로 한 번에 보고, 다시 볼 수 있게 스크립트로 굳혔다.

### 판단

**결손과 "의도된 빈 값" 을 가르는 게 작업의 본체였다.** NULL 이 많은 컬럼은 21개인데

| 분류 | 예 | 판정 |

| **🔴 진짜 결손** | `version` · `시행일` · `doc_type` · `페이지` | 아래 |

**`version` 등은 재파싱 없이 doc_id 에서 뽑았다.** 원본 `_stage0_articles.json` 문서
레코드에 그 필드가 **애초에 없고**(키: doc_id·layer·strategy·조·삭제조·최장·quality·flags·
path·규범), `load_db.py:89` 가 그 자리에 하드코딩 `None` 을 넣고 있었다. 수집 단계 누락이다.

그런데 doc_id 에 이미 들어 있다 — `L1_개인정보보호법_20251002`, `…제14차개정_20251223`.
**재파싱·재임베딩 없이 문자열에서 뽑았다.**

🔴 **추측으로 채우지 않았다.** 확실한 패턴만 잡고 나머지는 NULL 로 남겼다 —
틀린 버전스탬프("제13차 기준입니다")는 없는 것보다 나쁘다. 인용 신뢰를 무너뜨린다.

### 판단

**설치는 GitHub 릴리스 바이너리.** `curl -sSL https://cli.runpod.net | bash` 는 Linux/macOS/WSL
전용이라 이 환경(Windows + Git Bash)에서 안 된다. `runpodctl-windows-amd64.exe` 를 받아
`~/bin/` 에 뒀다 — 이미 PATH 에 있는 디렉터리라 PATH 수정이 필요 없다.

**키 저장은 `~/.runpod/config.toml` 직접 기입.** 대안 3개를 다 시도했고 기각 사유가 각각 있다:
- `runpodctl doctor` — 정공법이지만 **Claude Code 의 `!` 는 stdin 이 TTY 가 아니라** 프롬프트가
  즉시 `{"error":"failed to read input"}` 로 죽는다. 별도 터미널 창에서는 된다
- `runpodctl config --apiKey <키>` — 동작하지만 `config` 는 이 빌드에서 deprecated 목록이고,
  무엇보다 **키가 대화 기록에 평문으로 남는다**
- `export RUNPOD_API_KEY=...` — 세션마다 재실행 필요, SSH 키도 안 생긴다

**볼륨 DC 는 GraphQL 로 간다.** runpodctl 유지가 원칙이지만 이 정보만은 CLI 에 없다(아래 실측).
`storageSupport` 필드 하나 때문에 GraphQL 을 부르는 건 예외로 둔다.

**조회 실패 시 빈 집합을 반환하지 않고 `sys.exit` 한다.** 빈 집합이면 "조건에 맞는 GPU 가 없다"
로 표시돼 **재고 부족과 조회 실패가 구분되지 않는다.** 이번 버그가 정확히 그 모양이었다.

## 5. 공통 운영 규칙

**DB** — 로컬 Docker `suddoe-db` 가 이미 떠 있다.
`SUDDOE_DSN = postgresql://postgres:devpw@localhost:5432/suddoe`

**Bash** — 훅이 `PYTHONIOENCODING=utf-8` 없는 python 호출을 차단한다. 항상 앞에 붙인다.
`sys.stdout` 을 조건 없이 다시 감싸지 마라 — 다른 모듈을 import 할 때 버퍼가 닫힌다.

**🔴 GPU — A 만 연다. B~H 는 팟을 열지 않는다.**
8세션이 각자 팟을 열면 잔액($8.02)이 한 시간 만에 증발한다.
GPU 가 필요하면 **A에게 작업을 넘기고 자기 일을 계속한다.**
임베딩(item_alias 200쌍 · 사례집)은 **CPU KURE-v1** 으로 충분하다 — 수분이면 끝난다.

🔒 **훅으로 강제돼 있다** (`.claude/hooks/guard_gpu.py`, 2026-08-31 신설):

| 시점 | 하는 일 |
|---|---|
| `PreToolUse(Bash)` | 대장에 팟이 이미 있으면 **두 번째 개설을 거부**한다 (8세션 중복 개설 차단) |
| `Stop` | 대장에 팟이 남아 있으면 **턴 종료를 막고** 경과시간·누적비용을 들이민다 (15분 억제) |

팟은 `scripts/runpod_pod.py` 를 거쳐서만 연다. **작업이 끝나면 묻지 말고 즉시 `close`** 한다

훅도 세션이 죽으면 같이 죽으므로 마지막 방어선은 잔액과 사람이다.

**커밋 — A 만 한다.** B~H 는 워킹트리에 두고 보고만 한다. 한 워킹트리를 8세션이 쓴다.

**회귀 3종 — 자기 작업을 끝냈다고 선언하기 전에 반드시 돌린다.**

**자율 실행** — 오너에게 세세히 묻지 않는다. 데이터 오류는 **스스로 여러 번 교차검증**해서 잡는다.
막히면 가정을 명시하고 진행한 뒤 `결과보고.md` 에 그 가정을 적는다.
**단, 아래 3가지는 예외 — 판단을 바꾸지 말고 보고만 한다:**

- 오너가 검수 완료(`verified=true`)한 행을 뒤집어야 할 때
- 확정 원칙(§2)과 어긋나는 결론이 나왔을 때
- 규정 원문을 수정해야 풀리는 문제 (원문은 인용 검증의 대조 기준이라 고칠 수 없다)

확실한 패턴만 채우고 나머지는 NULL 로 남기고 사유를 적는다.

## 9. 세션 통신 규약 — 오너를 거치지 않는다

세션끼리 `SendMessage` 로 직접 주고받을 수 있다. 다만 이름이 `ai-72` 처럼 자동 생성이고
중복도 생기므로(같은 `ai-11` 이 둘) **등록소를 먼저 거친다.**

### ① 착수 직후 — 1회만

```
ListAgents 를 호출한다 → 첫 줄이 "This session is <이름> [<ref>]" 라고 알려준다
그 값을 그대로 scripts/_work/_sessions/<자기역할>.txt 에 쓴다   예) D.txt → "ai-72 [b67718]"
```

세션마다 파일이 달라 동시 쓰기 충돌이 없다. 남을 부를 땐 그 디렉터리를 `ls` 해서 이름을 찾는다.
`SendMessage` 는 **bare 이름**으로 먼저 보내고, 중복이라 거절당하면 `이름 [ref]` 로 다시 보낸다.

### ② 허브 앤 스포크 — A 를 통한다

🔴 **아무나 아무에게나 보내지 않는다.** 8세션 메시 통신은 노이즈가 되고 서로를 깨운다.
아래 5종만 보낸다. **A 가 허브**이고, 예외는 D 의 DDL 브로드캐스트 하나뿐이다.

| 메시지 | 보내는 이 → 받는 이 | 언제 |
|---|---|---|
| `DDL-READY` | **D → 등록된 전원** | `04_agent.sql` 머지 직후. **유일한 브로드캐스트** |
| `MODULE-READY <역할>` | B·C·E·F → A | 자기 모듈이 동결 인터페이스대로 동작할 때 |
| `MERGE-1` | A → G, A → 전원 | 합류점 1. G 에게는 "rules 재적재 허가" 를 명시 |
| `BLOCKED <한 줄>` | 누구나 → A | 남의 소유 파일을 고쳐야 할 때 · 계약 위반이 필요할 때 |
| `DONE <역할>` | 누구나 → A | 회귀 3종 통과 + `결과보고.md` 기록 완료 |

- 🔴 **남의 소유 파일을 직접 고치지 마라.** `BLOCKED` 로 A 에게 넘기고 네 일을 계속한다
- 진행 상황을 묻는 메시지("다 됐어?")를 보내지 마라. 필요하면 `notify_when_idle` 을 쓴다
- 메시지는 받는 쪽의 다음 도구 호출 때 전달된다 — 즉시 도착을 전제로 대기하지 마라.
  **의존 대상이 없으면 스텁으로 짜고 진행한다** (§4)

### ③ 🔴 메시지에만 의존하지 않는다 — 파일 마커가 정본

`SendMessage` 는 **보내는 순간 등록돼 있는 세션에만** 간다. 늦게 뜬 세션은 `DDL-READY` 를
영영 못 받는다. 오너가 자고 있으면 아무도 못 고친다. 그래서 **상태는 파일로도 남긴다.**

| 마커 파일 | 쓰는 이 | 뜻 |
|---|---|---|
| `scripts/_work/_sessions/_DDL_READY` | D | `04_agent.sql` 머지 완료. 새 컬럼·테이블 사용 가능 |
| `scripts/_work/_sessions/_MERGE_1` | A | 합류점 1. G 의 `rules` 재적재 허가 |

- 마커를 만드는 쪽은 **파일을 먼저 쓰고 그다음 메시지**를 보낸다 (파일이 정본, 메시지는 알림)
- 기다리는 쪽은 **메시지를 기다리지 말고**, 자기 작업 중 그 상태가 필요해질 때
  `ls scripts/_work/_sessions/` 로 직접 확인한다. 없으면 스텁으로 계속 간다
- 내용은 한 줄이면 된다 (완료 시각). 존재 자체가 신호다

## 10. 🔴 오늘 밤 **하지 않는 것** — 무인 실행의 최대 위험

오너가 자고 있다. 아무도 "그건 하지 마"라고 말해줄 수 없는 밤이다.
**지표를 올리려다 아키텍처를 스파게티로 만드는 것**이 오늘 밤 가장 큰 위험이다.

### 재제안 금지 (CLAUDE.md 확정 원칙 — 논의 대상이 아니다)

```
GraphRAG · KAG · agentic multi-hop · v1 리랭커 · 멀티 에이전트 오케스트레이션
PMS 스크린샷 업로드 · Qwen API 경유 · Llama 계열 · function calling 개방
```

### 오늘 밤 새로 금지하는 것

| 금지 | 이유 |
|---|---|
| **RAGAS 등 LLM-as-judge 평가 프레임워크 도입** | 심판이 LLM 이면 같은 산출물에 다른 점수가 나온다 — `Agent.md` §6 재현성 위반. 우리는 골든셋 정답지가 있어 `hit@k`·4-way 일치율로 **결정론적으로** 잰다. faithfulness 는 채점이 아니라 S번호 enum 으로 **차단**한다. 더 강하다 |
| **새 라이브러리·모델·검색기 도입** | 오늘은 있는 부품을 잇는 날이다. 부품을 바꾸는 날이 아니다 |
| **스키마 변경** (D 제외) | DDL 은 D 전권 |
| **동결 인터페이스(§4) 변경** | 협의 없이 바꾸면 다른 세션이 조용히 깨진다. 필요하면 `BLOCKED` |
| **골든셋 문항 수정·추가** | 정답지를 건드리면 오늘 잰 숫자가 어제와 비교 불가가 된다 |
| **"좋아질 때까지" 반복 튜닝** | 77문항에서 1문항 = 1.4%p. 노이즈를 신호로 착각한다. 변형은 **미리 선언한 개수만** |

### 판단 기준 — 마이너한 방향인지 가리는 법

무언가를 추가하고 싶어지면 스스로 물어라:

```
① 이게 없으면 오늘의 목표(judge_cli 한 줄 + E2E 숫자)가 안 나오는가?
   → 아니면 코드가 아니라 `결과보고.md` 의 "남은 것" 에 적는다
② 실측 근거가 있는가? "그럴 것 같다" 는 근거가 아니다
   → 재보고, 못 재면 하지 않는다
③ 설계 문서 중 어느 조항이 이걸 요구하는가?
   → 못 대면 오늘 할 일이 아니다
```

🔴 **개선 아이디어는 코드가 아니라 보고서에 적는다.** 오늘 밤 좋은 생각이 나면
그건 내일의 재료지 오늘의 커밋이 아니다. 검증 없이 들어간 개선은 아침에
"이 숫자가 무엇 때문에 나온 건지" 를 알 수 없게 만든다 — 그게 오늘 밤의 유일한 산출물인데.
