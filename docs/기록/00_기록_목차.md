# 기록 목차

「써도돼요」 일자별 작업 로그의 인덱스. **최신이 위**에 온다.

- 여기는 **무엇을 했고 무엇이 나왔나**만 적는다. 설계 결정은 `docs/` 축별 문서가 기준이다
- 🔴 **소급 수정 금지.** 그 시점의 관측이라 값이 낡은 게 정상이다.
  낡음을 알려야 하면 본문이 아니라 머리에 상태 배너를 단다
- 100줄 상한 면제 구역이다 — 통독하지 않는다
- 아래 대표 절 제목은 **원문 그대로**다. 용어 치환을 하지 않았다

작성 규칙 (날짜 파일에 적을 때)
- 날짜 헤딩은 `## YYYY-MM-DD (요일)`, 항목마다 `HH:MM` 을 단다
- 산출물은 **경로와 수치**를 적는다. "개선했다" 가 아니라 "320 → 181"
- 발견한 함정은 재발 방지 위치(어느 스크립트·어느 문서에 박았는지)까지 적는다
- 미완은 숨기지 않는다. **왜 안 했는지**를 남긴다
