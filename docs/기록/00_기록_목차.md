# 작업 현황

「써도돼요」 일자별 작업 로그. **최신이 위**에 온다.
설계 결정은 여기 적지 않는다 — 결정은 `구현.md`·`서비스 아키텍쳐.md`, 여기는 **무엇을 했고 무엇이 나왔나**만.

작성 규칙
- 날짜 헤딩은 `## YYYY-MM-DD (요일)`, 항목마다 `HH:MM` 을 단다
- 산출물은 **경로와 수치**를 적는다. "개선했다" 가 아니라 "320 → 181"
- 발견한 함정은 재발 방지 위치(어느 스크립트·어느 문서에 박았는지)까지 적는다
- 미완은 숨기지 않는다. **왜 안 했는지**를 남긴다
