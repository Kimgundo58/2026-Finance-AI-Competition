#### 4. 참조 그래프 — dangling 절반으로

```text
              1차      2차(수정 후)
엣지        1,087  →   1,136
resolved      735  →     920
shifted        32  →      35
dangling      320  →     181   ← 절반 이하
```

2차 개선 요인 — ① `요령`·`관리기준` 해소 로직 추가 ② 문자중복 해소가 통합관리지침에 적용.

**`shifted` 가 핵심 검증이다.** 2025년판 세부관리기준이 쓰는 `"지침 제33조"`(제12차 표기)를
조제목 매칭으로 현행 제14차 **제36조**로 자동 보정했다. 참조 그래프가 작동한다는 증거.

잔여 dangling 181건은 대부분 R&D 계열(과학기술기본법·출연연법)로 **판정 인덱스 밖이라 정상**.
