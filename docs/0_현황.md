## L3 — 고유 조건은 9개뿐

경상국립대 L3 문서(203개 조문) 전량 검토: L1/L2와 실제로 다른 조건은 **9개**뿐,
나머지 약 70%는 L2 세부관리기준 원문을 그대로 옮긴 것. 골든셋 L3 27문항 = 9조건 × 3문항(원형 1 + 변형 2).
분모는 조건단위 9다. 27로 나누면 정확도가 과대평가된다.

## 운영 서버

네이버클라우드 VM 1대(2vCPU/8GB)에서 API · PostgreSQL · Caddy 를 Docker Compose 로 운영한다
(2026-10-27 GCP 에서 이관, [[8_운영/8-6_NCP_배포]]). 기동 시 동기 워밍업 약 44초,
이후 `/admin/warmup` 0.2초. 판정 1건 약 60초 — 그중 판정 LLM 호출 55~59초(thinking 토큰).

배포는 main 병합 후 자동(Actions 빌드 → Container Registry → 서버 cron, [[8_운영/8-8_CI_CD]], 2026-11-03).
스키마 변경은 `db/migrations/` — 이 경우 자동 배포가 멈추고 손으로 반영한다.
