이후 `/admin/warmup` 0.2초. 판정 1건 약 60초 — 그중 판정 LLM 호출 55~59초(thinking 토큰).

배포는 main 병합 후 자동(Actions 빌드 → Container Registry → 서버 cron, [[8_운영/8-8_CI_CD]], 2026-11-03).
스키마 변경은 `db/migrations/` — 이 경우 자동 배포가 멈추고 손으로 반영한다.

## 저장소 정리

저장소는 운영 코드(`server/`·`scripts/`)·DB(`db/init`·`db/migrations`·`db/seed`)·배포(`deploy/ncp`)·코퍼스 원본·골든셋·설명 문서를 담는다.
개발 도구·작업 기록·구 파이프라인은 담지 않는다. 미뤄 둔 작업은 [[9_백로그]].
