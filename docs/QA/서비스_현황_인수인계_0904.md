## GPU — 무인 운전 (자동 켜짐/꺼짐)

- **요청이 오면 자동으로 켜진다.** 안 쓰면 **15분 뒤 자동으로 꺼진다.** 사람이 켜고 끌 필요 없다.
- 판정 시간 (스모크 실측):
  - GPU 꺼진 상태 **첫 요청**: 5초 안에 **"판단불가"로 반환** + GPU 깨우기 시작(부팅 약 4분). → **몇 분 뒤 다시 누르면 실판정**이 나온다. (첫 요청이 4분 멈추는 게 아니라, 판단불가로 빠르게 돌려주고 뒤에서 GPU 를 켠다.)
  - GPU 켜진 뒤 판정: **15~30초** (긴 질문은 1~2분)
  - 미리 구운 질문(캐시): **0.25초**
- 하루 기동 8회 상한 (비용 가드). 정지 상태는 GPU 요금 0.

## QA 요청 (기획자 팀원용 · 5줄)

1. `prototype@ssudo.kr` / `123456` 로 로그인한다 (기관: 경상국립대 창업중심대학사업단).
2. 지출 항목(품목·금액·용도)을 넣고 판정을 받는다 — 판정·근거·인용이 화면에 제대로 뜨는지 본다.
3. **첫 판정은 "판단불가"가 나올 수 있다(정상)** — GPU 를 깨우는 중이다. 몇 분 뒤 같은 항목을 다시 누르면 실제 판정이 나온다. 이후 판정은 15~30초.
4. **"판단불가"는 오류가 아니다** — 근거가 부족할 때의 정상 응답(문의 초안을 준다). 빨간 오류 화면만 버그로 본다.
5. 버그는 "무엇을 눌렀고 무엇이 나왔나"로 적는다 (양식: `docs/QA/버그_리포트_양식.md`).

## 알려진 것 (버그로 오해 말 것)

- GPU 꺼진 뒤 첫 판정이 느린 것 · 그 사이 "판단불가"가 나오는 것 — 정상.
- 판정 **정확도**는 아직 측정 전이다(골든셋 315문항 준비됨, 다음 측정). "이 판정이 맞나"는 QA 관찰 대상이지 보장된 값이 아니다.
