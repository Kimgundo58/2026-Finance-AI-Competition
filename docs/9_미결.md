## 설계됐으나 미구현

- Cloud Scheduler → `/api/gpu/reap` 이관 미배선 — 로컬 워치독과 이중, PC가 꺼지면 워치독도 죽는다
- `runpod_pod.py open`에 `--ports` 기본값 없음 — 템플릿 기본포트만 열려 vLLM 프록시 실패 이력. 제안값 `8000/http,8888/http,22/tcp`
- `runpod_pod.py close`가 `ops.gpu_pod` 행을 안 고친다 — 팟이 사라진 뒤에도 `'가동'`으로 남아 죽은 URL이 살아있게 보인다
- 판정 정규화 호출부에 계측(추론content있음·길이) 없음 — "판정은 안 잘렸다"까지만 말할 수 있고 정규화 쪽 잘림 여부는 못 잰다
- run 간 비교 시 "실패했다가 우연히 정답"인 건을 악화 집계에서 공제하는 로직 없음
- GPU 창 1회(실판정 리허설·Q4 발화율·Q2 roundtrip) — 오너 충전·승인 대기, 코드는 준비됨(무인 실행)
