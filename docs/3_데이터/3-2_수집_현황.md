# 수집 현황 — L1 조달

이 문서가 답하는 질문:
- L1 법령 모음은 어디서 어떻게 조달했는가
- 재크롤링이 필요할 때 무엇을 다시 돌리는가
- 법령별 인용 조항 상세는 어디서 찾는가

> **조달은 끝난 작업이다.** 이 문서는 law.go.kr 을 다시 칠 때(개정 대응·범위 확장)만 편다.
> 수량은 파일 실측(2026-09-07): 법령 XML 현행 274 · 구판 944 · 별표 103 · 신규 데이터셋 128.

## 자산 위치

| 자산 | 위치 |
|---|---|
| 현행 법령·행정규칙 XML | `법령 PDF/L1_법령/` |
| 구판(시점본·연혁) XML | `법령 PDF/L1_법령/연혁/` |
| 첨부 (별표·본문공백 보완) | `법령 PDF/L1_법령/첨부/` |
| 행정규칙 별표 (HWP→PDF 변환 완료) | `법령 PDF/L1_법령/별표/` + `_hwp변환/` |
| 범위 밖 보류 | `법령 PDF/L1_법령/_범위밖_보류/` |

수집 경로는 국가법령정보 OPEN API(`law.go.kr/DRF`), 포맷은 XML.

수집(크롤링·인덱스 편입 판정·HWP 변환)은 일회성 배치로 이미 끝났다. 수집 스크립트 자체는
저장소에 남기지 않는다 — 코퍼스 결과는 `2026_Finance_DATA_FOR_RAG/` 와 DB 에 있다.

## 운영 규칙 (핵심)

- **파일은 규범당 한 벌만.** 출처는 `_law_sources.json`의 `sources` 배열로 구분
- **판정 인덱스 편입은 `index` 플래그** — 직접참조 여부로만 결정 (위임으로 딸려온 것은 제외)
- 위임 추적 3단계(법률→시행령·시행규칙→위임 행정규칙), `위임구분=인용법령`은 제외

## API 함정 (상위 5, 전체 14건은 원본 참조)

| # | 함정 | 대응 |
|---|---|---|
| 1 | JSON은 단일 원소가 배열이 아닌 객체로 온다 | XML 채택 |
| 2 | `lsDelegated` 위임 일련번호는 구판 | 개정 불변 키로 현행판 재조회 |
| 4 | `위임구분=인용법령`은 위임이 아니라 참조 | 따라가지 않음(전체 법령 번짐) |
| 12 | `admbyl` 별표 확장자 `.hwp`인데 실제 HWPX 다수 | 매직바이트 판별 |
| 14 | 다단 레이아웃 PDF는 컬럼이 단어 사이에 끼어든다 | 좌표 기반 컬럼 분리 |
