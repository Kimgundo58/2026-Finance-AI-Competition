# 수집 현황 — L1 수집

이 문서가 답하는 질문:
- L1 법령은 어디서 어떻게 수집했는가
- 재크롤링이 필요할 때 무엇을 다시 실행하는가
- 법령별 인용 조항 상세는 어디서 찾는가

> **수집은 끝난 작업이다.** 이 문서는 law.go.kr 에서 다시 수집할 때(개정 대응·범위 확장)만 참고한다.
> 수량은 파일 실측(2026-09-07): 법령 XML 현행 274 · 구판 944 · 별표 103 · 신규 데이터셋 128.

## 자산 위치

| 자산 | 위치 |
|---|---|
| 법령·행정규칙 XML (수집 시점 판. 지금 현행인지는 [[9_백로그]] 「법령 XML 판」) | `법령 PDF/L1_법령/` |
| 시점별 판(연혁본) XML. 구판과 수집 당시 시행 전이던 판이 함께 있다 | `법령 PDF/L1_법령/연혁/` |
| 첨부 (별표·본문공백 보완) | `법령 PDF/L1_법령/첨부/` |
| 행정규칙 별표 (HWP→PDF 변환 완료) | `법령 PDF/L1_법령/별표/` + `_hwp변환/` |
| 범위 밖 보류 | `법령 PDF/L1_법령/_범위밖_보류/` |

수집 경로는 국가법령정보 OPEN API(`law.go.kr/DRF`), 포맷은 XML.

수집(크롤링·인덱스 편입 판정·HWP 변환)은 일회성 배치로 이미 끝났다. 수집 스크립트 자체는
저장소에 남기지 않는다 — 코퍼스 결과는 `2026_Finance_DATA_FOR_RAG/` 와 DB 에 있다.

## 운영 규칙 (핵심)

- **파일은 규정당 1개만.** 출처는 `_law_sources.json`의 `sources` 배열로 구분
- **검색 인덱스 편입은 `index` 플래그** — 직접참조 여부로만 결정 (위임으로 간접 포함된 것은 제외)
- 위임 추적 3단계(법률→시행령·시행규칙→위임 행정규칙), `위임구분=인용법령`은 제외

데이터: `법령 PDF/_law_sources.json`
```json
 "개인정보보호법": {
  "name": "개인정보 보호법",
  "file": "L1_개인정보보호법_20251002.xml",
  ...
  "sources": [
   "중기부",
   "창진원"
  ],
  ...
  "index": true,
  "index_reason": "직접참조"
 },
```

## API 주의사항 (상위 5, 전체 14건은 원본 참조)

| # | 주의사항 | 대응 |
|---|---|---|
| 1 | JSON은 단일 원소가 배열이 아닌 객체로 온다 | XML 채택 |
| 2 | `lsDelegated` 위임 일련번호는 구판 | 개정 불변 키로 현행판 재조회 |
| 4 | `위임구분=인용법령`은 위임이 아니라 참조 | 따라가지 않음(참조 범위가 전체 법령으로 확산) |
| 12 | `admbyl` 별표 확장자 `.hwp`인데 실제 HWPX 다수 | 매직바이트 판별 |
| 14 | 다단 레이아웃 PDF는 컬럼이 단어 사이에 끼어든다 | 좌표 기반 컬럼 분리 |
