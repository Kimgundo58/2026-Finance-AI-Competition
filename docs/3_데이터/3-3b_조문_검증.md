# 조문 검증 — 조번호 중복·검증 조건·문자 정제

이 문서가 답하는 질문:
- 같은 조번호가 두 번 나오면 어떻게 처리하는가
- 파싱 결과를 검색 인덱스에 넣어도 되는지는 무엇으로 검증하는가
- 적재 전에 어떤 문자를 정제하는가

(추출 경로·섹션 분리·조문 분할 전략은 [[3-3_파싱_규칙]].)

## 조번호 중복 2종 — 처리가 정반대

| 경우 | 판별 | 처리 |
|---|---|---|
| 목차 중복 | 조제목이 **같다** | 긴 쪽 하나만 |
| 원문 오류 | 조제목이 **다르다** | 둘 다 보존, 뒤엣것에 `[2]` 접미 |

코드: `scripts/article_split.py` · `_build()`
```python
        key = (조번호, 조제목)
        if key in by_key:                      # 목차 중복 — 긴 쪽 채택
            prev = by_key[key]
            if len(body) > len(prev["본문"]):
                prev["본문"] = body
            continue

        dup_count[조번호] = dup_count.get(조번호, 0) + 1
        표기 = 조번호 if dup_count[조번호] == 1 else f"{조번호}[{dup_count[조번호]}]"
```

## 검증 조건 — 실패 시 인덱싱 금지

| 검사 | 경고 접두어 | 실패 시 |
|---|---|---|
| 조 번호가 차례로 커지는지 | `조번호역전:` | 플래그 → 사람 확인 |
| 조 개수 ≥ 5 | `조개수부족:` | 파싱 실패 |
| 빈 조(50자 미만) 비율 < 10% | `빈조과다:` | 추출 실패 의심 (폐지 조문은 제외하고 셈) |
| 교차 참조 검증 | — | 불일치 리포트 → `xref_mismatch` |

코드: `scripts/article_split.py` · `validate()`
```python
    if len(arts) < 5:
        flags.append(f"조개수부족:{len(arts)}")
    ...
    live = [a for a in arts if not is_deleted(a)]
    empty = sum(1 for a in live if len(a["본문"]) < 50)
    if live and empty / len(live) > 0.10:
        flags.append(f"빈조과다:{empty}/{len(live)}")
    ...
    quality = "low" if (strategy in ("paragraph", "chapter") or len(arts) < 5) else "high"
    ok = len(arts) > 0
```

규정 적재 API(`scripts/corpus_ingest.py`)는 `조번호역전:`·`빈조과다:` 경고가 있으면 `parse_quality='low'` 로 둔다.

코드: `scripts/corpus_ingest.py` · `_준비()`
```python
    품질 = ("low" if v["quality"] == "low"
            or any(f.startswith(("조번호역전:", "빈조과다:")) for f in v["flags"]) else "high")
```

하위 문서의 `지침 제N조` 참조는 구판 조번호일 수 있다. 조번호 매칭 실패 시
**조제목(비목명)으로 재매칭**하고 `refs.해결상태='remapped'`로 기록.

## 별표 표 재구성 (표 추출) — 미해결 손실 1건

`[참고N]`·`[붙임N]` 표 섹션은 `_tables.json`(셀 단위 추출)로 조 본문을 교체한다(표 교체 스크립트는 저장소에서 삭제됨).
창업중심대학 참고3 「기계장치(공구·기구, 비품, SW 등)」 비목 행
블록이 재파싱 과정에서 빠졌다. 「단순저장장치」·「외장하드」가 `_articles.json`
원문엔 있고 `corpus.chunks` 엔 **0건**(직접 조회 확인). 본문 총길이는 10,515→10,677자로
**늘어서** 빈 조 비율 검사로는 잡히지 않는다 — 길이 검사를 통과해도 내용 누락은 찾지 못한다.
골든셋 5문항(561·562·563·564·585) 근거가 존재하지 않는다. 미해결.

## 문자 정제 (적재 전 필수)

`NUL`(0x00) 제거 · 짝 없는 서로게이트(U+D800~DFFF) 제거.

코드: `scripts/article_split.py` · `sanitize()`
```python
def sanitize(t: str) -> str:
    """Postgres text 에 넣을 수 없는 문자 제거.
    NUL(0x00) 은 DataError, 짝 없는 서로게이트는 인코딩 오류를 낸다."""
    if not t:
        return ""
    return "".join(
        c for c in t
        if c != "\x00" and not (0xD800 <= ord(c) <= 0xDFFF)
    )
```
