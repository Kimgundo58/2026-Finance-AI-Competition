이 문서가 답하는 질문:
- `2026_Finance_DATA_FOR_RAG/` 안에 무엇이 있는가
- 각 폴더의 파일은 어떤 형식·품질 문제를 갖는가
- 판정 인덱스에 실제로 무엇이 들어갔는지는 어디서 확인하는가

> ⚠️ **이 문서는 압축본이다.** 파일별 상세·개정 이력은
> `2026_Finance_DATA_FOR_RAG/DATASET_STRUCTURE.md`(원본) 참조.
> **판정 인덱스에 무엇이 들어가는지의 기준은 이 문서가 아니라 `corpus.documents`와
> `법령 PDF/_law_sources.json`이다.**

## `PMS/` — 조작 매뉴얼 (42건, PDF)

역할코드 4종: FO(창업자·14) · OR(주관기관·21) · EV(예비위원·5) · AC(위탁회계법인·2).
대부분 화면 캡처 이미지 + 말풍선 주석이라 텍스트 레이어가 거의 없다 —
VLM/OCR 필요. 규범이 아니라 F축 입력 UX 설계 자료.
