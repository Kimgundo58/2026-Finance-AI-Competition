# 저장소 스키마 — 테이블 지도

이 문서가 답하는 질문:
- DB 안에 스키마가 몇 개고 각각 무엇을 담는가
- 어느 테이블이 무슨 역할을 하는가
- RLS는 어디에 걸리는가

> **DDL 전문은 여기 없다.** 기준은 `db/init/*.sql` 16개(번호 순 적용). 이 문서는 표만 본다.
> 저장소는 GCP Cloud SQL(PG17 + pgvector). 로컬은 `db/docker-compose.yml`.

## 스키마 4분할

| 스키마 | 내용 | RLS |
|---|---|---|
| `corpus` | 공개 규범·룰·refs·체크항목. 전 사용자 공통 | 없음 |
| `tenant` | 사용자 것 (L3·계정·F축·지출계획·판정로그·캐시). org별 격리 | 전부 |
| `eval` | 정답셋·평가 run. **검색 인덱스 투입 금지**(`index_guard.py`) | — |
| `ops` | GPU 팟 상태 (`gpu_pod`) | — |

`public` 은 비워둔다.

| `refs` | 참조 그래프 (resolved / shifted / dangling) |
| `rules` / `precedence_rules` | 룰 테이블 ([[5-1_룰_테이블]]) · 효력순위 9행 |
| `item_vocab` / `item_alias` | 비목 어휘집(계통별) · 상품명 → 비목 별칭 |
| `programs` | 사업 8종 메타 |
| `check_items` | "결제 전/후 확인" 폐쇄 목록 52행 · 심층질문 문안(`질문문`·`선택지`·`질문유형`·`필요f필드`) · `기한근거` |
| `evidence_sources` | 증빙 발급처 안내 |

| `xref_mismatch` | 크로스 레퍼런스 불일치 |

`case_chunks`(사례 인덱스)는 2026-09-06 에 드랍했다.

## `tenant` 테이블 (13)

| 테이블 | 내용 |
|---|---|
| `orgs` / `org_programs` | 기관 413행 · 사업×연도별 기관 명부 1,063행 |
| `accounts` | 계정 (`email` ↔ `org_id`, `pw_hash` 비움) |
| `l3_documents` / `l3_articles` | L3 원문 목록 / 조 단위 (벡터 없음 — 검색 안 함) |
| `f_profile` / `f_exec` / `f_personnel` | F1 · F3 · F4 |
| `unmapped_premise` | 결핍 루프 |
| `expense_plans` / `plan_tasks` | 지출 계획 · 체크리스트 |
| `decisions` | 판정 로그 (+`plan_id` · `강등코드[]` · 전제 · 검색 시점 상태) |
| `judge_cache` | 판정 캐시 (키에 설정 해시 포함 — 프롬프트·룰이 바뀌면 자동 무효) |

`decisions`는 corpus가 아니라 tenant다 — 전제·검색 시점 상태에 F축 흔적이 남는다.

## `eval` 테이블 (4)

`golden_set` (정답셋 342행) · `golden_chunks` (정답 근거 청크 고정) · `runs` / `run_items` (평가 실행과 문항별 결과).

## RLS

**1차 방어는 코드다** — 앱이 항상 `org_id`를 명시적으로 건다. RLS는 2차 방어선.

```sql
-- db/init/10_rls_guc.sql
CREATE POLICY org_isolation ON tenant.l3_articles
    USING (org_id = tenant.current_org());
-- current_org() 는 request.jwt.claims → app.org_id 순으로 읽는다.
-- 앱은 요청마다 SELECT set_config('app.org_id', %s, true) 를 건다.
```

- 앱 롤은 비특권 `suddoe_app`(`rolbypassrls=false`). 로컬 `postgres` 는 superuser 라 RLS 가
  적용되지 않는다 — 격리 테스트는 반드시 `suddoe_app` 으로 돈다
- 새 커넥션을 열면 GUC 가 없다. `판정()` 이 커넥션을 새로 열 때 `set_config` 를 다시 건다
  (2026-09-04 사고 — GUC 없는 INSERT 가 RLS 에 막혀 판정이 저장 없이 200 을 냈다)
- 게스트 행은 `org_id IS NULL` 이라 이 정책을 구조적으로 못 넘는다 — [[9_미결]] #19
