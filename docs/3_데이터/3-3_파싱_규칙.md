# 파싱 규칙 — 텍스트 추출과 조문 분할

이 문서가 답하는 질문:
- 원문 텍스트를 조(條) 단위로 어떻게 정확히 잘라내는가
- 조판 오류(문자중복·다단·4분면)는 어떻게 찾아내는가

> 인덱싱 전체 흐름은 [[4-1_인덱싱]]. 이 문서는 파싱 단계 **안의** 텍스트→조문 재구성 방식만
> 다룬다(`scripts/text_extract.py` → `scripts/article_split.py`). 적용대상 태깅 방법은
> [[3-6_적용대상_태깅]] 참조 — 여기서는 다루지 않는다. 조번호 중복·검증 조건·문자 정제는
> [[3-3b_조문_검증]].

## 형식별 경로

| 형식 | 경로 | 근거 |
|---|---|---|
| XML | `extract_xml()` — 그대로 조 단위 | law.go.kr 응답이 이미 조 구조 |
| PDF | **`scripts/pdftext.py::extract()`** → `split_articles()` | `pdfplumber.extract_text()` 직접 호출 금지 — 훅이 경고 |
| HWP (수집분 L1·L2) | 파이프라인에 파서 없음. 한컴오피스 1회 수동 변환 PDF 사용 | 오픈소스 HWP 표 추출 정확도가 실무 수준 미달 — 수집분은 별표·표 위주 |
| HWPX·HWP (L3 사용자 업로드) | HWPX는 zip/XML 직파싱, HWP 5.0은 `hwp_extract.py` 계열 | L3는 조문 텍스트 위주라 표 약점이 덜함. 배포용·암호화 HWP는 실패 처리(`HWP-PROTECTED:`) |

코드: `scripts/text_extract.py` · `_형식()`
```python
    if head.startswith(b"%PDF"):
        return "pdf"
    if head.startswith(b"\xd0\xcf\x11\xe0"):
        return "hwp"
    if head.startswith(b"PK"):
        return "zip"
    if head.lstrip(b"\xef\xbb\xbf \t\r\n")[:5] == b"<?xml":
        return "hwpml" if _xml_루트(path) == "HWPML" else "xml"
```

## 텍스트 추출 — 조판 오류 3종

| 오류 | 검출 | 처리 |
|---|---|---|
| 문자중복 레이어 | 같은 글자가 2중 (`"제제5조조"`) | `dedupe_chars()` |
| 2단 조판 | 단 사이 세로 여백 | 컬럼별 분리 후 순서대로 연결 |
| 4분면(4-up) | 단 사이 세로 여백 + 가로 띠 | 좌상→우상→좌하→우하 |

코드: `scripts/pdftext.py` · `_pages_meta()`
```python
        probe = pages[min(4, len(pages) - 1)].extract_text() or ""
        deduped = dup_ratio(probe) > DUP_THRESHOLD
        src = [p.dedupe_chars() for p in pages] if deduped else pages

        gutter = is_two_column(src)
        quad = is_quadrant(src, gutter)
        texts = [_page_text(p, gutter, quad) for p in src]
```

## 섹션 분리 — 순서가 결과를 바꾼다

```
1. 목차 제거  목차 점선(·····) 10회 이상 + 마지막이 앞 30% 안이면 제거
2. 부칙 판별  뒤 300자의 "시행" 문구 (위치 비율·조 개수는 판별 기준 아님)
3. 붙임 탐지  부칙 뒤에서만 (붙임 표제와 본문 참조 혼동 방지)
```

## 조문 분할 전략 6종 — 앞에서부터 시도해 처음 성립하는 것

| 순위 | 전략 | 패턴 | 대상 |
|---|---|---|---|
| 1 | `article_titled` | `제(\d+)조(제목)` | 법령·지침·규정 대부분 |
| 2 | `outline_numbered` | `제N장`→`N.`→`가.` | TIPS 계열 |
| 3 | `article_untitled` | 제목 없는 `제(\d+)조` | 일부 조례 |
| 4 | `chapter` | `제(\d+)장` | 매뉴얼 |
| 5 | `roman_chapter` | 표제줄 + 로마숫자 단독줄(Ⅰ, Ⅱ, Ⅲ…) | "제N장"이 없는 개요형 문서 |
| 6 | `paragraph` | 빈 줄 2개 | 전부 실패 시 |

코드: `scripts/article_split.py` · `split_articles()`
```python
    # ── 1순위: 제N조(제목) ──────────────────────────────────────
    ms = [m for m in RE_조.finditer(본칙) if not _is_citation(본칙, m.start(), m.end())]
    if len(ms) >= 5 or _짧은_조문구조(본칙, ms):
        arts = _build(본칙, ms, page_offsets, titled=True, base=base)
        return arts + _tail(부칙, 붙임들), "article_titled"

    # ── 개요형: 제N장 > N. > 가. (TIPS 총괄 운영지침) ───────────
    oms = _outline_headings(본칙)
    if len(oms) >= 10 and int(oms[-1].group(1)) >= 10:
        arts = _build_outline(본칙, oms, page_offsets, base)
        return arts + _tail(부칙, 붙임들), "outline_numbered"
    ...
    ms = list(RE_조_제목없음.finditer(text))
    if len(ms) >= 5:
        return _build(text, ms, page_offsets, titled=False), "article_untitled"
```

`outline_numbered`가 `article_untitled`보다 **앞**이다 — 타 법령 인용(`「…법」 제29조`)을 조
표제로 오인하는 것을 막는다. 표제는 **번호 단조성**으로 고른다. `chapter`·`paragraph` 전략이나
조가 5개 미만인 결과는 `parse_quality='low'` — 검색 인덱스 제외.

사례집·판례는 조 체계 문서가 아니다 — 조문 분할을 적용하면 인용된 타 법령 조문을 그
문서의 조로 잘못 잡는다. 단락 분할까지만 하고 `low`로 둔다(사례 인덱스는 현재 쓰지 않는다).
