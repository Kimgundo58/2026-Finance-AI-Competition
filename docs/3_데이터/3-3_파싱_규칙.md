# 파싱 규칙 — Stage 0 메커니즘

이 문서가 답하는 질문:
- 원문 텍스트를 조(條) 단위로 어떻게 정확히 잘라내는가
- 조판 사고(문자중복·다단·4분면)는 어떻게 잡아내는가
- 파싱 결과를 판정 인덱스에 넣어도 되는지는 무엇으로 검증하는가

> 전체 파이프라인(Stage 0~2) 흐름은 [[4-1_인덱싱]]. 이 문서는 Stage 0 **안의**
> 텍스트→조문 재조립 메커니즘만 다룬다. Stage 0.5 적용대상 태깅 방법론은
> [[3-6_적용대상_태깅]] 참조 — 여기서는 다루지 않는다.

## 형식별 경로

| 형식 | 경로 | 근거 |
|---|---|---|
| XML | `extract_xml()` — 그대로 조 단위 | law.go.kr 응답이 이미 조 구조 |
| PDF | **`scripts/pdftext.py::extract()`** → `split_articles()` | `pdfplumber.extract_text()` 직접 호출 금지 — 훅이 경고 |
| HWP (조달분 L1·L2) | 파이프라인에 파서 없음. 한컴오피스 1회 수동 변환 PDF 사용 | 오픈소스 HWP 표 추출 정확도가 실무 수준 미달 — 조달분은 별표·표 위주 |
| HWPX·HWP (L3 사용자 업로드) | HWPX는 zip/XML 직파싱, HWP 5.0은 `hwp_extract.py` 계열 | L3는 조문 텍스트 위주라 표 약점이 덜함. 배포용(DRM) HWP는 실패 처리 |

## 텍스트 추출 — 조판 사고 3종

| 사고 | 검출 | 처리 |
|---|---|---|
| 문자중복 레이어 | 같은 글자가 2겹 (`"제제5조조"`) | `dedupe_chars()` |
| 2단 조판 | 세로 거터 | 컬럼별 분리 후 재조립 |
| 4분면(4-up) | 세로 거터 + 가로 띠 | 좌상→우상→좌하→우하 |

## 섹션 분리 — 순서가 결과를 바꾼다

```
1. 목차 컷    점선 지도(·····) 10회 이상 + 마지막이 앞 30% 안이면 제거
2. 부칙 판별  뒤 300자의 "시행" 언명 (위치 비율·조 개수는 판별 기준 아님)
3. 붙임 탐지  부칙 뒤에서만 (붙임 헤더와 본문 참조 혼동 방지)
```

## 조 분해 전략 5종 — 앞에서부터 시도해 처음 성립하는 것

| 순위 | 전략 | 패턴 | 대상 |
|---|---|---|---|
| 1 | `jo_titled` | `제(\d+)조(제목)` | 법령·지침·규정 대부분 |
| 2 | `outline_numbered` | `제N장`→`N.`→`가.` | TIPS 계열 |
| 3 | `jo_bare` | 제목 없는 `제(\d+)조` | 일부 조례 |
| 4 | `jang` | `제(\d+)장` | 매뉴얼 |
| 5 | `paragraph` | 빈 줄 2개 | 전부 실패 시 |

`outline_numbered`가 `jo_bare`보다 **앞**이다 — 타 법령 인용(`「…법」 제29조`)을 조
헤딩으로 오인하는 것을 막는다. 표제는 **번호 단조성**으로 고른다. 순위 3 이하는
`parse_quality='low'` — 판정 인덱스 제외.

사례집·판례는 조 체계 문서가 아니다 — 조 분해를 태우면 인용된 타 법령 조문을 그
문서의 조로 잘못 잡는다. `case_paragraph`(단락 분할)까지만 하고 `low`로 둔다.

## 조번호 중복 2종 — 처리가 정반대

| 경우 | 판별 | 처리 |
|---|---|---|
| 목차 중복 | 조제목이 **같다** | 긴 쪽 하나만 |
| 원문 오류 | 조제목이 **다르다** | 둘 다 보존, 뒤엣것에 `[2]` 접미 |

## 검증 게이트 — 실패 시 인덱싱 금지

| # | 검사 | 실패 시 |
|---|---|---|
| V1 | 조 번호 단조 증가 | 플래그 → 사람 확인 |
| V2 | 조 개수 ≥ 5 | 파싱 실패 |
| V3 | 빈 조(50자 미만) 비율 < 10% | 추출 실패 의심 (폐지 조문은 제외하고 셈) |
| V4 | 크로스 레퍼런스 검증 | 불일치 리포트 → `xref_mismatch` |

하위 문서의 `지침 제N조` 참조는 구판 조번호일 수 있다. 조번호 매칭 실패 시
**조제목(비목명)으로 재매칭**하고 `refs.해소상태='shifted'`로 기록.

## 문자 위생 (적재 전 필수)

`NUL`(0x00) 제거 · 짝 없는 서로게이트(U+D800~DFFF) 제거.
