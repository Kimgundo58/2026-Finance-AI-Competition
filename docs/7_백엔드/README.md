**`격리감사_0902.md` 의 "org_id 를 응답에 안 싣는다"는 방어가 아니다.** 2026-09-03 에
`org_id = uuid5(uuid5(DNS,"suddoe.org"), 공백뗀 기관명)` 을 재계산해 **413행 중 411행(99.5%)**
을 기관명만으로 맞혔다. 네임스페이스는 `scripts/archive/seed/load_org_programs.py:42` 에 그대로 있다.
실질 방어는 `SUDDOE_ORG_PARAM=0` 하나뿐이다 (`server/auth.py:63`).

## 인용된 루트 md 7벌은 2026-09-02 에 지워졌다

아래 문서들은 **출처 표시**로만 남아 있다 — "이 내용이 어디서 왔나"다. 링크가 아니니
찾아 나서지 마라. 내용은 전부 이 폴더 안에 흡수돼 있다.

## 이 폴더를 읽을 때

- 숫자는 전부 **실측**이다. 뜬 방법을 각 항목에 적어 뒀다
- "테스트 통과"는 "판정이 맞다"가 아니라 "안 죽는다 / 올바르게 뽑았다"의 증거다
- 관측과 추론을 갈라 썼다. 섞어 읽지 말 것

## 미결 — 이 폴더가 못 닫는 것

| 안건 | 막힌 이유 |
|---|---|
| 게스트 격리 | `expense_plans.org_id` 가 uuid + `orgs` FK. 로그인 설계와 분리 불가 (`계약_정정_0902.md` §4) |
| `PUT /api/profile` 쓰기 | `_실_프로필_저장` 이 스텁 그대로. 응답 모양만 동결 |
