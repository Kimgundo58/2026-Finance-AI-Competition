# 7. 백엔드

백엔드 갈래가 쓴다. 계약 기준 문서는 같은 폴더의 `API_계약_v1.0.md` 이고, 이 폴더는 **그 뒤에 서버가
실제로 바뀐 부분**만 싣는다. 충돌하면 이 폴더가 더 최신이다.

| 파일 | 내용 |
|---|---|
| `계약_정정_0902.md` | 2026-09-02 서버 변경분 — 프론트가 알아야 하는 것 |
| `엔드포인트_실측.md` | `app.openapi()` 실측 20메서드 · 쿼리 파라미터 포함 |
| `DB_재현_0902.md` | 빈 DB 에 `db/init` 적용 실측 · psql 메타명령 함정 |
| `프론트_인계_0902.md` | 🔴 프론트가 지금 알아야 하는 것 — 오늘 바뀐 2건 · 화면 체계 · 충돌 |
| `프론트_화면별_지원표.md` | 화면 1~14 지원 상태 · 3체계 대응표 |

## 이 폴더를 읽을 때

- 숫자는 전부 **실측**이다. 뜬 방법을 각 항목에 적어 뒀다
- 「테스트 통과」는 「판정이 맞다」가 아니라 「안 죽는다 / 올바르게 뽑았다」의 증거다
- 관측과 추론을 갈라 썼다. 섞어 읽지 말 것

## 미결 — 이 폴더가 못 닫는 것

| 안건 | 막힌 이유 |
|---|---|
| 게스트 격리 | `expense_plans.org_id` 가 uuid + `orgs` FK. 로그인 설계와 분리 불가 (`계약_정정_0902.md` §4) |
| `PUT /api/profile` 쓰기 | `_실_프로필_저장` 이 스텁 그대로. 응답 모양만 동결 |
| 조항별 해당/불해당 | 판정 출력에 필드가 없다. Agent 층 확장 필요 |
| `decisions.plan_id` 실측 | GPU 팟이 있어야 참이 된다 |
