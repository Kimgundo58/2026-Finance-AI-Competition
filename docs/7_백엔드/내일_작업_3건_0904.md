## ② 서버 — GPU 자동 기동·자동 종료  [백엔드]

지금은 팟 주소가 켤 때마다 바뀌어 **사람이 손으로 Cloud Run 환경변수를 고친다.**
이게 자동화의 실제 장벽이다.

- `POST /api/gpu/wake` — 팟 생성. 이미 있으면 그걸 쓴다
- `GET /api/gpu/status` — `꺼짐 / 기동중 / 준비됨` + 남은 시간(초)
- 🔴 **팟 주소를 DB 에 둔다.** LLM 클라이언트가 env 가 아니라 DB 를 읽는다.
  안 바꾸면 팟마다 재배포가 필요해 자동화가 성립하지 않는다
- **자동 종료: Cloud Scheduler → `POST /api/gpu/reap` 5분마다.**
  지금 워치독은 이 PC 의 로컬 프로세스라 PC 가 꺼지면 같이 죽는다. 3주 무인에 못 쓴다
- RunPod API 키는 Secret Manager. **세션 간에 값을 옮기지 않는다**

비용 가드 — 로그인 한 번이 $0.82/h 를 시작시킨다. 3주 무인이면 여기가 제일 위험하다.
```text

잔액         2026-09-03 기준 $9.15 = 11시간치. 충전 필요
```
