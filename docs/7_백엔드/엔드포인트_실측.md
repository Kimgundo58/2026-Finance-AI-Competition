# 엔드포인트 실측

뜬 방법: `app.openapi()["paths"]` — HEAD·OPTIONS 제외.
`app.routes` 로 세면 안 된다. 이 FastAPI 버전은 `include_router` 를 평탄화하지 않아
라우터 9개가 통째로 빠진다.

아래 표 밖의 `/api` 경로는 `/api/demo/session`·`/api/orgs`(데모 세션·기관 선택)와
호환용 스텁 `/api/gpu/wake`(항상 `{}`)다. GPU 운영(`/api/gpu/status`·`keepalive`·`reap`,
`/admin/gpu/pod`), 규정 자동 적재(`/admin/ingest`·`/admin/ingest/weekly`·`/admin/parse_report`),
`/admin/gate` 는 삭제했다. 프론트 화면 계약(아래 표)은 바뀌지 않았다.
개수는 `app.openapi()["paths"]` 로 다시 센다.
