# 엔드포인트 실측

측정 방법: `app.openapi()["paths"]` — HEAD·OPTIONS 제외. 경로 24개, 메서드 29개(2026-11-01).
`app.routes` 로 세면 안 된다. 이 FastAPI 버전은 `include_router` 를 평탄화하지 않아
라우터 전체가 빠진다.

## `/api` — 프론트 계약 대상

| 메서드 | 경로 | 쿼리 파라미터 |
|---|---|---|
| GET | `/api/health` | — |
| GET | `/api/vocab` | 사업명 |
| GET | `/api/programs` | — |
| POST | `/api/normalize` | — |
| POST | `/api/judge` | mock (`목` 도 받는다 — 구 이름 호환(제거 예정: 다음 릴리스)) |
| GET | `/api/plans` | 탭, 사업명, 확정비목, q, 금액_최소, 금액_최대, 정렬, 페이지, 크기, org_id |
| POST | `/api/plans` | — |
| GET | `/api/plans/{plan_id}` | org_id |
| DELETE | `/api/plans/{plan_id}` | org_id |
| POST | `/api/plans/{plan_id}/tasks` | org_id |
| PATCH | `/api/plans/{plan_id}/tasks/{task_id}` | org_id |
| POST | `/api/plans/{plan_id}/tasks:sync` | org_id |
| GET | `/api/tasks` | 상태, 구분, plan_id, 일정만, 이후, org_id |
| POST | `/api/l3/upload` | — (org_id 는 form 필드 · 필수) |
| GET | `/api/l3/current` | org_id |
| GET | `/api/l3/{doc_id}` | org_id |
| GET | `/api/profile` | — (토큰으로 검증된 기관만. 게스트는 빈 프로필) |
| PUT | `/api/profile` | — (토큰의 기관에 협약 네 값을 저장한다. 게스트는 401) |
| GET | `/api/orgs` | q, 사업명, 페이지, 크기 |
| POST | `/api/demo/session` | — |

`org_id` 쿼리는 검증되지 않은 값이다. 기본값(`SUDDOE_ALLOW_ORG_PARAM=0`)에서는 무시하고 토큰의 기관을 쓴다.
`POST /api/gpu/wake` 는 예전 프론트 호환용 스텁으로 항상 `{}` 를 돌려준다.
