## 1. 연동은 «매핑» 문제다 — 문자열 5개 + 접두사

### 비목 — 10 vs 10, **8개가 문자열까지 정확히 같다**

```js
[`재료비`,`외주용역비`,`기계장치비`,`특허권 등 무형자산 취득비`,`인건비`,
 `지급수수료`,`교육훈련비`,`여비`,`광고선전비`,`창업활동비`]
```

| 프론트 | 서버 enum |
|---|---|
| `기계장치비` | `기계장치` |
| `특허권 등 무형자산 취득비` | `특허권등무형자산취득비` |

나머지 8개는 동일. ⚠️ **부분문자열로 세면 틀린다** — 「기계장치」를 세면
「기계장치비」에 걸려 6회가 나온다. 배열 원문을 봐야 한다.

### 사업 — 8 vs 8, **스코프가 어긋나지 않는다**

```js
[`2026 예비창업패키지`,`2026 초기창업패키지`,`2026 창업도약패키지`,`2026 창업중심대학`,
 `2026 재도전성공패키지`,`2026 모두의 창업 일반・기술`,`2026 초격차 스타트업 1000+`,
 `2026 민관공동 창업자 발굴·육성`]
```

`2026 ` 접두사를 떼고 `corpus.rules` 키와 대조:

| 상태 | 건 |
|---|---|
| 정확일치 | **5** (예비창업 · 초기창업 · 창업도약 · 창업중심대학 · 재도전성공) |
| 라벨만 다름 | **2** — `모두의 창업 일반・기술`↔`모두의 창업 프로젝트` · `초격차 스타트업 1000+`↔`초격차 스타트업 프로젝트` |
| 룰 없음 | **1** — `민관공동 창업자 발굴·육성`(TIPS). `rules` 0행 |

🔴 **어느 쪽이 정본인지 먼저 정해야 한다.** CLAUDE.md 확정 원칙은
「모두의창업은 **일반·기술트랙만**이고 로컬트랙은 범위 밖」이다 —
그렇다면 프론트의 `모두의 창업 일반・기술` 이 **오히려 정확**하고
`rules` 의 `모두의 창업 프로젝트` 가 범위를 흐리는 표기일 수 있다.
**「프론트를 rules 에 맞춘다」로 단정하지 말 것.**

## 2. 프론트가 앞서 있는 것 — 서버가 못 받는다

| 항목 | 프론트 실물 | 서버 |
|---|---|---|
| 지급수수료 하위 | **16종 배열 실재** (기술이전·학회세미나·전시회박람회·시험인증·멘토링·기자재임차·사무실임차·운반·보험·보관·회계감사·세무기장·법인설립·기술보호·수리·규제애로해소법률컨설팅) | ❌ `/api/vocab` 10종, 하위항목 키 없음 |
| 질문뱅크 | **63문항** (상위비목 34 + 지급수수료 하위 29) | 🟡 `check_items` 52행 · 답변 저장 컬럼 미확정 |
| 첨부 확장자 | `accept:.pdf,.hwp,.hwpx,.doc,.docx` (2곳 동일) | ❌ **DOC·DOCX 를 415 로 거부** |
| 첨부 크기 | **3MB** · 최대 10개 (`3*1024*1024` 3곳) | 30MB — 실물이 더 엄격 |
| 집행 일정 | **쓰기 완성** — 추가·저장·삭제·완료 토글 | 🟡 표시만 (`/api/tasks?일정만=true`) |
| AI CHAT | **UI 완성** — 단 `setTimeout` 고정응답 (목) | ❌ 경로 없음 |

🔴 **「만들지 마라」가 아니라 「이미 만든 것을 받을 것인가」가 질문이다.**

## 4. 아직 확정하지 않은 것

`status` 어휘 10종(확인 필요·완료·준비 필요·특이사항 없음·집행·집행 예정·위험·
재점검 필요·점검 전·판정 전)이 **진행 축인지 판정 축인지 확정하지 않았다.**
`aiSummary`·`aiChecks`·`nextAction` 이 `status` 와 **별도 필드**인 것은 확인했고
(`aiStatus`·`judgment`·`riskLevel` 은 0건), 이는 「진행 축」쪽 신호다.
**화면 11 구조를 더 보고 확정한다 — 지금 단정하지 않는다.**
