## 1. 화면별 지원 상태

✅ 백엔드 지원 · 🟡 모양만(목·검수 대기) · ⏸ 설계 미확정(자리만) · ❌ 미지원

| B | 화면 | 상태 | 근거 / 남은 것 |
|:--:|---|:--:|---|
| 1 | 랜딩 | ✅ | API 불필요. 상태 라벨만 4-way 어휘로 |
| 2 | 온보딩① 사업 | ✅ | `GET /api/programs`. 정본은 `precedence_rules` 8사업 — 룰은 2사업뿐이라 **배지로 구분**하고 6개도 선택은 되게 |
| 3 | 온보딩② 기관 | 🟡 | ⚠️ **`tenant.orgs` 2행뿐.** 시연 전 데모 기관 적재 필수. 전국 목록 없다 — 검색은 프론트 필터 |
| 4 | 온보딩③ L3 | ✅ | `POST /api/l3/upload` · `GET /api/l3/{doc_id}`. 🔴 **폴링에 `org_id` 필수**(오늘 고침) |
| 5 | 온보딩④ 완료 | ✅ | 요약 카드. 예시 데이터는 프론트 시드 |
| 6 | 홈 | ✅ | `GET /api/plans` 가 목록+통계 한 번에. 통계 전용 API 없다 |
| 7 | 지출계획 목록 | ✅ | 같은 경로 `?크기=20`. 통계는 **필터 적용 전** 기준 |
| 8 | 새 계획① 기본정보 | ✅ | `POST /api/normalize`. **폼 유지**(0831 결론 뒤집힘) |
| 9 | 새 계획② 비목확인 | ✅ | `GET /api/vocab` — **실측 10종.** 하위항목 키 없음 |
| 10 | 새 계획③ 추가확인 | 🟡 | 질문뱅크 **존치**(위치·형태만 변경). `check_items` 는 있으나 답변 저장 컬럼 미확정 |
| 11 | 지출 상세 | ✅ | `POST /api/judge` SSE. ⏸ 조항별 해당/불해당은 **필드 자체가 없다** — 자리만 |
| 12 | AI CHAT | ❌ | 🔴 **충돌.** 서버에 경로 없음(18경로 전수 확인) — 인계 §3 |
| 13 | 집행 일정 | 🟡 | 표시는 `GET /api/tasks?일정만=true` 로 된다. **서버 기능(알림·메모)은 ❌** — 인계 §3 |
| 14 | 마이페이지 | 🟡 | `GET /api/profile` 정상 · 🔴 **`PUT` 은 실서버에서 저장 안 된다.** `accounts` 0행·인증 미배선 |
