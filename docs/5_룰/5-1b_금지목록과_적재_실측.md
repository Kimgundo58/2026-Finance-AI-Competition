## 2. 불가 0의 원인 (2026-09-04)

**관측** — 불가를 나타내는 필드는 `허용` 컬럼이 아니라 **금지예시**다(§4 가 진작 적어 둔 것과 같다).
`허용` 이 전부 조건부인 건 행 키가 `UNIQUE(layer,기관id,사업명,비목)` = **비목 10종 단위**라
"이 비목 **전체**가 무조건 가능하거나 불가한가"를 묻게 되기 때문이다. 구조상 맞다.

`corpus.rules` 직접 카운트 — 금지예시 358 · 허용예시 225. 룰 제안 절차가 항목별 근거를 단
신규 행을 계속 적재해 늘었다. 무조건/예외단서·핵심어 길이별 분류는 358 기준으로 다시
집계해야 한다(미결).

병목은 매칭이고 결함이 셋이다.

- **긴 핵심어 미일치** — 무조건의 81%가 10자 이상이라 사용자 표현과 일치하지 않는다
- **짧은 핵심어 과일치** — 부분배제를 전체배제로 판정한다
- **괄호 안 예시 누락** — `차량(승용차·화물차…)` 의 핵심어는 `차량 임차 경비` 라 `화물차 임차` 가 미일치

## 3. L1 단서 정정 — 외주용역비 8/8

'불가' 오판 표본 검수에서 L1 제38조③의 "영업비밀보호 등 불가피 시 사전심의 생략 가능"
단서가 여러 사업의 외주용역비 룰에 빠져 있는 것을 발견했다. 5건(rule_id **427·437·446·455·481**)의
`사전승인_조건`에 이 단서를 채웠다 — 실측: **외주용역비 8/8 행 전부**
`사전승인_조건` 원소 ≥1(예비창업 427·초기창업 437·재도전 481 각 1개 · 초격차 446·창업중심대학
455 각 2개 · 모두의창업 474 2개 · 창업도약 464 1개 · L1공통 418 2개).

## 4. 즉시 판정 경로 — 명시 금지목록

카드 사용제한 업종(유흥·위생·레저·사행 등)·구매금지 품목은 item_alias 와 결합해
**LLM 호출 0회로 즉시 "불가"를 반환**한다. 룰의 주요 출처는 별표가 아니라
L2 본문·[붙임2] 표(판정 유효 별표는 4건뿐).

코드: `scripts/rule_lookup.py` · `금지후보()`

```python
_최소매칭길이 = 4          # 정규화한 문자열 기준. '기프티콘'(4자)은 통과, 2~3자 조각은 막는다
...
    for r in 상위_룰(cur, 사업명, 비목, 정보["비목체계"] if 정보 else None):
        for 예시 in r["금지예시"]:
            h = 금지예시_파싱(예시)
            본문n = h["본문_정규화"]
            if len(본문n) < _최소매칭길이:
                continue
            if 품목n and 품목n == 본문n:
                방식 = "정확일치"
            elif 본문n in 입력n:
                방식 = "부분일치"
            else:
                continue
```

