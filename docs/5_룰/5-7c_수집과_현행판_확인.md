# 문서 수집과 현행 판 확인

이 문서가 답하는 질문:
- 1차 범위에서 아직 없는 문서는 무엇이고 어디서 받는가
- 받은 문서가 진짜 현행 판인지 어떻게 확인하는가
- 이미 있는 문서의 판은 어떻게 맞추는가(버전 정렬)

상태: 설계안 v2.1 (2026-11-06). 작업 P0-6 · P0-7([[5-10_구현_작업목록]]). 규정은 판이 맞아야 효력이 있으므로 이 작업이 추출보다 먼저다.

## 수집 절차 (P0-6)

1. 출처 확인: 공식 누리집 · 법령정보센터 · 플랫폼 중 어디에 있는지. 오픈데이터이면 URL 과 이용 조건을 적는다. 아니면 참가자 자격으로 받거나 정보공개청구
2. 내려받기: 파일 · URL · 받은 날짜 · SHA-256 을 `법령 PDF/_law_sources.json`(법령 · 행정규칙) 또는 `2026_Finance_DATA_FOR_RAG/DATASET_STRUCTURE.md`(창진원 문서)에 적는다
3. 진본 · 판 검증 (전부 통과해야 적재):
   - 발행 주체 · 문서 번호(고시 · 훈령 번호, 공고 번호) · 시행일 · 개정 차수가 본문 또는 표지에 있는가
   - 법령정보센터 또는 발행 누리집의 "현행" 표시와 같은가. 개정 이력에서 더 새 판이 없는가
   - 초안 · 안내용 요약 · 캡처본이 아닌가(워터마크 · "(안)" · 페이지 누락)
   - 목차 · 조 수가 본문과 맞는가. 표 · 별지 · 부칙이 있는가
4. 적재: `docs/8_운영/8-7_규정_적재_API.md` 경로(staged → activate), 적용대상 태깅([[3-6_적용대상_태깅]]). 활성화하면 그 문서를 가리키는 규범은 `재검토` 가 된다([[5-8_저장과_조회]])
5. 기록: [[3-2_수집_현황]] 과 `schema.json` 문서키 갱신

## 현행 판 정렬 (P0-7)

| 대상 | 확인 방법 | 지금 알려진 상태 |
|---|---|---|
| 모두의 창업 세부관리기준(개정본) | 창진원 · 플랫폼 공지의 최신 개정본과 대조. 부칙에서 시행일을 읽어 `documents.시행일` 에 적는다 | 시행일 NULL, 부칙 미적재 |
| 통합관리지침 14차 · 운영요령 2024-101호 | 법령정보센터 현행 여부 | 운영요령은 doc_id 2개(P0-2) |
| 1차 범위의 법령(보조금관리법 등) | 법령정보센터 현행 판 시행일과 DB 판 비교 | 2026-11-05 조사: DB 판보다 새 판이 있는 법령 16건, 시행 전 3건(실제 현행 여부 미확인). 1차 범위 안의 것만 먼저 본다 |
| 모집공고 | K-Startup 최신 공고 | 1 · 2차 superseded, 현행 미확인 |

- 결과는 표로 남긴다: 문서 · DB 판 · 확인한 현행 판 · 같음/다름 · 조치
- 다르면 새 판을 수집 절차로 적재하고, 옛 판은 `superseded`. 온톨로지 문서키는 새 doc_id 로 바꾼다

## 주의

- 구현 세션이 직접 한다: 웹 검색 · 페이지 읽기로 출처를 찾고, 내려받고, 위 검증 4항목을 적용하고, 적재한다(2026-11-06 자동화 결정). 받은 파일은 빈 폴더에 두고 스크립트는 그 밖에서 돌린다
- 못 찾거나 검증을 통과하지 못하면 멈추지 않는다. 수집 현황에 "미수집(사유)" 로 적고, 그 문서에 위임된 항목은 "가이드 확인" 조건으로 둔다
- 판이 확인되지 않은 문서에서 추출한 규범은 `AI검증` 으로 올리지 않는다
- 이 작업은 로컬 DB 기준이다. 운영 DB 의 문서 판은 따로 대조한다
