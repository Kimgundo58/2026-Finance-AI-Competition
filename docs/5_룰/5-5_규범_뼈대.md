# 규범 뼈대

이 문서가 답하는 질문:
- 룰 한 줄(규범)은 어떤 모양인가
- 지금 룰 82행과 우선순위 9행은 어떻게 옮기는가

상태: 설계안 (2026-11-02). 개요는 [[5-3_룰_온톨로지_설계]].

## 규범 종류

| 종류 | 뜻 | 코드가 하는 일 | 예 |
|---|---|---|---|
| 금지 | 대상에 해당하면 집행할 수 없다 | 대상 노드(또는 그 하위)와 일치하면 불가 | 광고선전비 중 기프티콘 |
| 상한 | 넘으면 집행할 수 없는 수치 | 입력값과 비교 | 멘토링비 1인 1일 30만원, 시간당 10만원 |
| 기준금액 | 이 값 이상(또는 초과)이면 의무가 생긴다 | 비교한 뒤 의무 규범을 발생시킨다 | 모두의 창업 기계장치 취득가액 500만원 이상 → 사업운영위원회 사전심의 |
| 의무 | 사전승인·증빙·절차·시점 | 판정의 조건과 할 일로 붙인다 | 외주용역비 사전심의, 협약기간 내 납품, 증빙 목록 |
| 우선순위 | 계층·문서 간 적용 순서 | 적용할 규범 집합을 정한다 | 예비 세부관리기준 제3조 |
| 요건 | 자연어 요건(창업아이템과 직접 관련 등) | 비교하지 않는다. 해당 원문을 판정 프롬프트에 넣는다 | 지침 제42조의 비목 정의 |

## 필드

| 필드 | 내용 |
|---|---|
| 규범 ID | `규범:<사업 또는 공통>/<대상>/<종류>/<번호>` |
| 종류 · 계층 · 사업한정 | 위 표의 종류, 근거 문서의 계층(L1/L2/L3), 특정 사업이면 사업 ID |
| 대상 | 개념 노드 ID 목록([[5-4_온톨로지_뼈대]]). 모든 비목에 걸리는 공통 규범(지침 제47조 등)은 `비목:*` |
| 조건 | 구조화 조건 `[{항목, 연산, 값}]`(지역, 주체, 시점 등)과 자연어 조건(원문 발췌) |
| 예외 | 다른 규범 ID 또는 단서 원문 발췌. 예외가 붙은 금지는 즉시 불가(게이트 A) 대상이 아니다 |
| 수치 | 값 · 단위(원/%/개) · 분모(인·일·박·월·시간·건 또는 계약총액·수정인건비 같은 금액 항목) · 분모 주체 · 누적 범위(건별·월·협약기간·지원기간 누적) · 비교(초과/이상) · 부가세 기준(공급가액/포함/정의없음) |
| 결과 | 금지·상한은 불가. 기준금액은 발생하는 의무 규범 ID |
| 근거 | 칸마다 `[{조항 ID, 발췌}]`. 수치의 근거와 조건의 근거를 따로 단다 |
| 검수단계 | `AI초안` → `AI대조` → `사람확정`. `verified` 는 `사람확정` 일 때만 true |

## 표현 규칙

- 규범 하나 = 원문 한 문장(또는 한 항)에서 나오는 효과 하나다. 한 문장에 상한이 둘이면 규범도 둘이다
- 지역별 단가는 지역 조건이 붙은 상한 여러 개로 쓴다(특별시 10만원, 광역시 8만원, 그 밖 7만원)
- 원문의 "이상"과 "초과"를 그대로 옮긴다. 지금 코드는 모두 초과(`>`)로 비교한다
- 원문이 부가세 기준을 정하지 않으면 `정의없음` 으로 둔다. 처리는 [[5-6_판정_결합과_검증]] 의 모호 구간
- 짧은 품목 금지는 품목 노드 + 금지 규범으로, 긴 서술형 금지는 요건 또는 조건부 금지로 쓴다

## 지금 룰 82행에서 옮기기

행 하나를 규범 여러 개로 나눈다. 한도 24행 원문 대조 결과(2026-11-02)를 옮긴 뒤 확인하는 기준으로 쓴다.

| 룰 | 지금 | 옮긴 뒤 |
|---|---|---|
| 473 모두의 창업 기계장치 | 금액 상한 500만원 | 기준금액(이상, 취득가액) → 사전심의 의무 |
| 431·441·476 지급수수료 | 30만원/인/일, 비목 전체 | 대상 `하위:지급수수료/멘토링비` 상한 2개(1인 1일 30만원, 시간당 10만원) |
| 459·468 지급수수료 | 30만원/인/일, 비목 전체 | 대상 멘토링비. 시간당 상한은 원문에 없다 |
| 485 재도전 지급수수료 | 단위 산문에 별도 한도 2개 | 멘토링비 총액 500만원, 기장대행 월 20만원을 각각 상한으로 |
| 486 재도전 여비 | 10만원/인/박, 비목 전체 | 대상 숙박비, 지역 조건 상한 3개. 근거에 공무원여비규정 별표를 단다 |
| 477 모두의 창업 여비 | 숙박비 상한, 비목 전체 | 대상을 숙박비로 한정 |
| 428·438·447·456 기계장치 | 1대/인, 비목 전체 | 대상 PC(456은 사무용 복합기 포함), 분모 주체(대표자·신규채용인력 등), 447은 지원기간 누적 |
| 497 TIPS 연구수당 | 20%, 분모 무시 | 분모 수정인건비. TIPS 는 범위 밖이라 표시만 한다 |

금지예시 454개는 원문 대조(그대로 132, 바꿔 씀 317, 근거 조문에서 못 찾음 5)를 거쳐 위 표현 규칙대로 나눈다.

## 우선순위

- 범위: `all`(상위가 항상 이김), `unspecified_only`(상위에 없을 때만 하위), `상충시`(내용이 부딪힐 때만 상위)
- 출처 종류: `규정조항`(문서가 직접 정함) 또는 `서비스정책`(우리가 정함)을 같이 적는다
- 지금 9행을 옮길 때 고칠 것
  - 재도전(prec 3): 근거를 2026년 11차 개정판 제3조로 바꾼다. 문구는 같다
  - L2>L3 `all` 6행(예비·초기·재도전·도약·창업중심대학·모두의 창업): 원문은 "상충되는 경우"만 말한다. 지금 코드는 L2 가 다루지 않는 L3 금지까지 지운다
- 서비스 정책(2026-11-01): L3 에 상위 규정 준용 문구가 없으면 L3 를 그대로 적용한다(L2 보다 느슨해도). 세부관리기준 제3조와 다르므로 아래 미결로 둔다

## 미결

| # | 항목 |
|---|---|
| 1 | L3 정책과 세부관리기준 제3조("상충 시 관리기준 우선")가 다르다. L3 가 더 느슨해 '가능'이 나오면 규정상 틀린 '가능'일 수 있다. 그 판정에 표시만 할지, 조건부로 낮출지 |
| 2 | 사업별 × 기관유형별 분기(참여율 100%/130% 등, [[5-1_룰_테이블]] §3)를 조건으로 다 담을 수 있는지. 표현 검증에서 확인한다 |
