# 도메인 모델과 능력 질문 (1차: 모두의 창업 프로젝트)

이 문서가 답하는 질문:
- 온톨로지가 답해야 하는 질문(능력 질문)은 무엇인가
- 도메인 개념은 무엇이고 규정 원문 어디에서 오는가
- 지금 테이블(`rules` · `item_vocab` · `item_alias`)과 무엇이 다른가

상태: 설계안 v2.1 (2026-11-06). 미구현. 입력은 DB 원문(`corpus.doc_articles`)뿐이고 기존 룰·별칭 테이블은 보지 않는다.
개요는 [[5-3_룰_온톨로지_설계]], 스키마는 [[5-4b_온톨로지_스키마]], 규범은 [[5-5_규범_구조]].

## 능력 질문 (competency questions)

온톨로지 공학에서 설계 범위를 정하는 표준 방법이다. 아래 질문에 구조만으로(LLM 없이) 답할 수 있어야 한다.
각 질문은 [[5-9_검증과_측정]] 의 테스트 질의가 된다. 사례와 기대 답은 `ontology/테스트/능력질문.json` 에 둔다.

| ID | 질문 | 답에 필요한 개념 |
|---|---|---|
| CQ-01 | 이 지출(품목 · 용도)은 어느 비목 · 세목에 속하는가 | 품목 → 세목 → 비목 계층, 별칭 |
| CQ-02 | 이 사업에서 그 세목에 걸리는 규범은 무엇인가 | 규범, 적용사업, 상속 |
| CQ-03 | 규범의 근거 조문과 준용 사슬(세부관리기준 → 지침 → 운영요령 → 법)은 | 조문 ID, 준용 · 위임 관계 |
| CQ-04 | 규범에 예외(단서)가 있는가, 조건은 무엇인가 | 예외 · 우선(override) 관계 |
| CQ-05 | 승인 · 심의 주체는 누구이고 언제 받아야 하는가 | 행위자, 절차, 시점 |
| CQ-06 | 거래 상대에 대한 제약은 무엇인가 | 거래처 유형, 특수관계, 당해연도 참여기업 |
| CQ-07 | 시간 제약은 무엇인가 | 협약기간, 집행 가능기간, 개최 시점 |
| CQ-08 | 수치 비교에 필요한 입력값은 무엇인가 | 금액(부가세 기준) · 인원 · 일수 · 시간 · 계약총액 · 출장지 |
| CQ-09 | 상위 · 하위 규정이 충돌하면 무엇이 적용되는가 | 우선순위 규범, 범위(all · unspecified_only · 상충시) |
| CQ-10 | 연결된 L3 조문 중 이 세목 · 상위 비목에 걸리는 것은 무엇인가 | L3 조문의 개념 연결(업로드 때 사람이 확인한 값) |
| CQ-11 | 이 조문은 어느 판이고 현행인가 | 문서키 → 현행 doc_id, 시행일, 개정 관계 |
| CQ-12 | 같은 개념을 다른 이름으로 부르는가 | 동치(창업기업등 → 진출자, 선언한 조문 범위 안에서), 세목 명칭 차이 |

## 개념 모델

규정이 스스로 정의한 어휘로 그린다. 괄호는 원문 위치(모두의 창업 세부관리기준은 조번호만, 지침은 「지침」을 붙임).

```
행위자        총괄기관(중기부) · 전문기관(창업진흥원) · 전담기관(소진공) · 지역허브기관 · 멘토기관
              주관기관 = 지역허브기관 + 멘토기관 (제2조9) · 협력기관 · 운영기관 · 운영사
              멘토 = 책임멘토 | 기술멘토 | 선배멘토 (제2조15)
              도전자 → 진출자 → 후속 지원자 · 재도전 대상자 (제2조16~19)
              거래처 = 사업자등록 업체 | 프리랜서 마켓 등록 개인 | AI솔루션 공급기업 (제35조①, 제2조25)
              심의 · 검토 주체 = 사업운영위원회 (제11조, 제34조③) · 책임멘토 (제35조③) · 회계법인 (제34조②, 제39조⑧)
돈            사업비 (제2조23)
                ├ 주관기관 사업비 (제24~32조, 별지1)            ← 서비스 범위 밖 (검색 FILTER 와 같음)
                └ 진출자 자금 — 자금 종류가 먼저 갈린다 (돈마다 비목과 규범이 다르다)
                    ├ 창업활동자금 (제2조20, 제31조 위임 → 전문기관 「1R 진출자 지원 안내 책자」): 1R, 진출자 개인 선불카드 200만원,
                    │   책자의 비목 5개(문헌구입비 · 회의비 포함), 50만원 초과 멘토기관 사전승인, 10만원 미만 증빙 생략, 택시 · 식사 허용
                    ├ 시제품제작비 (제2조21, 제33조①): 재료비 · 외주용역비 · 특허권등 · 지급수수료 · 여비 · 기타 인정 비목 ← 제34~37조 · 별지2 · 지침 준용
                    │   제34조는 재료비와 기계장치를 한 조에서 다룬다 → 두 비목 모두에 근거를 단다
                    └ 사업화자금 (제2조22): 후속 지원자. 제2편에 비목 조문 없음
                    비목 공통 노드는 지침 표-10 의 10개. 사업 · 자금 종류가 쓰는 비목은 `사용` 관계로 적는다
                      세목 (별지2 · 지침 제42조): 멘토링비 · 시험인증비 · 기자재임차비 · 사무실임차료 · 회계감사비 …
                        품목 (원문 열거): 귀금속·보석·원석 · 데이터 · 서버 · 차량 임차 · 보증금 · 관리비 …
사건          집행 건 = 품목 × 금액(부가세 구분) × 거래처 × 시점(납품 · 사용 · 개최 · 지급) × 지출 수단 × 증빙 집합
절차          사전승인 (지침 제37조②) · 사전심의 (제34조③, 제35조②) · 사전 검토 (제35조③) · 심의 생략 (제35조④)
              점검 · 최종점검 · 정산 · 사용실적 보고 (제40~46조)
시간          협약기간 · 사업비 집행 가능기간 (별지2) · 당해연도 (제35조②표-4) · 2년 이내 재직 (제35조②표-4)
              1인 1일 · 시간당 (제36조①) · 1인 1박 (제37조④) · 월 단위 계약 (별지2 사무실임차료)
문서 · 효력   법 → 운영요령 → 지침 → 세부관리기준 → 집행 가이드(전문기관의 장) → 주관기관 내부규정(L3)
              우선 적용 (제4조①) · 상충 시 관리기준 우선 (제4조②) · 준용 (제33조②, 제39조①)
              동치: 제39조①은 지침 제49조 안의 창업기업등 → 진출자, 제11조①은 지침 제11조 안의 창업기업등 → 멘토기관 또는 진출자 (조문마다 다르다)
규범          금지 · 허용 · 한도 · 임계값 · 의무 · 요건 · 우선순위 — 위 개념들 사이의 다항 관계 ([[5-5_규범_구조]])
```

원문 확인: 제2조 1~27호, 제4조, 제11조①, 제31조, 제33~37조, 제39조, 별지2, 지침 제36조 표-10 · 제37조 · 제42조 (로컬 DB 2026-11-06).
제35조에는 표-4 가 둘(②와 ③) 있고, 표-4 · 표-6 은 DB 원문에서 셀이 풀려 있어 PDF 대조가 필요하다 ([[5-7_원문_추출_절차]]).

## 지금 테이블과의 차이

| 지금 | 도메인 모델 |
|---|---|
| `rules` 1행 = (사업, 비목). 세목 · 주체 · 시점은 `한도_단위` · `사전승인_조건` 문자열 안 | 세목 · 행위자 · 사건 · 시간이 노드다. 규범은 노드들을 잇는 관계 1개 |
| `item_vocab.하위항목` 은 지급수수료 17개만 | 세목은 별지2 · 지침 표-10 · 제42조 열거를 전부 노드로, 사업한정 표시 |
| `item_alias` 품목 → 비목 문자열, 근거 칸은 코드가 안 읽음 | 품목 → 세목 → 비목 계층, 연결종류(원문명시 · 해석), 근거 발췌 필수 |
| `refs` 문자열 참조 → 조 단위 해결 | 준용 · 위임 · 동치를 관계 종류로 구분, 항 단위 |
| `precedence_rules` 9행 | 우선순위 규범 1종으로 통합, 범위와 출처(규정조항 · 서비스정책)를 조건에 적는다 |
