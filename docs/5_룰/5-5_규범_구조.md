# 규범 모델

이 문서가 답하는 질문:
- 규범(룰 한 줄)의 종류와 필드는 무엇인가
- 수치 · 예외 · 우선순위를 어떻게 적고, 비교 연산은 무엇을 뜻하는가
- 원문 한 항을 규범으로 어떻게 나누는가

상태: 설계안 v2.1 (2026-11-06). 미구현. 기존 `corpus.rules` 82행은 이관하지 않고 원문에서 다시 추출한다 ([[5-7_원문_추출_절차]]). JSON 키는 [[5-8b_원천_JSON_형식]].

## 기반

| 출처 | 가져오는 것 |
|---|---|
| LegalRuleML (OASIS) | 의무론 규범(금지 · 허용 · 의무), 규범 사이 우선관계(override), 반박가능(defeasible) 규칙 |
| Catala | 조문 = 원칙 + 단서(예외). 단서는 원칙을 덮어쓴다 |
| DMN 결정표 | 입력 · 출력을 먼저 고정하고 결합 순서를 표로 정한다 ([[5-6_판정_결합과_검증]]) |

## 종류

| 종류 | 뜻 | 코드가 하는 일 | 원문 예 (모두의 창업) |
|---|---|---|---|
| 금지 | 대상에 해당하면 집행 불가 | 예외 없는 금지에 일치하면 불가(게이트 A). `AI검증` 이상 규범 + 사용자가 확정한 노드일 때만 | 제37조⑥ 국외 여비 · 제37조② 식비 · 일비 · 별지2 주관기관 소속 인력 멘토링비 |
| 허용 | 집행할 수 있다 | 판정을 올리지 않는다. LLM 문맥과 질문 재료로만 | 제34조③ 기구 · 비품 · 기계 구입 가능 · 지침 제42조③ 임직원 참가비 |
| 한도 | 넘으면 집행 불가인 수치(규정 용어 "한도") | 입력이 있으면 비교. 예외 없는 초과는 판정 LLM 없이 불가 | 제36조① 1인 1일 30만원 · 시간당 10만원 · 제37조④ 표-6 · 제35조② 선금 50% |
| 임계값 | 이상(또는 초과)이면 의무가 생기는 수치 | 비교 뒤 의무 규범을 활성화 | 제34조③ 500만원 이상 → 사전심의 · 제35조② 2천만원 초과(부가세 포함) → 사전심의 · 제36조① 12만5천원 초과 → 공제 |
| 의무 | 절차 · 증빙 · 시점 · 지급 방식 | 조건부 판정의 조건과 할 일 | 제34조① 협약기간 내 납품 · 사용 · 제35조① 프리랜서 마켓 대금은 플랫폼 통해서만 · 별지2 증빙 서류 |
| 요건 | 자연어 판단이 필요한 조건 | 비교하지 않는다. 원문을 판정 프롬프트에 넣는다 | 제35조① "시제품 제작 및 사업화를 위해" · 지침 제37조③ 연관성 |
| 우선순위 | 문서 사이 적용 순서 | 적용 규범 집합을 정한다. `precedence_rules` 를 대체 | 제4조① 운영요령 · 지침 우선, 명시되지 않거나 달리 정한 것은 관리기준 · 제4조② 내부규정과 상충 시 관리기준 |

규정이 "기준금액"을 한도 뜻으로도 쓰므로(제37조④ "지급 기준금액을 초과하여 집행할 수 없다") 의무를 발동시키는 수치는 **임계값** 이라 부른다.

## 필드

| 필드 | 내용 |
|---|---|
| 규범 ID | `규범:<사업키\|공통>/<조문 키>/<종류>/<순번>` ([[5-8b_원천_JSON_형식]]) |
| 종류 · 계층 · 적용사업 | 위 종류, 근거 문서 계층(L1 · L2 · L3), 사업한정이면 `corpus.programs.사업명` |
| 대상 | 개념 노드 ID 목록. 비목 전체면 비목 노드, 모든 비목이면 `비목:창업/*`. 하위 노드는 상속한다 |
| 수범자 · 승인주체 | 규범을 지켜야 하는 주체(진출자 · 팀원) · 승인 · 심의하는 주체(사업운영위원회 · 전문기관의 장 · 책임멘토) |
| 조건 | 구조화 `[{항목, 연산, 값}]`(지역 · 거래처 유형 · 시점) + 자연어 조건(원문 발췌). 우선순위 규범은 `{상위, 하위, 범위, 출처}` |
| 수치 | 아래 수치 모델 |
| 시점 | 의무를 언제 이행하나: `집행 전`(사전승인 · 서약서) · `집행 후`(증빙 · 보고서) · `기한`(날짜 또는 "협약기간 내") |
| 증빙 | 의무가 요구하는 증빙 노드 목록(주문상세내역서 · 실물사진 · 자산보유서약서 · 붙임2 …). 조건(금액 · 결제 유형 · 사용처 확인 가능)에 따라 다르면 규범을 나눈다 |
| 결과 | 금지 · 한도는 불가. 임계값은 활성화할 의무 규범 ID. 의무는 조건 문장. 어기면 따르는 제재(환수 · 참여 제한 n년)는 `제재` 로 적는다 |
| 예외 | override 하는 규범 ID 또는 단서 발췌. 예외가 붙은 금지 · 한도는 즉시 불가 대상이 아니다 |
| 해석미결 | 원문이 서로 다르거나 불명확해 검증 에이전트도 가르지 못한 규범. true 면 코드 판정에 쓰지 않고 결정 로그에 남긴다 |
| 근거 | 칸마다 `[{조문 ID, 발췌}]`. 수치 · 조건 · 대상 근거를 따로 단다 |
| 검수단계 | `AI초안` → `AI대조`(독립 추출 2회 일치) → `AI검증`(검증 에이전트가 PDF 원문과 대조) → `사람확정`(선택). 개정 뒤 `재검토`. `verified` 는 `AI검증` 이상 |

## 수치 모델과 비교 연산

| 요소 | 값 | 비고 |
|---|---|---|
| 값 · 단위 | 300000 · 원 / 50 · % / 1 · 대 | |
| 위반연산 (한도) | 초과 · 이상 | "30만원 한도" · "이하" · "초과 불가" → 초과. "미만이어야" → 이상. 입력이 이 연산을 만족하면 위반 |
| 발동연산 (임계값) | 이상 · 초과 | "500만원 이상 … 사전심의" → 이상. 입력이 만족하면 의무 활성 |
| 분모 · 분모주체 | 인 · 일 · 박 · 시간 · 건 · 월 · 계약총액 · 용역비총액 / 진출자 본인 · 팀원 · 멘티 | "1인 1일" 은 분모 2개 |
| 누적범위 | 건별 · 동일업체합계 · 월 · 협약기간 | 제35조② "동일 거래업체와의 거래금액" |
| 부가세 | 포함 · 공급가액 · 정의없음 | 제35조② 는 "부가가치세 포함" 명시, 제36조① 은 정의없음 |
| 지역 | 특별시 · 광역시 · 그밖 | 표-6 → 한도 규범 3개, 입력은 출장지 구분 |

비교 절차: 입력 부가세 구분(포함 · 공급가액 · 모름)과 규범 `부가세` 를 맞춘다(공급가액 ×1.1 ↔ 포함). 입력이 `모름` 이면 코드가 "부가세 포함 금액인가요?" 를 묻는다.
규범이 `정의없음` 이면 두 기준으로 다 비교해 결과가 같을 때만 쓰고, 갈리면 판단불가(`VAT_BASIS_UNKNOWN`).

## 작성 규칙

- 규범 1개 = 원문 한 문장(또는 한 항)에서 나오는 효과 1개. 단서("단,", "다만", "~에도 불구하고")는 별도 규범으로 쓰고 원칙에 `예외` 로 잇는다
- "이상" · "초과" 는 원문 그대로 위반연산 · 발동연산으로 옮긴다. 지금 코드는 전부 `>` 하나다(`rule_lookup._비교_금액`)
- 짧은 품목 금지는 품목 노드 + 금지 규범, 긴 서술형 금지는 요건. 표(표-4 · 표-6)는 PDF 대조 뒤에 적는다
- 준용 대상이 조문 밖("소득세법 시행령을 준용")이면 추출 때 조문을 특정하고, 못 하면 `미특정` 으로 남긴다
- 모든 칸에 근거 발췌. 근거 없는 규범은 적재하지 않는다

## 예: 제36조① + 별지2 멘토링비 유의사항

```
규범:모두의창업/제36조①/한도/1      300,000 원 · 위반연산 초과 · 분모 인 · 일 · 부가세 정의없음      근거 제36조① "1인 1일 최대 30만원 한도"
규범:모두의창업/제36조①/한도/2      100,000 원 · 위반연산 초과 · 분모 시간                          근거 제36조① "시간당 10만원 초과 불가"
규범:모두의창업/제36조①/임계값/1    125,000 원 · 발동연산 초과 → 의무/1                              근거 제36조① "12만 5천원을 초과하는 경우"
규범:모두의창업/제36조①/의무/1      기타소득세 등 공제 후 집행 · 준용 소득세법 시행령(미특정)          근거 제36조①
규범:모두의창업/별지2/지급수수료/유의사항/금지/1   수범자 진출자 · 조건 거래처 = 주관기관(전담조직) 소속 인력   근거 별지2 "주관기관(전담조직) 소속 인력에게 집행 불가"
```
별지2 유의사항은 30만원 · 10만원 한도를 되풀이하지만 12만5천원 조항은 없다(확인). 한도 1 · 2 의 근거는 두 곳이다.

## 충돌 예와 처리 원칙 (2026-11-06 결정)

지침 표-10 기타 "비교견적서: 2천만원 이상", 별지2 기타 "2천만원을 초과(부가가치세 포함)", 제35조② "2천만원을 초과(부가가치세 포함)", 제35조②표-4 제목 "외주용역비(2천만원 이상)".
원칙: 제4조① "지침과 달리 정하는 사항은 본 관리기준" 대로 **관리기준(초과)이 이긴다.** 우선순위 규범으로 적고, 두 기준의 결과가 갈리는 금액(정확히 2천만원)에서는 조건부로 내리고 화면에 두 기준을 함께 보여 준다.
같은 문서 안의 충돌(제35조② "초과" vs 표-4 제목 "이상")은 본문 조항이 표 제목보다 우선한다. 원칙으로 못 가르는 경우만 `해석미결=true`.

## 결정됨
