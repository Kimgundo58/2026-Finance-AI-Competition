# 구현 작업목록 (인수인계용)

이 문서가 답하는 질문:
- 누가 무엇을 어떤 순서로 하는가. 수직 슬라이스는 어디까지인가
- 각 작업의 입력 · 산출물 · 완료 기준은 무엇인가
- 이번 범위에서 하지 않는 것은 무엇인가

상태: 설계안 v2.1 (2026-11-06). 구현: 모두의 창업 P0~P4 로컬 끝, P5-1 은 LLM 없는 범위만, P5-2 본 측정 · P5-3 전, 운영 미적용(작업별 범위는 `ontology/진행상황.md`, 2026-11-08). 역할: 구현 세션(Claude Code + 하위 에이전트 Opus 5.5 high)이 수집 · 추출 · 검증 · 코드 · 측정을 전부 한다.
사용자 게이트는 main 병합과 운영 반영(P5-3)뿐이다. 완료 기준은 CLAUDE.md 의 "end-to-end 검증" 을 따른다: 화면 경로에서 효과가 확인돼야 완료다.

## 순서

```
슬라이스 (제33조 · 제36조 · 별지2)   P0-1s → P0-3 → P1-1 → P2-1s → P2-2 → P2-3 → P3-1 → P3-2 → P3-3 → P4-1 → P4-2 → P4-3 → P4-4 → P4-7 → 화면 확인
확장                                 P0-1 → P0-2 · P0-4 · P0-5 → P1-2 → P1-3 → P2-1 → (재적재) → P4-5 → P4-6 → P3-4 → P5
```
슬라이스가 화면까지 통과하기 전에는 P1-2(전체 추출)를 시작하지 않는다. 코드가 읽지 않는 테이블 · 칸은 만들지 않는다.
