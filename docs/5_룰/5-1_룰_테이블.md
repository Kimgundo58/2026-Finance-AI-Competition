# 룰 테이블

이 문서가 답하는 질문:
- 왜 숫자를 룰로 빼는가
- 무엇을 룰로 빼고 무엇을 안 빼는가
- `rules` 테이블 구조는

적재 실측·금지목록 즉시 판정은 [[5-1b_금지목록과_적재_실측]] 에 있다.

## 0. 목적

숫자 비교를 LLM 에게 안 시키기 위해서다.

```text
"한도 3% 이내" + "신청액 250만원 / 사업비 5,000만원 = 5%"  → 계산. 코드가 한다
"직접 연관성을 소명하고 사전승인을 받아야 한다"           → 요건 충족 판단. 룰로 고정하면 오류가 드러나지 않는다
```

## 1. 경계

| 룰로 뺀다 | 룰로 만들지 않는다 |
|---|---|
| 별표·한도표의 숫자 | 조문 본문의 자연어 요건 |
| 비율/금액/개수 상한 | "직접 연관성", "사업 목적 부합" |
| 명시 금지 목록 | "범용성 기자재는 소명 필요"의 판단 |
| 사전승인 필요 여부(플래그) | 사전승인을 받을 수 있는지의 판단 |
| 비목별 증빙 서류 목록 | 증빙이 충분한지의 판단 |
| 우선순위 조항(효력 결정) | 우선순위 없을 때 대체 경로 판단 |

## 2. 비목 어휘집

정규화 `비목후보` · `rules.비목` · `item_alias.비목` · 골든셋이 같은 고정 목록(enum)을 쓴다.

| 적용범위 | 출처 |
|---|---|
| 공통(기본 어휘) | L1 통합관리지침 제36~45조 |
| 사업별 확장 | L2 [붙임2] 비목 해설표(해당 사업 범위 한정) |

산출물 `_비목_어휘집.json` — 31비목(창업기업10/주관기관18/미상3), `비목_enum` 10종,
검수대기 0.

데이터: `2026_Finance_DATA_FOR_RAG/_비목_어휘집.json` · `비목_enum`

```json
 "비목_enum": [
  "광고선전비",
  "교육훈련비",
  "기계장치",
  "여비",
  "외주용역비",
  "인건비",
  "재료비",
  "지급수수료",
  "창업활동비",
  "특허권등무형자산취득비"
 ],
```

정규화 출력 스키마가 실행 시점에 이 목록을 읽어 enum 으로 건다(`scripts/llm_schema.py` `비목_enum()`).

## 3. `rules` 컬럼

| 컬럼 | 뜻 | 비고 |
|---|---|---|
| layer/기관ID/사업명/비목 | 조회 키 | UNIQUE |
| 허용 | 가능/조건부/불가 | |
| 사전승인 + 사전승인_조건 | 플래그 + 조건 문구 | `사전승인_조건` **TEXT→TEXT[]** 배열화(커밋 `fe58488`). 한 행이 조건을 둘 이상 담는다 — 전체 74행에 원소 **59개**(`corpus.rules` 직접 카운트). 병합은 [[5-2b_조건_병합과_L3_확인]] §2 참고 |
| 한도_유형/한도_값/한도_단위 | 비율·금액·개수 | 코드가 비교 |
| 증빙 TEXT[] | 비목별 서류 | |
| 금지예시/허용예시 | | item_alias 와 결합 |
| 근거 JSONB | `[{doc_id,조번호}]` | 없으면 룰이 아니다 |
| verified | 사람 검수 여부 | 한 조합에 붙은 룰이 **전부** false 면 "가능"→조건부로 하향 |

코드: `db/init/01_schema.sql` · `corpus.rules`

```sql
CREATE TABLE corpus.rules (
    ...
    허용          TEXT NOT NULL CHECK (허용 IN ('가능','조건부','불가')),
    ...
    한도_유형     TEXT CHECK (한도_유형 IN ('비율','금액','개수') OR 한도_유형 IS NULL),
    한도_값       NUMERIC,
    한도_단위     TEXT,
    ...
    근거          JSONB NOT NULL DEFAULT '[]',   -- [{doc_id, 조번호}]
    ...
    verified      BOOLEAN NOT NULL DEFAULT FALSE,
    ...
    UNIQUE (layer, 기관ID, 사업명, 비목)
);
```

- 사업별 × 기관유형별 이중 분기 존재(참여율 100%/130% 등) — 참여인력 프로필의 소속기관유형 필요
- 룰 유형 실측 18종 — 현행 3컬럼(한도_유형/값/단위)으로 다 못 담는다.
  분기 스키마 설계가 다음 단계 선결 과제
