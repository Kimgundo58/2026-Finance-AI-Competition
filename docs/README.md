# 문서 지도

「써도돼요」 — 창업지원금 지출비 사전승인 판정 서비스.

`docs/` 아래 문서는 100줄 이하다. 면제 대상은 아래에 열거한다.

## 어디부터 읽나

| 상황 | 순서 |
|---|---|
| 처음이다 | `1_배경/` → `0_현황.md` → `2_구조/` |
| 코드를 고친다 | `0_현황.md` → 해당 축(3~8) |
| 공모전 제출·심사용 요약이 필요하다 | `제출_공모전_설명.md` — 데이터·검색·프롬프트·인젝션방어·성능표 한 장 |

그 밖에 100줄을 조금 넘는 문서가 몇 있다 (`8-5_배포_레시피` · `5-1_룰_테이블` · `5-2_효력_결정` · `6-2_출력_스키마` · `제출_공모전_설명`). 넘으면 쪼갠다.

## 충돌하면 무엇을 믿나

1. **코드가 기준인 것** — 문서와 어긋나면 코드를 믿는다
   `scripts/pdftext.py` · `db/init/01_schema.sql` · 인덱싱 경로는 `scripts/retrieve.py` 의 FILTER 로 막는다 ·
   `법령 PDF/_law_sources.json` · `2026_Finance_DATA_FOR_RAG/_refs.json` ·
   `2026_Finance_DATA_FOR_RAG/_precedence_rules.json`
2. **실측이 기준인 것** — 수치는 DB 가 이긴다
3. 그 밖은 `0_현황.md`
