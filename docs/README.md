## 코드 발췌

설계 문서의 코드 블록은 실제 코드를 그대로 옮긴 것이다. 블록 바로 위 출처 줄
(`코드:` · `현재 코드:` · `데이터:` + 파일 경로 + 함수·테이블 이름)이 원본을 가리킨다.
생략한 곳은 `...` 한 줄로 표시한다. 실제 코드가 아닌 블록에는 `예시 (실제 코드 아님)` 을 붙인다.
`현재 코드:` 는 설계안이 바꾸려는 지금 코드다.

## 충돌하면 무엇을 믿나

1. **코드가 기준인 것** — 문서와 어긋나면 코드를 믿는다
   `scripts/pdftext.py` · `db/init/01_schema.sql` · `scripts/retrieve.py` 의 FILTER(검색 대상 조건: 계층 L1·L2, 적용대상, `retrieval_scope`) ·
   `법령 PDF/_law_sources.json` · `2026_Finance_DATA_FOR_RAG/_refs.json` ·
   `2026_Finance_DATA_FOR_RAG/_precedence_rules.json`
2. **실측이 기준인 것** — 수치는 DB 값을 따른다
3. 그 밖은 `0_현황.md`
