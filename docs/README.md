# 문서 지도

「써도돼요」 — 창업지원금 지출비 사전승인 판정 서비스.

**모든 문서는 100줄 이하다.** 넘으면 쪼갠다 (기록 제외).

## 어디부터 읽나

| 상황 | 순서 |
|---|---|
| 처음이다 | `1_배경/` → `0_현황.md` → `2_구조/` |
| 코드를 고친다 | `0_현황.md` → 해당 축(3~7) → `9_미결.md` |
| 무엇이 안 됐나 궁금하다 | `9_미결.md` |
| 언제 무엇을 했나 궁금하다 | `기록/00_기록_목차.md` |

## 충돌하면 무엇을 믿나

1. **코드가 정본인 것** — 문서와 어긋나면 코드를 믿는다
   `scripts/pdftext.py` · `db/init/01_schema.sql` · `scripts/index_guard.py` ·
   `법령 PDF/_law_sources.json` · `2026_Finance_DATA_FOR_RAG/_refs.json` ·
   `_precedence_rules.json`
2. **실측이 정본인 것** — 수치는 DB 와 SessionStart 훅이 이긴다
3. 그 밖은 `0_현황.md`

## 기록은 고치지 않는다

`기록/` 은 그 시점의 관측이다. **낡은 값을 소급 수정하지 마라** — 「그때 무엇을 보고
그렇게 판단했나」가 사라진다. 낡았으면 본문이 아니라 머리에 상태 배너를 단다.
