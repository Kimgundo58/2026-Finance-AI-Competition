## 100줄 상한이 면제되는 곳

「모든 문서는 100줄 이하」가 검사 가능한 규칙이 되려면 예외를 숨기지 않아야 한다.

| 경로 | 왜 |
|---|---|
| `docs/기록/**` | 그 시점의 관측 기록. 요약하면 "그때 무엇을 보고 그렇게 판단했나"가 사라진다 |
| `docs/부록/**` | 참고 자료 — 통독 대상이 아니라 필요할 때 펴는 전문(全文). 요약은 각 부록의 배너가 가리키는 축 파일에 있다 |
| `docs/7_백엔드/API_계약_v1.0.md` (387줄) | 계약 명세 전문 |
| `docs/7_백엔드/API_DB_명세_v1.md` (755줄) | 생성기 기본 출력물 |

그 밖 모든 문서는 100줄 이하다. 넘으면 쪼갠다.

## 충돌하면 무엇을 믿나

1. **코드가 기준인 것** — 문서와 어긋나면 코드를 믿는다
   `scripts/pdftext.py` · `db/init/01_schema.sql` · `scripts/index_guard.py` ·
   `법령 PDF/_law_sources.json` · `2026_Finance_DATA_FOR_RAG/_refs.json` ·
   `2026_Finance_DATA_FOR_RAG/_precedence_rules.json`
2. **실측이 기준인 것** — 수치는 DB 와 SessionStart 훅이 이긴다
3. 그 밖은 `0_현황.md`

## 기록은 고치지 않는다

`기록/` 은 그 시점의 관측이다. **낡은 값을 소급 수정하지 마라** — 「그때 무엇을 보고
그렇게 판단했나」가 사라진다. 낡았으면 본문이 아니라 머리에 상태 배너를 단다.
