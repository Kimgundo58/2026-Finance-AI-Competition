# 10. 측정 결과

이 문서가 답하는 질문:
- 질문 재료가 되는 조문에 요건이 얼마나 들어가는가
- 검색 구성별로 결정 근거가 얼마나 후보에 들어가는가
- 질문 품질과 지연은 어떠한가
- 답변 반영이 틀린 「가능」을 늘리는가

따로 적지 않은 값은 2026-11-04 로컬 DB 기준이고 정답 라벨은 사람이 검수하지 않았다. 판정은 온도 0 에서도 실행마다 달라진다.

## 결정 근거 포함률

골든셋 v2 dev 중 L3 가 아닌 481문항, 결정 근거 조문 692개(AI 라벨).

| | 조문 기준 | 문항의 결정 근거 전부 |
|---|---|---|
| `조문_후보()` (상한 40,000자) | 607 / 692 (87.7%) | 405 / 481 (84.2%) |
| 판정 프롬프트의 검색(비목 없음) | 398 / 692 (57.5%) | 234 / 481 (48.6%) |

후보 자수 중앙값 13,607자, 최댓값 39,998자. 상한이 30,000자였을 때는 창업중심대학의 사업비 집행 유의사항(11,390자)이 빠져 590 / 692(85.3%)였다.

후보에서 많이 빠지는 조문은 예비 제23조, 운영요령 제21조·제3조, 모두의 창업 제31조·제27조·제4조, 창업도약 제45조다. 조제목과 룰 근거로 찾히지 않는 조문이다. 온톨로지로 바꿀 때 다시 잰다.

## 검색 구성별 결정 근거 포함률 (2026-11-05)

로컬 DB, LLM 없음. 골든셋 v2 dev 중 L3 가 아닌 501문항(위 481문항에 비목 없는 20문항 포함), 결정 근거 조문 723개. 질의는 `대화.첫질문`(규정을 보고 LLM 이 쓴 문장), 사업 필터 켬, 검색은 상위 5개 + 참조 확장. 룰 근거 + 공통 조문은 `_룰_근거()` + `_공통_조문()` 이고 정답셋 비목을 그대로 넣었다.

| 후보 구성 | 조문 기준 | 문항의 결정 근거 전부 |
|---|---|---|
| dense | 395 (54.6%) | 230 (45.9%) |
| BM25 | 341 (47.2%) | 197 (39.3%) |
| RRF (지금 판정) | 402 (55.6%) | 237 (47.3%) |
| 룰 근거 + 공통 조문 (검색 없음) | 565 (78.1%) | 370 (73.9%) |
| 룰 근거 + 공통 조문 + dense | 609 (84.2%) | 407 (81.2%) |
| 룰 근거 + 공통 조문 + BM25 | 612 (84.6%) | 410 (81.8%) |
| 룰 근거 + 공통 조문 + RRF | 611 (84.5%) | 408 (81.4%) |

- 사업별 룰 근거 + 공통 조문: 모두의 창업 61 / 110(55.5%), 나머지 6개 사업 77.4~91.8%. 모두의 창업 룰은 사업비 집행기준인 별지1·별지2를 근거로 가리키지 않는다.
- 창업중심대학은 RRF 14 / 96, 룰 근거 + 공통 조문 80 / 96 이다. 참고3·참고5 청크가 전부 `참조확장전용` 이라 검색 대상이 아니다. `FILTER` 를 통과하는 청크는 20,648개 중 1,270개다. 범위를 넓힌 검색은 아래 절에 있다.
- 이 표는 후보 포함률이다. 판정·인용 정확도는 재지 않았고, 비목이 틀렸을 때의 포함률도 재지 않았다.

## 검색 범위·후보 수별 포함률 (운영 DB, 2026-11-06)

운영 DB 읽기 전용, LLM 없음, 별도 에이전트와 값 일치. 위와 같은 501문항·723개, 사업 필터 켬, RRF 기본 가중, 참조 확장 포함, 조문 기준. 문항의 결정 근거 전부는 첫 행 k=5 249/501, k=50 391/501, 상한 428/501이다. 후보 자수 중앙값은 첫 행 k=5 5~6천자, k=50 5~6만자다. 질의는 정답셋 문장이고 화면의 합성 문장이 아니다. 판정 정확도는 재지 않았다.

## 질문 생성 (측정입력 19건, `qwen3.7-plus`)

| 값 | |
|---|---|
| LLM 지연 | 중앙값 5,063ms, 최댓값 13,097ms(후보 39,942자인 입력) |
| 검색 지연 | 약 400~800ms (모델을 올린 뒤) |
| 질문 | 통과 34, 버림 2 (사유: 부정질문), 호출 실패 0 |
| 질문 0개 입력 | 0건 |

- 모델: `qwen3.8-flash` 도 재 봤다(1차 측정). 지연은 비슷하고 말투가 더 나빠 판정과 같은 `qwen3.7-plus` 로 정했다.
- 조건 확인: KTX·제주 출장에 항공 등급을 묻지 않고, 해외 항공권에는 이코노미 여부를 묻는다. 귀금속은 사전승인을 묻는다.

사람이 보지 않은 약한 질문이 남아 있다. 창업활동비의 「법인사업자인가요?」, 3D 프린터에 PC 기준을 근거로 든 경우가 그렇다. 표본 검토는 [[11_해야할일_정비]].

## 어울리지 않는 질문 (2026-11-05 수정 전후)

외주용역비 조문은 품목과 상관없이 프롬프트에 들어가므로 홈페이지 외주에도 금형을 물었다. 프롬프트 끝에 「마지막 점검」을 두었다. 입력별 3회, `qwen3.7-plus`.

| | 수정 전 | 수정 후 |
|---|---|---|
| 물건을 만들지 않는 외주 8종: 금형·양산 질문이 나온 회차 | 24 / 24 | 2 / 24 |
| 물건을 만드는 외주 3종: 금형·양산·시제품 질문이 나온 회차 | 8 / 9 | 8 / 9 |
| 다른 비목 3종: 금형·양산 질문이 나온 회차 | 0 / 9 | 0 / 9 |
| 부정질문으로 버린 질문 | 1 | 7 |
| 질문 0개 회차 · 호출 실패 | 0 · 0 | 0 · 0 |

- 외주 8종(경계 입력 2종 포함)을 입력별 2회, 답변 없음과 모두 충족답으로 판정했더니 32회 중 「가능」은 0건이다.
- 규칙 2에만 적었을 때는 15회 중 12회가 10회로 줄었을 뿐이다. 프롬프트 끝에 둔 뒤 크게 줄었다. 끝에 두어서 줄었는지 따로 떼어 재지는 않았다.
- 입력 19건 점검: 질문 통과 31, 버림 2, 질문 0개 입력 0, 호출 실패 0, LLM 지연 중앙값 4,933ms, 최댓값 7,417ms.
- 남은 문제: 부정형으로 쓴 질문은 다시 만들지 않고 버리므로 필요한 질문이 사라질 수 있다(사출 외주 3회 중 1회). 표본이 작아 수치는 경향만 본다.

## 답변 반영 전후 비교

정답이 「가능」이 아닌 문항만 썼다. `scripts/question_check.py --judge-compare`. 충족답은 모든 질문에 요건을 충족하는 답을 한 경우, 모름은 모든 질문에 「모르겠어요」로 답한 경우다.

| | 없음 | 충족답 | 모름 |
|---|---|---|---|
| 1차 30문항×2회: 틀린 「가능」 | 1 / 60 | 2 / 60 | 재지 않음 |
| 2차 62문항×1회: 틀린 「가능」 | 0 / 62 | 0 / 62 | 0 / 62 |
| 합계: 틀린 「가능」 | 1 / 122 | 2 / 122 | 0 / 62 |
| 합계: 정답과 일치 | 99 / 122 | 98 / 122 | 47 / 62 |
| 2차: 정답과 일치 | 51 / 62 | 50 / 62 | 47 / 62 |
| 2차: 판단불가 | 7 | 6 | 9 |

- 틀린 「가능」 3건은 모두 같은 문항(TIPS 광고선전비, 정답 판단불가)이다. 답변 없이도 나왔다. 사전에 정한 「늘어나면 끈다」 기준을 숫자만 보면 1차가 건드리지만(1→2), 표본 122회에서 같은 문항 1건 차이이고 2차(62문항)에서는 0이어서 답변 반영을 켠 채 배포했다.
- 2차의 질문 0개 문항은 11건(`없음` 7, `바로판정` 4)이고 질문 생성 실패는 0건이다.
- 모름은 없음보다 4문항 덜 맞다. 없음→모름으로 9문항이 바뀌었다: 불가→판단불가 4, 조건부→불가 3, 판단불가→불가 2. 「모르겠어요」가 판단불가를 없애지는 못한다.
- 정답은 불가 45, 조건부 13, 판단불가 4로 치우쳐 있다. 표본이 작아 이 수치로 답변의 효과를 말할 수는 없고, 틀린 「가능」이 뚜렷이 늘지 않았다는 것까지만 말한다.
