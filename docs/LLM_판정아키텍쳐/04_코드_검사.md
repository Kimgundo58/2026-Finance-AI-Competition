# 04. 질문 검사 (코드)

이 문서가 답하는 질문:
- LLM 이 만든 질문을 무엇으로 검사하는가
- 검사가 잡지 못하는 것은 무엇인가

통과하지 못한 질문은 사용자에게 보이지 않는다. 오류도 표시하지 않고, 남은 질문만 나간다. 사유 코드는 로그에만 남긴다.

코드: `scripts/question_generate.py` · `질문_검증()`

| 사유 | 조건 | 막는 것 |
|---|---|---|
| 근거없음 | 고른 번호의 원문을 DB 에서 못 읽음 | 근거 없는 질문 |
| 물음표 | 물음표로 끝나지 않거나 둘 이상 | 복합 질문, 평서문 |
| 빈칸 | 이유·할일이 비었음 | 화면 구멍 |
| 충족답 | 「예」·「아니오」가 아님 | 답의 방향을 알 수 없는 질문 |
| 길이 | 질문 70자, 이유 120자, 할일 40자 초과, 줄바꿈 | 읽기 어려운 문장 |
| 내부값 | `S01`, `제N조`, 링크, HTML 태그 | 내부 값 노출 |
| 새숫자 | 숫자가 근거 문장·품목·용도·금액에 없음 | 지어낸 한도 |
| 한글금액 | 「천만원」류가 근거 문장에 없음 | 지어낸 한도 |
| 결론어 | 「문제없」·「괜찮」·「해도 됩니다」, 「이 지출은 …가능」, 질문문·할일의 가능·불가·허용·적합 | 판정 전에 결론을 말함 |
| 근거없는말 | 질문문·이유의 허용·적합·승인·금지·인정이 근거 문장에 없음 | 없는 절차나 기준을 만듦 |
| 부정질문 | 「~아닌가요?」, 「~않나요?」, 「~없나요?」로 끝남 | 「예」의 뜻이 뒤집힘 |
| 근거불일치 | 이유의 글자 묶음(2-gram)이 근거 문장과 겹치는 비율이 임계 미만 | 근거와 무관한 질문 |
| 중복 | 같은 질문문 | 같은 질문 반복 |

금액은 단위까지 값으로 바꿔 비교한다(`숫자집합`). `2천만원`, `2천 만원`, `20,000,000` 은 같은 값이다.

이유 칸의 가능·불가는 근거 문장에 없어도 된다. 「법인 명의일 때만 구매가 가능해요」는 규정을 옮긴 말이고 이 지출의 결론이 아니기 때문이다. 할일 칸의 승인·인정도 검사하지 않는다. 「사전 승인 여부 확인」처럼 확인할 일을 적는 말이기 때문이다.

긴 조문은 `근거_발췌()` 로 이유와 가장 많이 겹치는 줄만 잘라 검사한다. 비목 해설표 전체를 근거 문장으로 삼으면 표의 다른 칸 숫자로 통과할 수 있어서다. 「규정 원문 보기」도 같은 발췌를 보여 준다.

## 임계값

`최소_겹침` 은 측정입력 19건의 결과로 정했다. 값이 바뀌면 [[10_측정_결과]] 를 다시 잰다. 품목·용도에서 온 단어는 분모에서 뺀다. 「맥북」처럼 규정에 없는 말이 들어갔다고 탈락시키지 않기 위해서다.

## 잡지 못하는 것

- **`충족답` 을 잘못 적은 경우.** 「대표자의 배우자인가요?」에 충족답을 「예」로 적으면 사용자가 「아니오」라고 답했을 때 코드가 「가능」을 낮춘다. 반대로 틀리면 낮추지 못한다. 판정 LLM 이 충족답 없이 질문과 답을 직접 읽어 이 경우를 막는다.
- **뜻이 뒤집힌 문장.** 부정 끝맺음이 아닌 이중 부정은 통과할 수 있다. 사람 표본 검토로 확인한다.
- **쓸모없는 질문.** 지출과 무관한 요건을 물어도 근거 문장과 맞으면 통과한다.
- **다른 조건을 빠뜨린 질문.** 근거 문장의 조건 일부만 옮겨도 통과한다.

답변이 판정에 들어가므로 이 한계가 판정에 닿을 수 있다. 그래서 다음을 함께 둔다.

- 코드는 답으로 판정을 올리지 않는다. 낮추기만 한다([[06_판정_반영]]).
- 판정 LLM 은 규정 원문을 직접 읽고, 답변은 사용자 진술로만 받는다.
- 충족답으로 모두 답한 전후 비교를 한다. 생성 질문 표본은 사용자가 원문과 대조한다.

## 자체 점검

`python scripts/question_check.py --self-test` (DB·LLM 없음, CI 에서 실행). 사유별 통과·탈락 고정 입력, `숫자집합`, `답변_구성`, `질문_공개` 를 본다.
