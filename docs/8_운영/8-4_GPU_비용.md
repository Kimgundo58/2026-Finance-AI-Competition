# GPU 비용

이 문서가 답하는 질문:
- GPU·DC 별 단가는 얼마인가
- 한 번 돌리는 데 실제로 얼마가 드는가
- 볼륨 요금은 언제까지 붙는가

## GPU·DC 단가 (secure, 2026-08-30 실측 — 재고·가격은 변한다)

| GPU | VRAM | 볼륨 되는 DC | $/h |
|---|---:|---|---:|
| L40S | 48 | EU-NL-1, US-TX-3 | 0.99 |
| A100 SXM | 80 | EUR-IS-1, US-KS-2 등 | 1.59 |

표로 박지 않는 이유가 이거다.

## 실제 1회 비용

| 항목 | 단가 | 실제 |
|---|---|---|
| A100 SXM(secure) | $1.59/h | 정답셋 1회 2~3시간이면 **$4 내외** |
| 볼륨 STANDARD | $0.07/GB·월 | 100GB = 월 $7, **존재하는 동안 계속**(팟을 꺼도) |
| HIGH_PERFORMANCE | DC별 상이, 공개가 없음 | 처리량 3배·IOPS 4배. 지금은 불필요 |

볼륨은 실험이 길어지면 GPU 요금을 넘어선다 — 다 쓴 볼륨은 지운다.

## run 191 실측 (2026-09-02, A40 48GB)

- A40 **$0.44/h**
- 93문항 실전 e2e **1.4~1.6시간 ≈ $0.6~0.7**
- 볼륨 없이 열면 가중치 20GB 재다운로드에 **10~20분** 붙는다(볼륨 상주 시 이 시간이 0)
