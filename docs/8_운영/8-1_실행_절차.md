# 실행 절차

이 문서가 답하는 질문:
- 로컬에서 무엇을 어떤 순서로 켜고 돌리는가
- 판정을 한 줄로 돌리려면 무엇을 치는가
- 룰 검수·개정 대응 도구는 무엇으로 여는가

## 1. DB

```powershell
cd db
docker compose up -d      # 켜기 (Docker Desktop 버튼으로도 가능)
docker compose stop       # 끄기 (데이터 유지)
docker compose down -v    # 전부 초기화 — init/*.sql 을 고쳤으면 반드시 이걸 먼저
```

http://localhost:8081 (pgweb, 로그인 없음) — 왼쪽 `v_적재현황` 이 첫 확인 지점.

## 2. 판정 한 줄

```powershell
python scripts/judge_cli.py --help
```

(1)~(7) 오케스트레이션(`scripts/orchestrate.py`)이 실제 LLM 까지 돈다. 입구는 `judge_cli.py`.

## 3. 룰 검수

```powershell
python scripts/review_rules.py
```

행별 추출값 vs 원문 대조. 절차는 [[5-3_검수_절차]].

## 4. 개정 대응(A4) — 비동기, 배치

```
조 매칭(제목주·번호보조) → 본문 diff → 근거 JSONB 로 영향 rules 조회
→ 해당 룰 verified=false 전환 → 변경 요약(LLM)
```

트리거: 주 1회 배치 또는 수동. 비목 어휘집 재검수도 같이 트리거된다.

## 5. 자주 쓰는 진입점

| 하고 싶은 것 | 스크립트 |
|---|---|
| 판정 CLI | `scripts/judge_cli.py` |
| 검색 스모크(5문항) | `scripts/smoke_search.py` |
| 검색 채점(15문항) | `scripts/eval_retrieval.py` |
| 골든셋 채점 | `scripts/score_judgment.py` |
| DB 감사 | `scripts/audit_db.py` |
| GPU 선택 | `scripts/pick_gpu.py` |
| RunPod 팟 관리 | `scripts/runpod_pod.py` |

## 6. 환경

```powershell
export PYTHONIOENCODING=utf-8   # Bash 에서 한글 깨짐 방지 — 훅이 python 호출에 강제
```
