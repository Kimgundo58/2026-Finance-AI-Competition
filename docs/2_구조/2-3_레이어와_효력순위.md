# 레이어와 효력순위

이 문서가 답하는 질문:
- L1/L2/L3는 각각 누가 발행하고 무엇을 담는가
- 두 규정이 충돌하면 무엇이 이기는가
- 검색에서 주관기관용 조항과 창업기업용 조항을 어떻게 가르는가

## 규정 축 (L1/L2/L3)

통합관리지침 제2장(추진체계)의 위임 계통을 따른다.

| 계층 | 주체 | 무엇 | 조달 |
|---|---|---|---|
| **L1** | 중기부 (총괄기관) | 법률 · 고시 · 훈령 · **통합관리지침** | 우리 — 법령 OPEN API + 배포본 |
| **L2** | 창진원 (전문기관) | 사업별 **세부관리기준** · 공고 · 별표 | 우리 — 창진원 배포본 |
| **L3** | 주관기관 | 기관 회계·집행 규정, 협약 특약 | **사용자 업로드** (비공개라 조달 불가) |

레이어는 파일명이 아니라 **발행주체 메타데이터**로 부여한다. `법령 PDF/`의 `L1_`~`L4_`
접두사는 구 체계 잔재 — 무시할 것.

구 표기 대응: 구 L1+L2 → 현 **L1** / 구 L3 → 현 **L2** / 구 L4+L5 → 현 **L3**.

적재 실측·검색 후보 풀 수치는 [[4-5_적재_지표]] 참조.

## L1 내부 위계 (충돌 시 위가 이긴다)

```
① 법률 (보조금법·공공재정환수법·중소기업창업 지원법)
② 고시 (창업지원사업 운영요령)
③ 훈령 (중기부 보조사업 관리규정)
④ 지침 (중소기업창업 지원사업 통합관리지침)      ← 여기까지 L1
⑤ 세부관리기준 · ⑥ 공고문                        ← L2
⑦ 기관 규정 · 협약 특약                          ← L3 (사용자 input)
```

## 🔴 L2/L3 충돌 — "아래가 엄격하면 이긴다"가 아니다

세부관리기준이 자기 우선순위를 스스로 규정한다.

| 사업 | L2 > L3 | L1 > L2 (미규정만 L2) |
|---|:-:|:-:|
| 예비 · 초기 · 재도전 · 도약 · 창업중심대학 | O | |
| 모두의창업 | O | O |
| 초격차 | | O |
| TIPS | | (해당 조항 없음 — 운영사 체계) |

8개 사업 중 6개가 "주관기관 내부규정과 상충되는 경우 본 관리기준을 우선한다"고 명시한다
— **사용자가 올린 규정(L3)이 더 엄격해도 진다.** 기계 판독 원본은 `_precedence_rules.json`.

구현 규칙: **우선순위 조항(대개 제3조 부근)을 먼저 파싱해 룰로 등록**하고 그다음 충돌을 푼다.
컴파일·검수 절차는 `docs/5_룰/` (범위 밖).

## 적용대상 축 — 주관기관 조항 vs 창업기업 조항

세부관리기준에는 주관기관용 조항과 창업기업용 조항이 섞여 있다. 모든 조문에
`적용대상 ∈ {주관기관, 창업기업, 공통}`을 태깅하고 검색에서 항상 필터한다:

```sql
WHERE 적용대상 IN ('창업기업','공통')
```

이 필터가 없으면 "노트북 사도 되나요?"에 주관기관 전담인력 인건비 조항이 검색된다.
값이 어떻게 매겨지는지는 [[3-6_적용대상_태깅]] 참조.
