# 규정 계층과 효력순위

이 문서가 답하는 질문:
- L1/L2/L3는 각각 누가 발행하고 무엇을 담는가
- 두 규정이 충돌하면 무엇이 우선하는가
- 검색에서 주관기관용 조항과 창업기업용 조항을 어떻게 구분하는가

## 규정 계층 (L1/L2/L3)

통합관리지침 제2장(추진체계)의 위임 체계를 따른다.

| 계층 | 주체 | 무엇 | 수집 |
|---|---|---|---|
| **L1** | 중기부 (총괄기관) | 법률 · 고시 · 훈령 · **통합관리지침** | 직접 수집 — 법령 OPEN API + 배포본 |
| **L2** | 창진원 (전문기관) | 사업별 **세부관리기준** · 공고 · 별표 | 직접 수집 — 창진원 배포본 |
| **L3** | 주관기관 | 기관 회계·집행 규정, 협약 특약 | **사용자 업로드** (비공개라 수집 불가) |

계층은 파일명이 아니라 **발행주체 메타데이터**로 부여한다. `법령 PDF/`의 `L1_`~`L4_`
접두사는 구 체계 잔재 — 무시할 것.

구 표기 대응: 구 L1+L2 → 현 **L1** / 구 L3 → 현 **L2** / 구 L4+L5 → 현 **L3**.

적재 실측·검색 후보 풀 수치는 [[0_현황]] 참조.

## L1 내부 위계 (충돌 시 위가 우선한다)

```
① 법률 (보조금법·공공재정환수법·중소기업창업 지원법)
② 고시 (창업지원사업 운영요령)
③ 훈령 (중기부 보조사업 관리규정)
④ 지침 (중소기업창업 지원사업 통합관리지침)      ← 여기까지 L1
⑤ 세부관리기준 · ⑥ 공고문                        ← L2
⑦ 기관 자체규정 · 협약 특약                      ← L3 (사용자 업로드)
```

## L2/L3 충돌 — "아래가 엄격하면 우선한다"가 아니다

세부관리기준이 자기 우선순위를 스스로 규정한다.

| 사업 | L2 > L3 | L1 > L2 (미규정만 L2) |
|---|:-:|:-:|
| 예비 · 초기 · 재도전 · 도약 · 창업중심대학 | O | |
| 모두의창업 | O | O |
| 초격차 | | O |
| TIPS | | O |

(2026-09-05 확인 — TIPS 는 L1>L2 1행이 `precedence_rules` 에 있다. `corpus.precedence_rules` **9행**.
L2>L3 는 여전히 TIPS 에 없다 — "8개 사업 중 6개"는 행 수가 아니라 **사업 수**라 안 바뀐다.)

8개 사업 중 6개가 "주관기관 내부규정과 상충되는 경우 본 관리기준을 우선한다"고 명시한다
— **사용자가 올린 규정(L3)이 더 엄격해도 우선하지 않는다.** 기계 판독 원본은 `_precedence_rules.json`.

데이터: `2026_Finance_DATA_FOR_RAG/_precedence_rules.json`
```json
   "사업명": "예비창업패키지",
   "우선계층": "L2",
   "후순위계층": "L3",
   "범위": "all",
   ...
   "원문": "내부규정과 상충되는 경우 본 관리기준을 우선한다",
   "해석": "주관기관 규정이 더 엄격해도 세부관리기준이 우선 적용된다",
```

코드: `scripts/rule_lookup.py` · `_L2우선L3()` · `_l3_반영()`
```python
def _L2우선L3(우선순위: Sequence[dict]) -> bool:
    """사업 세부관리기준이 기관 자체규정보다 우선한다고 범위 'all' 로 정했는가."""
    return any(p["우선계층"] == "L2" and p["후순위계층"] == "L3" and p["범위"] == "all"
               for p in 우선순위)
...
    if _L2우선L3(우선순위):
        return eff, {"모드": "L2우선", "L3더엄격": _L3더엄격(l3, eff), "L3반영": False}
    합 = _L3_병합(eff, l3)
```
L2 > L3 조항이 없는 초격차만 `_L3_병합()` 으로 엄격한 쪽을 합친다. TIPS 는 비목체계가 RND 라 L3 룰을 붙이지 않는다(`_l3_선택()`).

구현 규칙: **우선순위 조항(대개 제3조 부근)을 먼저 파싱해 룰로 등록**하고 그다음 충돌을 푼다.
컴파일·검수 절차는 `docs/5_룰/` (범위 밖).

## 적용대상 구분 — 주관기관 조항 vs 창업기업 조항

세부관리기준에는 주관기관용 조항과 창업기업용 조항이 섞여 있다. 모든 조문에
`적용대상 ∈ {주관기관, 창업기업, 공통}`을 태깅하고 검색에서 항상 필터한다:

코드: `scripts/retrieve.py` · `FILTER`
```python
FILTER = """embedding IS NOT NULL AND status='active' AND parse_quality='high'
        AND retrieval_scope='검색대상' AND layer IN ('L1','L2')
        AND 적용대상 IN ('창업기업','공통')"""
```

이 필터가 없으면 "노트북 사도 되나요?"에 주관기관 전담인력 인건비 조항이 검색된다.
값이 어떻게 매겨지는지는 [[3-6_적용대상_태깅]] 참조.
