# 백로그: 보류한 버그

[9_백로그.md](9_백로그.md) 에서 나눈 문서다. 운영 경로에서 지금은 도달하지 않거나 영향이 작은 버그를 적는다.

| 영역 | 내용 |
|---|---|
| 계획 연결 | 판정 요청의 `plan_id` 는 소유 확인 없이 `decisions.plan_id` 로 들어간다. 다른 계정의 계획을 넘기면 계획에 연결되지 않고(`저장: false`) 판정 행만 그 계획을 가리킨다. 응답 문구로 다른 기관 계획 id 의 존재 여부를 알 수 있다. 내용은 노출되지 않는다 |
| 이전 임시저장 계획 | 2026-11-04 이전에 임시저장한 계획은 `정규화` 가 비어 판정 때 용도 없이 금지목록을 본다. 운영 백업 복사본(11-04 04:30) 기관 cfeba091 의 5건(23555~23558, 23570)은 용도를 넣어도 걸리는 금지 항목이 없었다 |
| 대체 판정 | 계획 상세를 읽지 못하면 프론트가 들고 있던 값으로 판정하고 저장한다(`lib/judge.ts:84`). 목록의 21번째 이후 계획은 상세를 읽지 않아(`lib/plan-service.ts:103`) 용도가 비어 있어 용도 없이 판정되고, 재점검의 확인 질문도 용도 없이 만들어지며, 「확인한 내용」도 보이지 않는다. 이 경우 틀린 '가능'이 나오는지는 측정하지 않았다 |
| 비목 안내 | 저장되지 않은 판정 뒤나 클라이언트가 먼저 포기한 판정 뒤에 비목을 고치면, 점검에 쓰이는지 알리는 문구가 실제와 달라진다. 코드로만 추적했고 실행하지 않았다 |
| 비목 표기 | `/api/vocab` 응답 전에 수정 창을 열면 코드의 이름(기계장치비)을 보낸다. 로컬 점검에서 판정은 정상 완료됐다 |
| L3 룰 | `l3_load.l3룰` 이 단락 단위로 분할된 기관 규정에서 금지예시 없이 `불가` 를 만든다(로컬 기관 cfeba091: 재료비·외주용역비·인건비·여비·교육훈련비·광고선전비 6개 비목). L2 > L3 우선 조항이 없는 사업(초격차)에 그 기관이 판정하면 해당 비목이 전부 `불가` 가 된다. 지금 그 기관의 사업은 모두의 창업이라 반영되지 않는다 |
| L3 업로드 | 파싱에 실패한 파일과 정리된 데모 기관의 파일이 디스크에서 지워지지 않는다 |
| L3 참조 | 인용된 상위 규정 이름을 부분 일치로 찾아 다른 문서(시행령·시행규칙 등)로 연결한다 |
| 참조 생성 | `build_refs` 는 같은 이름이면 active 를 먼저 쓰지만 옛 판뿐인 이름은 폐지 문서로 매핑한다. 쉼표로 이어진 지침 조 보정(2026-11-06)은 DB 에 모두의 창업만 넣었다. 창업도약 · 창업중심대학 · 초격차의 같은 표기 13행은 다음 적재 때 생긴다(미확인: 옛 판 조번호 여부). 모두의 창업 제15조 "지침 19조"("제" 없음) · 제8 · 2 · 5조의 창업지원법 조 표기는 행이 없다(`ontology/수집/P0-2_P0-4_P0-5_기록.md`). 별지 참조를 `별지N` 으로 쓰는데(`build_refs.py:38,302-304`) 법령 XML 의 조번호는 `서식N` 이라, 별지 참조 5,839건 중 5,028건은 대상 조가 없어 참조 확장에서 빠진다(그중 4,934건은 같은 번호 서식이 있다. 로컬·운영 같음, 2026-11-05). |
| 참조 확장 | 폐지(superseded) 문서를 가리키는 참조는 경고 없이 빠진다. 미해결 참조(`DANGLING_WARN`)로 표시하면 스냅샷 46건(골든셋 37 · L3 9)의 결과가 바뀌어 기준선 재측정이 필요하다. 안내 책자(L2, FILTER 통과 30청크)가 v2_dev 모두의 창업 84문항의 상위 5 청크 420개 중 334개를 차지해 참조 보정이 끌어올 시작 조가 안 들어온다(결정 근거 포함 28 → 책자 끄면 66 / 125, 로컬 첫질문 · 화면 합성 질의와 운영은 미확인, 2026-11-07, `ontology/수집/P0-2_P0-4_P0-5_기록.md`) |
| 할 일 동기화 | 같은 코드 항목이 두 번 오면 한 건이 사라진다. 결제 전 할 일에도 결제 후 기한이 붙는다 |
| 기한 계산 | L3 기한 계산이 적용 문서의 사업비 외 장까지 읽는다 |
| 판정 요청 | `정규화` 필드 크기 제한이 없어 큰 입력이 프롬프트로 들어갈 수 있다 |
| 검증 | 항·호 범위 표기('④~⑤')와 단일 표기를 비교해 `CITE_PARAGRAPH_MISMATCH` 가 정상 데이터에도 붙는다. 과업범위요약 프로필 경로가 검증은 통과하지만 전제 확인에서 해결되지 않는다. |
| 프롬프트 | B3 행 조회에 ORDER BY가 없어 실행 계획에 따라 문장 ID 순서가 바뀔 수 있다 (적용 시 기준선 재측정) |
| 룰 계산 | 개수·비율 한도 계산의 분모 처리 오류 (현재는 금액만 넘겨서 도달하지 않음) |
| BM25 | 전체 재색인 경로가 삭제된 중간 파일을 요구해 실행되지 않는다. `--증분` 만 동작한다 |
