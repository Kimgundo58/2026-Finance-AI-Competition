# 참조 확장

이 문서가 답하는 질문:
- 검색이 찾은 조항 하나가 어떻게 관련 조항 전체로 확장되는가
- 왜 깊이는 1이면 충분한가
- 참조가 끊겨 있으면 어떻게 처리하는가

> RAG가 존재하는 이유 자체가 이 참조 추적이다 — 배경은 [[1-1_서비스와_문제]].
> 과거 실측(전/후 비교)은 [[4-4_검색_지표]] 참조. 여기는 **현재 규칙**만.

## 재귀 CTE — 깊이 1

```sql
WITH RECURSIVE 참조확장 AS (
    SELECT dst_doc_id, dst_조번호, 1 AS depth, ref_id
      FROM corpus.refs
     WHERE (src_doc_id, src_조번호) IN :진입점집합
       AND 해소상태 <> 'dangling'
    UNION ALL
    SELECT r.dst_doc_id, r.dst_조번호, p.depth + 1, r.ref_id
      FROM corpus.refs r JOIN 참조확장 p
        ON (r.src_doc_id, r.src_조번호) = (p.dst_doc_id, p.dst_조번호)
     WHERE p.depth < 3
)
SELECT DISTINCT * FROM 참조확장;
```

그래프 DB를 쓰지 않는다 — 규정 모음이 이 규모에서는 재귀 CTE로 밀리초다.

**깊이는 1이면 충분하다.** 깊이 1·2·3의 hit@5+참조확장이 동일하다 — 2단계 이상은
커버리지에 기여 없이 토큰만 늘린다. 규정 모음이 바뀌면 재측정.

🔴 **조 지정 없는 참조는 확장하지 않는다** (`dst_조번호 IS NOT NULL`). 「소득세법」처럼
조 없이 법률명만 인용한 것을 문서 전체로 해석하면 법 하나가 수천 청크를 끌고 온다.
인용은 S번호 추출이므로 조가 특정돼야 근거로 쓸 수 있다.

## 해소 상태 3종

| 상태 | 뜻 |
|---|---|
| `resolved` | 대상이 규정 모음에 있고 조번호도 맞다 |
| `shifted` | 조번호가 구판이라 **조제목으로 재매칭**했다 — 원래 표기와 보정 근거를 함께 남긴다 |
| `dangling` | 대상이 규정 모음에 없다 또는 조를 지목하지 않는다 |

`관계='미규정위임'`("정하지 아니한 사항은 상위 규범에 따른다")은 어느 조인지
지목하지 않으므로 `resolved`가 아니라 `dangling`이다 — 결손이 아니라 법령의
정상 문형이므로 업로드 안내에서 이 라벨로 걸러 안내한다.

`shifted`는 보정된 dst를 쓰되 원래 표기도 함께 전달 — 화면 7이 "귀 기관 규정은
제33조라 하지만 현행 기준 제39조입니다"를 그린다.

## 끊긴 참조 처리 방침

- 판정 인덱스 **안의** 끊긴 참조(`dangling`)만 신호로 취급(밖은 정상 — 참조 확장
  도착지가 규정 모음 밖 법령인 경우가 많다)
- 끊긴 참조는 제외하되 그 사실을 판정에 싣는다 → 근거 불완전 → 판단불가 쪽으로 기운다
- **판정 시점이 아니라 업로드 시점에** 사용자에게 알린다

## `retrieval_scope`와 참조 확장의 관계

`폐포전용` 청크의 안전 근거는 "검색에 안 걸려도 참조로 도달한다"인데, 이게 성립하려면
`refs.dst_doc_id`가 `documents.doc_id`로 **정규화**돼 있어야 한다(파일 경로·약칭·
정상 doc_id가 섞여 있으면 폐포전용 청크가 검색으로도 참조로도 도달 불가). 약칭은
**문서가 스스로 정의한 것**(제1·2조 "이하 '법'이라 한다")을 걷어 해소한다 —
전역 별칭 사전 하드코딩은 기각(문서마다 「법」이 다르다).

## 사례 — 폐포전용인데 참조로도 안 닿는 경우 (2026-09-05, ai-35 실측 · 이 세션 재현 안 함)

위 문단이 말한 실패 조건이 실제로 발생했다. 09-05 재적재분 53청크(8개 조, 창업중심대학
참고3 등)가 전부 `retrieval_scope='폐포전용'`인데, 참조로 도달 가능한 경로는 3개
조뿐(창업중심대학 참고3·TIPS 붙임3·붙임5)이고 나머지 5개 조는 **인입참조가 자기참조뿐이거나
0건이라 도달 불가**하다고 보고됐다. 사실이면 채점 분모 295 중 5문항이 구조적으로 hit
불가 — [[9_미결]] #14(주관기관 16문항)와 같은 갈래의 세 번째 사례. 재현 방법이 문서화돼
있지 않아 이 세션에서는 대조만 하고 재계산하지 않았다.
