# 검색 지표 — 실측 이력

이 문서가 답하는 질문:
- 검색 품질 관련 결정(scope 태깅·RRF 가중·참조확장 깊이)은 무슨 실측으로 정해졌는가
- 지금 검색 hit@k는 얼마인가
- 어떤 튜닝이 이미 시도됐고 왜 더 손대지 않는가

⚠️ **run끼리 직접 빼지 말 것.** 사업필터·정답출처·분모·규정 모음 버전이 다르면 숫자는
비교 불가(`eval.runs.설정` 참조). 아래 표는 실측 시점을 함께 적는다.
