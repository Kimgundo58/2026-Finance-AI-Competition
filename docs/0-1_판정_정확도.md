## 🔴 게이트 A(금지적중)는 상한 4.4% — 룰만으로 「불가」를 낼 수 있다는 착시를 깨라

정답셋 「불가」182건 중 `rule_lookup.금지적중()` 이 실제로 잡는 건 **8건(4.4%)** 뿐이고,
이것도 **상한**이다. 매칭은 「금지예시 ⊂ 품목」이라 품목 문자열이 길수록 잡히기 쉬운데,
이 8건은 **질문 문장 전체**를 품목으로 넣은 값이다. 실경로처럼 정규화된(짧은) 품목을
쓰면 잡히는 건 더 준다 — 앞 18자로 자르면 **1건**까지 떨어진다(θ_불가출처_분해, 2026-09-06).
나머지 **159건(87.4%)은 LLM 판단에 전적으로 의존**하고, **15건(8.2%)은 룰 자체가 없다.**

🔴 **그래서 다음 run 에서 「불가」 적중이 오르면 그건 룰 append 효과가 아니라 B0 구분선
(정규화 프롬프트가 확신 없으면 판단불가 대신 불가 쪽으로 기울게 만드는 문구) 효과일 수
있다.** 두 원인을 갈라서 읽어라 — 룰 반영과 판정 결과 사이에 게이트 A 4.4% 상한이라는
좁은 파이프가 있다는 걸 잊으면 「룰을 늘렸더니 좋아졌다」는 착각이 난다.
