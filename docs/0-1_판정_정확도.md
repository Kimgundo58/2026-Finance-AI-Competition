# 0-1. 판정 정확도 — run 194 (최신)

판정이 얼마나 맞는지, 어디서 틀리는지를 적는다.
지금 병목은 룰 테이블의 분포와 코드다. GPU 도 배포도 아니다.
실서버 배관은 [[0-2_실서버_배관]] 에 있다. 두 갈래를 섞지 마라.
구판 run 191(93문항) 은 [[0-1b_판정_정확도_run191]] 로 뺐다 — 🔴 **두 run 을 빼지 마라.**

🔴 배관을 고치면 정확도가 오른다고 읽으면 틀린다. 아래 라벨축 실측이 그 반대다.

> 정정으로 시작하는 줄은 그 시점의 기록이다. 문장을 다듬지 않는다.

## 룰 분포 — 판정 품질의 최대 병목

`허용` 실측은 **조건부 73 · 가능 1 · 불가 0** 이다.
내역은 L1 조건부 9 · L2 조건부 64 · L2 가능 1 (ai-a3 실측 2026-09-03).

검수 전 72행과 비교하면 분포가 한 행도 안 바뀌었다. 늘어난 2행도 전부 조건부다.

🔴 룰이 낼 수 있는 판정은 조건부뿐이다. 판정 품질의 최대 병목이 여기 있다.
검수는 행이 맞는지를 봤을 뿐, 이 분포로 판정이 나오는지는 안 봤다.

### 실패 96건 = 타임아웃. **코드 결함이 아니다**

```
실패단계 정규화 (74)   TimeoutError: read operation timed out          71
                       RemoteDisconnected                                2
                       URLError: getaddrinfo failed                      1   ← 06:35 네트워크 전환
실패단계 판정LLM (22)  HTTP 524 (Cloudflare 프록시 타임아웃)            19
                       URLError: getaddrinfo failed                      2   ← 같은 전환
                       RemoteDisconnected                                1
```

**vLLM 은 무죄다** — preemption 0 · 대기열 0 · abort 0. GPU 는 멀쩡히 서빙하고 있었고
**클라이언트와 Cloudflare 프록시가 먼저 포기했다.**

🔴 **여기서 계측의 「층」을 착각했다.** 「동시6 과부하」 가설을 vLLM 계측(preemption 0)을
보고 기각했는데, 「요청을 «떨어뜨리지 않았다»」와 「«제때 끝냈다»」는 다른 말이다.
결과적으로 처음 가설이 효과로는 맞았다.

🔴 **HTTP 524 는 타임아웃 상향으로 못 푼다** — RunPod 프록시(Cloudflare)의 고정 한계다.
동시성을 낮추거나 SSH 터널로 우회해야 한다. **동시성 상향 계획은 폐기했다.**

### 4-way 혼동 (정답 → 예측 · 상위)

```
 57  불가 → 판단불가      ← 실패 96건이 여기 대부분 들어간다
 21  불가 → 조건부
 20  가능 → 조건부
 18  조건부 → 판단불가
 17  가능 → 판단불가
 13  조건부 → 불가
  9  판단불가 → 조건부
  1  조건부 → 가능        ← 유일한 치명
```

### 판단불가는 «근거 도달» 과 거의 동치다

| | 근거✗ (116건) | 근거○ (117건) |
|---|---|---|
| 판단불가 | **74 (64%)** | **1 (1%)** |
| 불가 / 조건부 | 20 / 19 | 57 / 52 |
| 가능 | 1 | 3 |

판단불가 75건 중 **74건이 근거✗** 다. 모델은 근거를 받으면 거의 항상 답한다.
🔴 그래서 **B0 의 「확신 없으면 판단불가」 경고를 빼도 효과가 낮다** — 답할 재료 자체가
없어서 못 답한 것이다. 오히려 근거 없이 답하게 만들어 치명 오답을 늘릴 위험이 있다.

### 강등코드 배선 — 전부 기각

| | 오답에 붙음 | 정답에 붙음 |
|---|---:|---:|
| `PREMISE_UNMAPPED` | 29 | 29 |
| `CITE_HANG_MISMATCH` | 11 | **17** |
| `VLM_DOWNGRADE` | 7 | 6 |

**어느 코드도 오답을 선별하지 못한다.** 판정을 뒤집는 스위치로 쓰면 손해다.
`CITE_HANG_MISMATCH` 는 정답에 더 많이 붙어 **순손실**이다.
