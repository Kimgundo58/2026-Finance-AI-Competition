```sql
CREATE TABLE IF NOT EXISTS corpus.programs (

);
```

## 모두의창업 — 로컬트랙 범위 밖

세부관리기준 구조: 제1편 총칙 / **제2편 일반·기술트랙(다룬다)** / **제3편 로컬트랙(다루지 않는다)**.

- 로컬트랙 상위 규정은 통합관리지침이 아니라 「신사업창업사관학교 운영지침」 —
  위임 체계가 다르다
- `precedence_rules` 조회 키가 `사업명`이라 두 트랙이 같은 키를 쓴다.
  제3편을 남겨두면 일반·기술트랙 판정에 로컬트랙 룰이 함께 조회된다
- 청킹 단계에서 제3편(제53조 이후)을 제외한다 — `scripts/scope.py::범위밖_조()` 가 실행

코드: `scripts/scope.py` · `범위밖_조()`
```python
범위밖_시작: dict[str, re.Pattern[str]] = {
    "모두의 창업 프로젝트": re.compile(r"제\s*3\s*편\s*로컬트랙"),
}
...
    일치 = [i for i, a in enumerate(articles) if pat.search(a.get("본문") or "")]

    return {a["조번호"] for a in articles[경계 + 1:]}
```
