# 서비스와 문제 — 「써도돼요」

이 문서가 답하는 질문:
- 이 서비스는 무엇을 하는가
- 왜 이 문제가 존재하는가
- 판정은 어떤 구조로 이루어지는가

## 정의

> **"이거 사업비로 써도 되나요?"** — 창업지원금을 받은 창업팀이 결제 전에 물으면,
> 판정(가능/조건부/불가/판단불가) · 근거 조항 · 해야 할 일(사전승인·증빙 체크리스트)을
> 답하는 사전 판정 서비스.

- 대회: 금융 AI 공모전(금융보안원) · 6주 MVP
- 창업팀 전용 (센터 관리자 기능 없음). 수익 모델 미결
- 포지셔닝: 판정기가 아니라 **소명 지원 도구**

코드: `scripts/llm_schema.py` · `판정_ENUM` · `미충족시_ENUM`
```python
# 판정 4종. enum 순서가 바뀌면 스키마 문자열이 바뀌어 출력이 달라질 수 있으므로 순서도 고정한다.
판정_ENUM: tuple[str, ...] = ("가능", "조건부", "불가", "판단불가")

# 전제가 깨졌을 때의 결론. 전제는 "이 사실이 아니면 이렇게 된다" 를 말하므로 판단불가는 들어가지 않는다.
미충족시_ENUM: tuple[str, ...] = ("가능", "조건부", "불가")
```

## 판정의 구조 — 규정 요건과 사실관계

```
[ 규정 계층 = 무엇이 요건인가 ]          [ 기업 프로필 = 이 건이 요건을 충족하나 ]
 L1 중기부 · L2 창진원 · L3 주관기관     협약 · 과업범위 · 집행내역 …
                    └──────────┬──────────┘
          요건 충족 판단 + 우선순위 조항 충돌 해결
```

규정 계층은 [[2-3_규정_계층과_효력순위]], 기업 프로필(사실 정보)은 [[2-5_기업_프로필]] 참조.

코드: `scripts/assemble_context.py` · `프롬프트_구성()`
```python
    번호 = _문장ID_생성기()
    블록: list[str] = [시스템_프롬프트]
    if l3:
        블록.append(_기관규정_블록(번호, l3))
    if 검색:
        블록.append(_검색규정_블록(cur, 번호, 검색))
    if 참조확장:
        블록.append(_참조조항_블록(cur, 번호, 참조확장))
    if 룰결과:
        블록.append(_룰요약_블록(룰결과))
    if 프로필요약:
        블록.append(_프로필요약_블록(프로필요약))
```
규정 요건(L3·검색 규정·참조 조항·룰 결과)과 사실관계(프로필 요약)를 한 프롬프트에 넣고 LLM 은 요건 충족 판단만 한다.

RAG는 검색이 아니라 "사용자 문서(L3)가 가리키는 곳을 끝까지 따라가 실제 적용 조항에
도달하는 것"이다 — 상세는 [[4-3_참조_확장]].

## 문제 배경

### 자금 흐름과 이해관계자

```
중소벤처기업부(중기부) ─ 총괄기관: 예산·정책·법령·고시·훈령·통합관리지침
  └─ 창업진흥원(창진원, KISED) ─ 전문기관: 사업별 세부관리기준, 사업 총괄
      └─ 주관기관 (대학 창업지원단, BI, CCEI, TP 등) ─ 창업팀 선정·관리·정산
          └─ 창업기업등 (예비창업자·창업기업·(예비)재창업자) ─ 지원금을 실제로 쓰는 사람
```

- 창업지원사업 전체 규모: 연 3.4조원 / 111개 기관 / 508개 사업
- 창업팀은 **협약**에 따라 지원금을 받고 **비목** 체계 안에서만 집행,
  종료 후 **정산**(증빙 심사)을 통과해야 한다

### 왜 문제가 생기는가

| # | 원인 | 설명 |
|---|---|---|
| 1 | 규정 용어와 질문 표현의 수준 차이 | 규정은 비목 단위 추상어("범용성 기자재는 직접 연관성 소명 및 사전승인 필요"), 창업팀은 지출 건 단위 구체어("맥북 250만원 사도 되나요?") |
| 2 | 반려는 "금지"가 아니라 "절차" | Top3: 회의비(회의록 부실) · 범용성 기자재(사전승인 없이 결제부터 함) · 외주용역비(과업지시서-결과물 불일치) |
| 3 | 리스크가 비대칭 | 부정 사용 시 환수 + 제재부가금 최대 5배 + 참여제한 최대 5년 |
| 4 | 규정이 여러 계층 | 대학 산학협력단 회계를 거치면 학교 회계규정이 추가로 적용된다 |

## 제품 형태 (요약)

창업팀 화면: 묻기 → 비목 확인 → 판정 → 할일 → 근거 → 문의. 상세 흐름은 [[2-2_판정_흐름]].
게스트는 L1·L2만으로 판정(전제 다수). 로그인은 필수가 아니다 —
로그인해 기업 프로필을 저장하면 미확인 전제가 줄어 정확도가 올라간다.

## MVP 범위 밖

"위반입니다" 단정 · 전국 L3 커버(데모 1개 기관) · 정산 서류 자동 제출 · 반려 확률 예측.
