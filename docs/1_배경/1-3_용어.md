# 용어

이 문서가 답하는 질문:
- 이 프로젝트에서만 쓰는 도메인 용어는 무엇인가
- 문서 전반에 나오는 번호·기호(①~⑦, L1~L3, F1~F7 등)는 무엇을 가리키는가

## 도메인 용어

| 용어 | 의미 | 구현 관점 주의 |
|---|---|---|
| 비목(費目) | 사업비 지출 카테고리 (재료비, 외주용역비 등) | 판정의 1차 분류축. 사업마다 체계가 다름 |
| 총괄기관 / 전문기관 / 주관기관 | 중기부 / 창진원 / 대학 창업지원단 등 | 각각 L1·L2·L3 발행 주체 |
| 창업기업등 | 예비창업자·창업기업·(예비)재창업자 총칭 | 지침 제1장 정의 용어 |
| 협약 | 창업기업등-주관기관 간 지원 계약 | 협약기간 밖 집행은 원천 불가 |
| 정산 | 종료 후 집행 내역·증빙 심사 | "정산 리허설" 확장 기능이 이 단계의 역방향 검사 |
| 증빙 | 지출 정당성 서류 (견적서·세금계산서·회의록·사진) | 화면 6 체크리스트의 내용물 |
| 사전승인 | 일부 지출은 결제 전 주관기관 승인 필수 | 반려 2위 원인 |
| 품의 | 지출 전 내부 결재 | L3 계층에서 자주 등장 |
| 산학협력단 | 대학의 회계·연구비 관리 법인 | L3 규정의 발행 주체 |
| 통합관리지침 | L1 최하단 지침, "제N차"로 개정 관리 | 구버전 인용은 사고 |
| 세부관리기준 | 사업별 L2 규정 | 사업별 존재, 상당수 HWP |
| 별표/붙임 | 규정 뒤 부록 | 한도·증빙 실질은 L2 [붙임2]·[참고N] 표에 있다 |
| 조/항/호 | 규정의 계층 (제15조 제2항 제3호) | 청킹·인용(S번호)의 단위 |
| 환수/제재부가금/참여제한 | 부정 사용 제재 3종 | 리스크 고지 문구의 근거 |
