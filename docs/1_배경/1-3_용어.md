# 용어

이 문서가 답하는 질문:
- 이 프로젝트에서만 쓰는 도메인 용어는 무엇인가
- 문서 전반에 나오는 번호·기호(①~⑦, L1~L3, B0~B6 등)는 무엇을 가리키는가

코드·DB 식별자와 이전 이름까지 포함한 전체 사전은 [[용어집]].

## 도메인 용어

| 용어 | 의미 | 구현 관점 주의 |
|---|---|---|
| 비목(費目) | 사업비 지출 카테고리 (재료비, 외주용역비 등) | 판정의 1차 분류 기준. 사업마다 체계가 다름 |
| 총괄기관 / 전문기관 / 주관기관 | 중기부 / 창진원 / 대학 창업지원단 등 | 각각 L1·L2·L3 발행 주체 |
| 창업기업등 | 예비창업자·창업기업·(예비)재창업자 총칭 | 지침 제1장 정의 용어 |
| 협약 | 창업기업등-주관기관 간 지원 계약 | 협약기간 밖 집행은 원천 불가 |
| 정산 | 종료 후 집행 내역·증빙 심사 | "정산 사전 점검" 확장 기능이 이 단계의 역방향 검사 |
| 증빙 | 지출 정당성 서류 (견적서·세금계산서·회의록·사진) | 할일 화면 체크리스트의 내용물 |
| 사전승인 | 일부 지출은 결제 전 주관기관 승인 필수 | 반려 2위 원인 |
| 품의 | 지출 전 내부 결재 | L3 계층에서 자주 등장 |
| 산학협력단 | 대학의 회계·연구비 관리 법인 | L3 규정의 발행 주체 |
| 통합관리지침 | L1 최하단 지침, "제N차"로 개정 관리 | 구버전 인용은 오류 |
| 세부관리기준 | 사업별 L2 규정 | 사업별 존재, 상당수 HWP |
| 별표/붙임 | 규정 뒤 부록 | 한도·증빙 실질은 L2 [붙임2]·[참고N] 표에 있다 |
| 조/항/호 | 규정의 계층 (제15조 제2항 제3호) | 청킹·인용(문장 ID)의 단위 |
| 환수/제재부가금/참여제한 | 부정 사용 제재 3종 | 리스크 고지 문구의 근거 |

## 판정 파이프라인에서 자주 만나는 개념

여러 문서에서 정의 없이 바로 쓰인다 — 처음 보면 여기부터 확인한다.

| 용어 | 의미 | 상세 |
|---|---|---|
| 요건 충족 판단 | 이 사실이 이 요건에 해당하는지 판단하는 것 — LLM이 하는 유일한 일 | [[2-1_시스템_개요]] |
| 전제 | 판정이 성립하려면 추가로 확인돼야 할 조건(기업 프로필에서 확인되지 않은 항목) | [[2-2b_근거와_전제]] §미확인 전제 처리 |
| 문장 ID | 컨텍스트에 넣은 조문 문장에 매긴 일련번호(S01…) — LLM은 원문 대신 이 ID만 인용 | [[6-2_출력_스키마]] §2 |
| 하향 | 근거가 약할 때 판정을 한 단계 낮추는 것(예: 가능→조건부). 검사 결과는 검증코드로 남긴다 | [[6-4_검증과_하향]] |
| 신뢰등급 | 인용 근거의 품질(A/B) — 코드가 청크 속성으로 산정, LLM 출력값 사용 금지 | [[6-2_출력_스키마]] §1 |
| 참조관계 | "이 규정이 왜 나에게 적용되나"를 보여주는 위임 관계 목록 | [[6-2_출력_스키마]] §1 |
| PMS | K-Startup 사업관리시스템 — 창업기업이 실제 협약·집행을 등록하는 정부 시스템 | [[3-4_데이터셋_구조]] |

코드: `scripts/llm_schema.py` · `인용` · `최종응답`
```python
class 인용:
    """문장ID 는 LLM 이 고르고, 나머지는 llm_validate 가 문장맵과 DB 로 채운다."""
    문장ID: str                                 # LLM
    ...
    원문: Optional[str] = None                  # 코드: DB 원문 치환. LLM 이 생성하지 않는다
...
class 최종응답:
    ...
    # 코드가 채우는 것. LLM 이 스스로 주장한 값을 쓰지 않는다
    신뢰등급: Optional[Literal["A", "B"]] = None   # 인용 문서의 extraction 등 실제 속성으로 정한다
    규정버전: Optional[str] = None                 # 인용 문서의 documents.version
```

## 번호·기호 대응표

| 표기 | 뜻 | 비고 |
|---|---|---|
| ①~⑦ = (1)~(7) | 온라인 판정 파이프라인 단계 | 두 표기는 같은 것. ④는 판정 생성, 조건부이면 재판정이 한 번 더 붙는다. 조항별 사전 판정은 설계만 있고 채택하지 않았다 |
| B0~B6 | ④ 판정 프롬프트의 블록 순서 — B0 시스템 지시 · B1 기관 규정(L3) · B2 검색 규정 · B3 참조 조항 · B4 룰 요약 · B5 프로필 요약 · B5.5 확인 항목 · B5.7 사용자가 확인해 준 내용 · B6 질문 | [[6-2b_컨텍스트_구성]] §4 (범위 밖) |
| 인덱싱 단계 | 오프라인 인덱싱 — 파싱 → 적용대상 태깅 → 참조 그래프 → 우선순위 조항 추출 → 표 추출 → 룰 컴파일 → 청킹·임베딩 | [[4-1_인덱싱]]. 이전 문서의 Stage 0~2 표기 |
| L1 / L2 / L3 | 규정 계층 — 중기부 / 창진원 / 주관기관 | [[2-3_규정_계층과_효력순위]] |
| 기업 프로필 항목 | 협약 · 과업범위 · 집행내역 · 참여인력 · 특수관계 · 기업정보 · 수혜이력 | [[2-5_기업_프로필]]. 이전 표기 F1~F7. 판정 프롬프트의 경로 접두어 `F1.`~`F5.` 는 아직 이 번호를 쓴다 |
| 화면 이름 | 묻기 · 비목 확인 · 판정 · 할일 · 근거 · 문의 | 화면 번호 체계가 여럿이라 문서에서는 이름으로 쓴다 — 아래 화면 번호 표 |
| 엄격조항 · 개정감지 · 기관답변 | 재검수 큐(`corpus.recheck_queue.종류`)를 채우는 비동기 작업 구분 (판정 처리와 무관) | 범위 밖. 이전 작업 코드 A2 · A4 · A5 |
