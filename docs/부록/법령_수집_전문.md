# 법령 크롤링 — L1 코퍼스 조달 방법과 재실행 가이드

**조달은 끝난 작업이다.** 이 문서는 law.go.kr 을 다시 칠 때(개정 대응·범위 확장)만 편다.
수량 실측은 SessionStart 훅이 정본이다.

## 1. 자산과 스크립트

| 자산 | 위치 |
|---|---|
| 현행 법령·행정규칙 XML | `법령 PDF/L1_법령/` |
| 구판(시점본·연혁) XML | `법령 PDF/L1_법령/연혁/` |
| 첨부 (별표·본문공백 보완) | `법령 PDF/L1_법령/첨부/` |
| 행정규칙 별표 (HWP→PDF 변환 완료) | `법령 PDF/L1_법령/별표/` + `_hwp변환/` |
| 범위 밖 보류 | `법령 PDF/L1_법령/_범위밖_보류/` — 인덱싱 금지, 사슬 완성용 보관 |

| 스크립트 | 역할 |
|---|---|

| `scripts/fetch_admrul_history.py` | 행정규칙 구판 (`nw=2`) |

| `scripts/build_delegation_paths.py` | 위임 계통 복원 |
| `scripts/build_law_sources.py` | 출처 통합 인덱스 + 판정 인덱스 편입 판정 |

## 2. 운영 규칙

- **파일은 규범당 한 벌만.** 창진원·중기부 두 배치가 같은 법을 참조해도 복제하지 않는다 —
  출처는 `_law_sources.json` 의 `sources` 배열(`["창진원"]`/`["중기부"]`/둘 다)
- **판정 인덱스 편입은 `index` 플래그.** 위임 추적이 넓게 딸려온 타부처 보조금 규정·복지 계열
  등은 `index: false` — 「교육부 국고보조사업 관리규정」이 창업지원금 판정에 인용되면 사고다
- ⚠️ `index` 는 **직접참조 여부로 결정**한다. 위임으로 딸려온 것(`ref_id` 가 `D-`)을
  직접참조로 세면 타부처 규정이 전부 통과해 필터가 무력화된다
- 위임 추적은 3단계(법률 → 시행령·시행규칙 → 위임 행정규칙), `위임구분=인용법령` 은 제외.
  제외분은 `_law_delegated_dropped.json` · `_mss_delegated_dropped.json` 에 보관
- 구판은 판정 인덱스 편입분만 받는다(`--all` 로 전량 가능). 구판은 제명이 다를 수 있어
  묶는 키는 개정 불변인 **행정규칙ID / 법령ID**
- 청킹·조 분해는 `RAG.md` §3 이 정본이다 (이 문서는 조달까지만)

### 별표는 세 갈래로 갈린다

| 대상 | 별표가 어디 있나 | 수집 |
|---|---|---|
| 법령 | XML `별표단위/별표내용` 에 ASCII 박스표 | 자동 (본문 포함) |
| 행정규칙 (본문 참조) | 본문엔 "별표 1에 따른다"만 | `target=admbyl` |
| 행정규칙 (첨부) | 첨부 HWP/PDF | `첨부파일링크` |

`admbyl` 의 `query` 는 별표명만 매칭하므로 행정규칙명으로는 못 찾는다 — 전체 목록을
페이지네이션으로 훑어 `_admbyl_index.json` 캐시를 만들고 `관련행정규칙명` 으로 거른다.

### 행정규칙 XML 본문 모양 3종

```text
(a) 법령          → .//조문단위
(b) 행정규칙       → 최상위 조문내용 반복
(c) 행정규칙 변종   → <조문> 래퍼 안에 조문번호/조문제목/조문내용
```

`stage0_extract.py::extract_xml()` 은 `.//조문내용` descendant 검색이라 셋 다 처리한다.

## 3. 재실행 명령어

```powershell
python scripts/Law_Crawling.py --dry-run          # 창진원(L2) 배치 대상 확인
python scripts/mss_crawl.py --dry-run             # 중기부(L1) 배치 대상 확인
python scripts/fetch_admrul_history.py            # 행정규칙 구판 (nw=2)
python scripts/fetch_admrul_attachments.py        # 별표 참조 행정규칙의 첨부
python scripts/fetch_admrul_appendix.py           # 행정규칙 별표 (target=admbyl)
python scripts/build_delegation_paths.py          # 위임 계통 복원
python scripts/build_law_sources.py               # 출처 통합 인덱스
python scripts/build_mss_doc.py                   # 중기부_법령_링크모음.md 재생성
python scripts/convert_hwp.py                     # HWP/HWPX → PDF
python scripts/build_precedence.py                # 우선순위 조항 → _precedence_rules.json
python scripts/build_refs.py                      # 참조 그래프 → _refs.json
python scripts/verify_corpus.py                   # 마스터 ↔ 디스크 전수 대조
```

OC 키는 **환경변수 `LAW_GO_KR_OC`** (공개 저장소에 개인 ID 를 두지 않는다).
비어 있으면 `require_oc()` 가 즉시 죽는다 — OC 가 틀리면 API 는 HTTP 200 에 빈 결과를
주므로 조용한 0건으로 새면 안 된다.

```powershell
$env:LAW_GO_KR_OC = "<law.go.kr 신청 ID>"   # PowerShell
export LAW_GO_KR_OC='<law.go.kr 신청 ID>'    # bash
```

## 5. 검증된 API 함정 14 — 재크롤링 시 반드시 반영

| # | 함정 | 대응 |
|---:|---|---|
| 1 | JSON 은 단일 원소가 배열이 아닌 **객체**로 와서 `for` 순회가 조용히 깨진다 | XML 채택으로 회피 |
| 2 | `lsDelegated` 가 주는 위임 일련번호는 **구판**이다 | `행정규칙ID`/`법령ID`(개정 불변 키)로 현행판 재조회 |
| 3 | 행정규칙 본문은 `MST` 가 아니라 **`ID`** 파라미터 | `MST` 로 치면 HTML 껍데기가 온다 |
| 4 | `위임구분=인용법령` 은 위임이 아니라 참조다 | 따라가면 전체 법령으로 번진다 → 제외 |
| 5 | **다른 법으로 넘어가는 위임도 시행령/시행규칙으로 표시**된다 | 제명 접두 일치로 필터 |
| 6 | 행정규칙 구판은 `eflaw` 가 아니다 | `target=admrul&nw=2` (`nw=1`은 현행만). 묶는 키는 `행정규칙ID` |
| 7 | 일부 판본은 조문내용 대신 안내문만 온다 | 본문은 첨부에만 있다 |
| 8 | `·`(U+00B7)와 `ㆍ`(U+318D)는 **다른 문자**다 | 문서와 API 표기가 갈린다 |
| 9 | 행정규칙 별표가 본문에도 첨부에도 없는 경우가 있다 | `target=admbyl` + `_admbyl_index.json` 캐시 (§2) |
| 10 | `admbyl` 페이지네이션 중 빈 응답이 간헐적으로 온다 | 재시도·부분저장 필수 |
| 11 | 행정규칙 XML 본문 모양이 셋이다 | descendant 검색(`.//조문내용`)이면 셋 다 잡힌다 (§2) |
| 12 | `admbyl` 별표는 확장자 `.hwp` 인데 실제로는 **HWPX** 인 것이 다수 | 한컴 COM 에 포맷을 틀리게 주면 Open 이 조용히 False — **매직바이트 판별** (OLE `D0CF11E0`=HWP / `PK`=HWPX), `convert_hwp.py::sniff()` |
| 13 | 다운로드 간헐 실패 시 수 KB **HTML 오류페이지**가 온다 | 크기 검사로는 새어 나간다 — 매직바이트 검증 + 재시도 |
| 14 | 다단 레이아웃 PDF 는 단어 *사이* 로 다른 컬럼이 끼어든다 | 좌표 기반 컬럼 분리 (`pdftext.py`, `RAG.md` §3-1) |
